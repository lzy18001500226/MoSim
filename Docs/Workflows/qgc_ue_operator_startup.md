# MoSim 飞行仿真与地面站启动流程

## 操作顺序

1. 双击仓库根目录的 `启动Gazebo飞行仿真.cmd`。
2. 保持状态终端打开，等待终端出现 `state=running` 和 `reason=runtime_ready`。
3. 双击 `启动MoSim地面站.cmd`，等待 UE 嵌入 QGC。
4. 确认 QGC 左上角显示 `Ready To Fly` 后，使用 QGC 原生起飞操作。
5. 本轮结束后双击 `停止所有仿真.cmd`。

## 生命周期边界

- 飞行仿真入口拥有 Gazebo、PX4、MAVROS 和控制运行时。
- 地面站入口只连接当前活动 `run_id`，并启动 UE 与 QGC，不创建新的飞行运行时。
- 关闭并重新启动地面站不会停止飞行仿真；地面站启动器会恢复失效的受管 UE 窗口。
- 状态终端直接显示当前运行状态和日志目录，不再提供单独的状态检查脚本。
- 停止入口只清理当前 `run_id` 记录的受管进程，不关闭其他 Unreal 项目。
