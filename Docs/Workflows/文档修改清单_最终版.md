#### 14.3.1 传统Syslab Result Viewer工具

MWORKS Syslab提供内置的Result Viewer结果查看器，用于快速查看仿真曲线、频域分析和数据导出。

1. **时域曲线查看**：打开Result.msr文件，从变量树选择position_mea/velocity_mea/attitude_mea等变量，右键"添加到曲线"，实时查看时域响应

3. **FFT频域分析**：选择时域曲线→工具栏"FFT分析"，查看控制量频谱特性、识别振荡频率
4. **数据导出**：文件→导出数据→CSV格式，用于批量后处理（Python/MATLAB/Excel）
5. **动画回放**：3D Viewer窗口回放飞行轨迹动画，检查空间运动合理性

```

  ├─ tool_parse_simulation_csv  解析ClimbPath/场景仿真结果
  ├─ tool_compute_metrics       计算RMSE、MAE、稳态误差
  ├─ tool_compare_controllers   多控制器横向对比
  ├─ skill_mworks_docs          查询MWORKS语法与接口规范
  └─ workflow_generate_summary  输出标准化分析报告
    ↓
输出：指标图表 + 量化分析 + 参数优化建议
```

- 问："px4ctrl和Official PID在Figure8场景的跟踪误差差异原因？"
