## APP 三阶段架构（从15.3节提取）

**Stage 1：在线建模验证**（图15-2）
- 任务、UAV数量、地图、控制器家族/实例选择
- 场景参数（外力扰动、质量/惯量倍率、电机效率、故障时刻）
- 写入配置 → 打开仿真模型 → CheckModel → MWORKS 原生仿真

**Stage 2：实时联合仿真**（图15-3，MWORKS Live）
- 配置目标主机、RT1/ROS连接、目标频率
- 故障/场景参数配置
- 连接预检 → 实际飞行任务

**Stage 3：代码生成**（图15-4）
- 选择控制器家族
- 打开模型 → MWORKS 原生 GenerateModelCode
- 导出 C99 → CMake 构建 → 部署到 ROS/Gazebo
