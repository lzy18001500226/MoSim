## 0. 正文公式组排版约定

`仿真分析报告_正文骨架.md` 的正文公式按控制律的因果结构排版，而不是把
若干短式横向拼接。若多行共同定义同一条连续或离散计算链，例如误差状态、
更新律、控制输出与限幅，则使用纵向 `aligned` 并以
`\left\{\begin{aligned}\cdots\end{aligned}\right.` 作为一个公式组。若两组
关系处于不同语义层，例如标准设计式与当前图形桥接器的实际投影，必须在两组
之间加入中文推导说明后分开呈现；不要用一个大括号掩盖并不存在的因果连接。
每个正文公式组还应明确其变量、限幅或接口边界，并且不能把候选理论、结构
存在或单次内部探针写成全机性能结论。

## 1. 坐标系、符号与边界

### 1.1 活动模型坐标

MWORKS 活动全机模型使用世界系 ENU 和机体系 FLU 约定：

```latex
\[
\mathcal{F}_W=(x_E,y_N,z_U), \qquad
\mathcal{F}_B=(x_F,y_L,z_U).
\]
```

`FormalAttitudeThrustRunnerBase` 将位置、姿态和参考在同一 MWORKS 约定下
传递。任何 NED/FRD 转换仅发生于外部运行时适配边界，不能把外部 PX4 约定
直接代入 MWORKS 内部符号。常用方向变换可以写为

```latex
\[
\mathbf p_{NED}=\begin{bmatrix}y_N\\x_E\\-z_U\end{bmatrix}, \qquad
\mathbf v_{FRD}=\begin{bmatrix}x_F\\-y_L\\-z_U\end{bmatrix},
\]
```

但该式是接口换算说明，不是活动 MWORKS Plant 内的一次重复动力学计算。

### 1.2 旋翼编号与旋向

活动 Profile 的 MWORKS 旋翼位置为

```latex
\[
\mathbf r_1=(0.053745,-0.053740,-0.014052)^T,\quad
\mathbf r_2=(0.053746, 0.053759,-0.014052)^T,
\]
```
```latex
\[
\mathbf r_3=(-0.053761,0.053760,-0.014052)^T,\quad
\mathbf r_4=(-0.053761,-0.053739,-0.014052)^T\;\mathrm{m}.
\]
```

旋翼指令符号和偏航反扭矩方向均为
\(\{+1,-1,+1,-1\}\)。负号是当前视觉旋翼/分配器约定的一部分，不能在
报告中改写为所有电机正转的理想矩阵。

## 2. 旋翼、电机与故障注入

### 2.1 一阶电机动态与推力

对第 \(i\) 个旋翼，活动模型使用带上升/下降时常数的一阶动态：

```latex
\[
\tau_i=
\begin{cases}
\tau_{up}, & |\omega_{cmd,i}|>|\omega_i|\\
\tau_{down}, & \text{otherwise}
\end{cases},\qquad
\dot{\omega}_i=\frac{\omega_{cmd,i}-\omega_i}{\tau_i}.
\]
```

未缩放推力、故障后推力和偏航反扭矩分别为

```latex
\[
T_{0,i}=C_T\omega_i^2,
\qquad T_i=\eta_{f,i}\eta_{T,i}T_{0,i},
\qquad M_{z,i}=\eta_{f,i}d_i\eta_{M,i}C_M\eta_{T,i}T_{0,i}.
\]
```

其中 \(\eta_{T,i}\) 为静态推力效率，\(\eta_{M,i}\) 为反扭矩效率，
\(d_i\in\{+1,-1\}\) 为偏航方向。调度故障乘子 \(\eta_{f,i}\) 只在指定旋翼且
`time >= fault_start_s` 时取 `fault_rotor_effectiveness`，其他旋翼取 1。

### 2.2 力矩与总作用量

推力在机体系沿正 z 方向；第 \(i\) 个旋翼产生

```latex
\[
\boldsymbol\tau_i=
\begin{bmatrix}
r_{y,i}T_i\\-r_{x,i}T_i\\M_{z,i}
\end{bmatrix}, \qquad
T=\sum_{i=1}^4T_i,\qquad
\boldsymbol\tau=\sum_{i=1}^4\boldsymbol\tau_i.
\]
```

`PhysicalWrenchAdapter` 将 \(\{0,0,T\}\) 与 \(\boldsymbol\tau\) 施加到
MultiBody 机体，并允许质量缩放与主惯量缩放作为参数失配场景输入。

### 2.3 6-DOF 刚体闭环表达

当前 `PhysicalWrenchAdapter` 与 MultiBody `BodyShape` 的连续物理等价式为

```latex
\[
\dot R_B^W=R_B^W[\boldsymbol\omega]_\times,\qquad
\mathbf J_B\dot{\boldsymbol\omega}+
\boldsymbol\omega\times(\mathbf J_B\boldsymbol\omega)=\boldsymbol\tau .
\]
```

其中 \(\mathbf J_B\) 由 `Sunray150VirtualPx4Classic` 的
`body_inertia_diagonal_kg_m2` 提供。该式是 MWORKS MultiBody 执行力/矩的
报告级物理表达，不表示项目额外实现了一份手写刚体求解器。

## 3. 实际 X 型控制分配

### 3.1 悬停工作点与线性化斜率

`OfflineWrenchAllocator` 不使用理想化对称矩阵。它在当前 Profile 的带符号
悬停转速 \(\omega_h\) 处线性化：

```latex
\[
\Delta T_{rotor}=2C_T\omega_h\Delta\omega,
\]
```
```latex
\[
s_F=4\Delta T_{rotor},\quad
s_\phi=-4\Delta T_{rotor}a_y,\quad
s_\theta=4\Delta T_{rotor}a_x,\quad
s_\psi=-4\Delta T_{rotor}c_M.
\]
```

其中 \(a_x=|r_{1x}|\)、\(a_y=|r_{1y}|\)，当前 Profile 的悬停转速和几何
决定这些斜率。总推力增量、滚转/俯仰/偏航项为

```latex
\[
\Delta\omega_c=\frac{F_z-F_{h}}{s_F},\quad
r=\frac{\tau_x}{s_\phi},\quad
p=\frac{\tau_y}{s_\theta},\quad
y=\frac{\tau_z}{s_\psi}.
\]
```

### 3.2 当前活动混控器

活动分配器实际执行

```latex
\[
\begin{aligned}
\omega_{1,raw}&= \omega_h+\Delta\omega_c-y-p+r,\\
\omega_{2,raw}&=-\omega_h-\Delta\omega_c-y+p+r,\\
\omega_{3,raw}&= \omega_h+\Delta\omega_c-y+p-r,\\
\omega_{4,raw}&=-\omega_h-\Delta\omega_c-y-p-r.
\end{aligned}
\]
```

之后执行按旋向的限幅：1、3 号限制在 \([0,\omega_{max}]\)，2、4 号限制在
\([-\omega_{max},0]\)。因此该实现既包含几何、旋向，又包含悬停线性化与饱和，
不能以未带符号和限幅的对称分配矩阵冒充活动模型。

## 4. px4ctrl 位置/速度外环

图形类
`MoSimQuadrotorModel.Control.Implementations.Sysblocks.PX4CTRL_Original_OuterLoop_Graphical_Sysblock`
以 0.01 s 运行。令 \(\mathbf e_p=\mathbf p_r-\mathbf p\)、
\(\mathbf e_v=\mathbf v_r-\mathbf v\)，图形模型使用

```latex
\[
\mathbf a_d=\mathbf a_r+K_p\mathbf e_p+K_v\mathbf e_v+
\begin{bmatrix}0\\0\\g\end{bmatrix}.
\]
```

当前图形模块三个轴的增益元件均为 \(K_p=1.5\)、\(K_v=1.5\)，并以
\(g=9.80665\) 和 \(m=1.0\) 形成总推力、归一化推力及按测得偏航旋转的
滚转/俯仰命令。该式描述位置/速度外环；其输出通过 EquationBridge 与共享
姿态环、角速度环和分配器相连。它不是对 PX4/ROS C++ 部署行为的声明。

`Px4CtrlAttitudeThrustAdapter` 将当前姿态转换为四元数后送入 EquationBridge，
并把输出的期望四元数转换为 `attitude_ref`，总推力转换为相对悬停的
`collective_thrust_delta`。为了与共享 Plant 保持符号一致，适配器显式采用
`roll_mea = -attitude_mea[1]`。

### 4.1 FormalRunner 的离散与连续边界

正文第 4.1 节中的 \(\mathcal D_{T_s}\) 不是抽象的统一采样假设，而是
`FormalAttitudeThrustRunnerBase`、`FormalBodyRateThrustRunnerBase`、
`FormalWrenchRunnerBase` 及 `Px4CtrlFormalRunner` 中实际存在的
`Modelica.Blocks.Discrete.UnitDelay`。它们对参考位置/速度/加速度、位置测量和
姿态测量采用 `samplePeriod=0.01`、`y_start=0`，位置导数估计器使用
`Modelica.Blocks.Continuous.Derivative(T=0.05)`。

Official PID 是有意保留的例外：`OfficialPidFormalRunner` 继承
`Experiment.Runners.RotorCommandRunner`，该类把参考、位置、姿态和旋翼命令
直接连接；它仍有 `T=0.05` 的速度导数滤波，但没有上述 `UnitDelay` 边界。
因此 v2 Profile 中的 `result_interval_s=0.01` 只能解释为导出/指标节拍，不能
倒推出 Official PID 命令被离散保持。完整公式见正文第 4.1 节。

## 5. 指标定义

位置误差样本沿用正文式（2-6）；这里单独列出其可复制表达，样本数为 \(N\)：

```latex
\[
e_k=\lVert\mathbf p_{r,k}-\mathbf p_k\rVert_2
\]
```

```latex
\[
\mathrm{RMSE}_p=\sqrt{\frac{1}{N}\sum_{k=1}^N e_k^2},
\qquad e_T=e_N.
\]
```

对于具有明确稳态参考的分量，超调按指标脚本中的参考幅值归一：

```latex
\[
M_p=100\%\cdot\frac{\max_t|x(t)-x_{ss}|}{|x_{ss}-x(0)|}.
\]
```

当分母很小或轨迹不是一步稳态时，超调数值可很大；因此它必须与场景定义一同
读取，不能脱离场景做横向优劣结论。对于通用的非阶跃记录，`calc_metrics.py` 的默认
调节时间使用 \(\varepsilon=0.10\,\mathrm m\)、\(T_{hold}=2.0\,\mathrm s\)：

```latex
\[
t_s=\min\left\{t_k-t_0\ \middle|\
e(t_\ell)\le\varepsilon,\quad
\forall t_\ell\in[t_k,t_k+T_{hold}]\right\}.
\]
```

`step_response` 不使用这一通用默认值，而是按合同采用 X/Y 两轴各自阶跃幅值的
5% 容带，并从候选时刻保持到 45 s；该专用判据、尾段窗口和 G3 单条通过关系见正文
第 2.4 节及 `Scripts/results/calc_metrics.jl` 的
`persistent_step_settling_time`。

控制能量是最终四路电机命令 \(\mathbf u_k=[u_{1,k},\ldots,u_{4,k}]^T\) 的梯形
积分代理，而不是电池能耗：

```latex
\[
E_{\mathrm{cmd}}=\sum_{k=1}^{N-1}\frac{t_{k+1}-t_k}{2}
\left(\|\mathbf u_k\|_2^2+\|\mathbf u_{k+1}\|_2^2\right).
\]
```

所有这些指标从每条有效记录的 `metrics/METRICS.json` 读取。无效记录的诊断数值
保留为诊断，不参与通过判定。

## 6. SIL 数值一致性误差

对图形基线 \(x^{(g)}\) 和生成 CFunction 闭环 \(x^{(c)}\)，同一时间栅格上定义

```latex
\[
\mathrm{RMSE}_{\Delta p}=
\sqrt{\frac1N\sum_{k=1}^N\|\mathbf p_k^{(g)}-\mathbf p_k^{(c)}\|_2^2},
\]
```
```latex
\[
e_{att,max}=\max_{k,j}|\theta_{k,j}^{(g)}-\theta_{k,j}^{(c)}|,
\qquad
e_{rotor,max}=\max_{k,i}|\omega_{k,i}^{(g)}-\omega_{k,i}^{(c)}|.
\]
```

当前门限为 \(\mathrm{RMSE}_{\Delta p}<10^{-6}\,m\)、
\(e_{att,max}<10^{-8}\,rad\)、\(e_{rotor,max}<10^{-6}\,rad/s\)。50 s SIL
的实际结果和哈希位于
`Results/control_platform/px4ctrl_codegen_sil_v1/logs/CLOSED_LOOP_SIL_RESULT.json`；
它仅证明 MWORKS 内的图形模型到 CFunction 数值等价。
