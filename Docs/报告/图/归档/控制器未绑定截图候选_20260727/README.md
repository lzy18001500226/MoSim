# 未绑定控制器截图候选归档

本目录保存迁移到 v2 截图槽位之前的 92 张控制器图片候选：46 张结构图候选和 46 张最小闭环结果图候选。

原始归档时，这些文件缺少当前冻结模型来源和当前 G5 packet 的绑定。2026-07-28 用户完成视觉审核后，46 张 `01_图形模型.png` 候选已按控制器 ID 复制到 `Docs/报告/图/控制器/` 的当前七族目录，用于结构展示；本归档副本保持不动。46 张 `02_最小闭环结果原生窗口.png` 仍仅用于历史追溯，不能作为当前源仿真、RMSE、排名或七场景结论。

原始路径、归档路径、SHA-256、文件尺寸和候选角色见 `UNBOUND_SCREENSHOT_ARCHIVE_MANIFEST.json`。`pre_v2_*` 清单记录归档时的旧 v1 槽位状态；当前归位关系和哈希核验见 `Docs/报告/审计/控制器原生截图归位/CONTROLLER_SCREENSHOT_REBUILD_MANIFEST.json`。
