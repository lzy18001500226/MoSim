# 手绘架构图片清单

本目录保留报告可用的架构和流程图副本。`00` 为总览缩略图，`01` 至 `22` 为
可选正文图，共 23 张 PNG。图 `03`、`06`、`14`、`15`、`21`、`22` 已于
2026-08-01 按当前 P0 口径替换；旧版本不再作为正文图源。

## 使用规则

- 图前必须有正文引导，图后必须给出解释或结论；不要连续堆放多张图。
- 图题放在图下方，Word 中用域代码编号；下表仅给出写作参考。
- 手绘图解释结构和流程，不替代 `Results/` 下的仿真日志、指标、原生截图或
  manifest。
- 图中的控制器数、G3 状态、七场景和安全结论必须服从
  `Docs/Design/报告手册交付证据总账_P0_20260731.md`，不从图形反推性能结论。
