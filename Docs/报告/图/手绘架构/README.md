# 手绘架构图片清单

> 来源：`Docs/报告/新建文件夹/` 中 20 张哈希命名 PNG。
> 本目录保留报告可用副本，原始图不移动、不删除。

## 使用规则

- 这些图优先用于《仿真分析报告》和《用户手册》的系统说明、算法结构、部署链路和操作流程章节。
- 图名前必须有正文引导，图后必须有解释或结论；不要连续堆放多张图。
- 图名放在图下方，Word 中用域代码编号；本文中的“建议图题”只作为正文写作参考。
- 手绘图用于解释结构和流程，不替代 `Results/` 下的仿真日志、指标、截图或 manifest。
