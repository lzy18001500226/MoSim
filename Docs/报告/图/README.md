# 报告图片目录

本目录保存准备插入《仿真分析报告》和《用户手册》的图片副本与图表。原始仿真
结果、指标、日志和原生窗口截图仍以 `Results/` 下的记录为准。

## 当前 P0 使用口径

当前数值、证据层级和不得升级的结论统一以
`Docs/Design/报告手册交付证据总账_P0_20260731.md` 为准。报告正文需要的是
可读、可追溯的代表性结构图、数据图和原生窗口例证；它不要求把每个控制器都
复制成一张正文图片。

当前工作区已有足够的正文视觉资产。后续图文排版只需按下表选择合适的图，不再
将“补截图数量”当作 P0 的独立完成条件。

## 使用边界

- 手绘图只解释架构、算法和流程，图后的性能结论必须回到 `Results/` 的指标或
  P0 证据总账。
- 七场景为 14 条总记录，其中 12 条有效、2 条无效负样本；灵敏度为 24 条记录，
  17 条通过、3 条物理门限失败、4 条执行阻塞。
- ECBF 图必须保留“已执行但 `blocked`、安全触发门未通过、避障未验证”的边界。
- 历史导出资产和未绑定候选图仍在 `归档/` 下，仅供哈希追溯，不能作为正文或
  当前性能证据。

## 文件命名

新增图片采用：

```text
序号_对象_场景_证据类型.png
```

例如：

```text
01_OfficialPID_ClimbPath_结果曲线.png
02_PX4CTRL_代码生成_目录窗口.png
03_ECBF_三机编队_安全边界.png
```

不要将登录页、升级弹窗、空白窗口、通知遮挡截图或无法追溯来源的论文图片放入
本目录。
