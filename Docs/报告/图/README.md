## 文件命名

统一采用：

```text
序号_对象_场景_证据类型.png
```

例如：

```text
01_OfficialPID_悬停_结果曲线.png
02_PID_INDI_八字_结果曲线.png
03_FTC_电机1效率下降_结果曲线.png
```

不要在本目录中放入激活登录页、升级弹窗、空白窗口、被通知遮挡的截图或无法追溯来源的论文图片。
