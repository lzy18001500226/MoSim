## Skill 简要介绍（模型开发调试类）

### 一、简要概述

| 字段 | 内容 |
|------|------|
| **Skill 名称** | `ty-sysplorer-modeling-rules` |
| **Skill 中文名称** | Sysplorer 建模必须遵守的规范 |
| **Skill 描述** | 用于在 Sysplorer 建模任务中统一规定 Modelica 物理模型、Sysblock 框图模型和混合建模的分流、路径、工具、七门闸、图解语义和交付闭环。 |
| **版本信息** | `V1.0.0` |
| **Skill 类型** | 建模必须遵守的总规则 |

---

### 二、触发条件

- 当用户表达需要新建、搭建、编辑或仿真模型时触发。
- 当任务涉及 Modelica 物理建模、Sysblock 框图建模或 Sysplorer + Sysblock 混合建模时触发。
- 当建模范式、工作路径、工具分工、七门闸或图解闭环需要统一约束时触发。
- 领域 Skill 必须在本 Skill 之后作为补充层使用。

---

### 三、核心功能

- 支持 Modelica 物理路径、Sysblock 路径和混合建模路径分流。
- 规定建模工作路径、Sysplorer 会话安全、工具分工和全局禁令。
- 规定 Modelica 纯文本建模、Sysblock 官方 API 建模和混合模型 SEC 实例嵌入边界。
- 规定七门闸、修复闭环、Gate 6 图解语义 / `smart_layout` 检查和最终交付证据。

---

### 四、适用场景

- 从零搭建 Modelica 物理模型或模型库。
- 创建、修复或验证 Sysblock 框图模型。
- 在 Modelica 物理顶层中嵌入已完成 Sysblock 控制器或算法模型。
- 对模型执行检查、布局、翻译、仿真、结果验证和目标达成判断。
