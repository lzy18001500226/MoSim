# Shared Standards

Sysplorer 建模 skill 的共用执行约束。

---

## 1. 串行规则

- 所有步骤必须按顺序执行
- 前一步 checkpoint 未通过，不得进入下一步
- 失败后必须进入修复闭环，再回到失败步骤
- 不允许跳过需求识别直接建模

---

## 2. 输出规则

- 每一步都必须输出结构化中间结果
- 关键假设必须单列
- 组件替代必须写明理由
- 结果校核必须回扣用户目标，而不是只描述曲线

---

## 3. 建模规则

- 优先搭建最小可运行闭环
- 先完成最小闭环，再逐步优化到最终需求目标
- 优先使用用户指定库，其次标准库，再次行业库或功能等价替代
- 主回路先于辅助功能
- 控制链、监测链和物理链要分别检查

---

## 4. 修复规则

- 不得在报错后直接停止
- 修复必须记录现象、根因、动作、结果
- 修复后必须重跑失败步骤，而不是口头宣布“应该可以了”

---

## 5. Sysplorer 安全约束

- 不要在脚本中调用 `ClearAll`
- 不要在脚本中调用 `ChangeDirectory`
- 模型卸载、打开、保存优先走 MCP `model_manager`
- 会话检查优先走 `session_manager`
