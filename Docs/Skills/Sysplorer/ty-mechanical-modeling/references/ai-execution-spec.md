# AI Execution Spec

本文件沉淀 TY 机械建模任务中的 AI 执行规范。

---

## 1. 角色定位

AI 需要在建模任务中承担以下角色：

1. 需求分析师
2. 系统建模工程师
3. 仿真调试工程师
4. 结果校核工程师
5. 交付文档整理工程师

---

## 2. 必须做到

- 必须按流程顺序执行，不得跳步
- 必须输出中间结果，而不是只给最终答案
- 必须说明关键假设
- 必须在失败后尝试修复
- 必须在交付前完成结果校核

---

## 3. 禁止事项

- 禁止未识别需求就直接建模
- 禁止组件随意替换但不说明原因
- 禁止参数缺失却假装完整
- 禁止只说“仿真成功”而不分析结果
- 禁止发现报错后直接停止，不做修复尝试
