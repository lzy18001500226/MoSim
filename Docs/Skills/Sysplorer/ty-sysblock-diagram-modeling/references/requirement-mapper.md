# 需求映射器

本文档将用户请求映射为具体的 Sysblock 建模任务类型。

## 1. 任务类型识别

### 1.1 新建模型 (Build New Model)

**触发关键词：**
- "新建"
- "搭建"
- "创建"
- "实现"
- "设计"
- "build", "create", "new"

**典型场景：**
- "新建一个典型的Sysblock模型"
- "搭建一个电机转速控制系统"
- "创建一个 PI 控制器模型"
- "设计一个传递函数系统"

### 1.2 修复模型 (Repair Model)

**触发关键词：**
- "修复"
- "错误"
- "不工作"
- "有问题"
- "报错"
- "repair", "fix", "error", "bug"

**典型场景：**
- "模型检查报错"
- "仿真失败"
- "端口连接错误"

### 1.3 验证模型 (Verify Model)

**触发关键词：**
- "验证"
- "检查"
- "测试"
- "verify", "check", "test"

**典型场景：**
- "验证模型是否正确"
- "检查系统稳定性"

### 1.4 参数整定 (Parameter Tuning)

**触发关键词：**
- "整定"
- "调整"
- "优化"
- "tune", "tuning", "adjust", "optimize"

**典型场景：**
- "PI 参数整定"
- "调整控制器增益"
- "优化系统响应"

## 2. 系统域识别

### 2.1 控制系统

**特征：**
- 控制器（PI, PID, PD）
- 传递函数
- 阶跃响应
- 反馈回路
- 稳态误差
- 超调量

**典型组件：**
- Step (阶跃信号)
- Gain (增益)
- Sum (加法器)
- Integrator (积分器)
- TransferFcn (传递函数)
- Scope (示波器)

### 2.2 信号处理

**特征：**
- 滤波
- 调制/解调
- 采样保持

**典型组件：**
- SineWave (正弦波)
- LowpassFilter (低通滤波)
- UnitDelay (单位延迟)

### 2.3 电力电子

**特征：**
- PWM
- 逆变器/整流器
- 电机驱动

**典型组件：**
- PulseGenerator (脉冲发生器)
- TriangleWave (三角波)
- Compare (比较器)

## 3. 关键参数提取

### 3.1 控制性能指标

| 参数 | 说明 | 单位 |
|------|------|------|
| 上升时间 | 10%~90% 响应时间 | s |
| 超调量 | 峰值超过稳态值的比例 | % |
| 调节时间 | 到达并保持在误差带内的时间 | s |
| 稳态误差 | 长期偏差 | % |

### 3.2 仿真参数

| 参数 | 说明 | 典型值 |
|------|------|--------|
| StopTime | 仿真结束时间 | 5s, 10s |
| Interval | 输出间隔 | 0.01s |
| Solver | 求解器 | Euler, RungaKutta |

### 3.3 控制器参数

| 控制器 | 参数 | 说明 |
|--------|------|------|
| P | Kp | 比例增益 |
| PI | Kp, Ki | 比例增益, 积分增益 |
| PID | Kp, Ki, Kd | 比例, 积分, 微分 |

## 4. 边界条件

### 4.1 不适用本 Skill 的场景

| 场景 | 正确 Skill |
|------|------------|
| 液压系统建模 | ty-hydraulic-pneumatic-modeling |
| 气动系统建模 | ty-hydraulic-pneumatic-modeling |
| 机械系统建模 | ty-mechanical-modeling |
| Modelica 物理模型 | modelica-library-workflow |

### 4.2 需要额外工具的场景

| 场景 | 额外工具 |
|------|----------|
| HDL 代码生成 | SimulinkImporter + HDL Coder |
| FMU 导出 | model_manager(export_fmu) |
| 实时仿真 | xPC Target 配置 |

## 5. 决策流程

```
用户请求
    │
    ├─► 包含 "Sysblock" 或 "框图" 或 "嵌入式控制"
    │       │
    │       ├─► 新建模型 → 走 Workflow A
    │       ├─► 修复模型 → 走 Workflow B  
    │       └─► 参数整定 → 走 Workflow C
    │
    └─► 不包含上述关键词
            │
            └─► 检查是否液压/气动/机械 → 跳转对应 Skill
```

## 6. 输出模板

映射结果应输出：
1. **任务类型**: 新建/修复/验证/参数整定
2. **系统域**: 控制系统/信号处理/电力电子
3. **关键组件**: 列表形式
4. **关键参数**: 提取的性能指标
5. **建议工作流**: A/B/C
