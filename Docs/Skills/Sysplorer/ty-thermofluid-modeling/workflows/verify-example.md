# 验证样例或现有模型

## 适用场景

- 用户要求运行官方样例、企业样例或现有模型并验证结果。
- 用户要求判断某个样例是否可以作为后续建模参考。

## 推荐输入

- 样例路径、模型名称或现有模型名称。
- 用户关注的关键变量和验证目标。
- 需要验证的是结构、收敛性还是物理结果。

## 执行流程

### GATE 1：明确验证边界

1. 先确认任务是“只做验证”，还是“验证后继续改造成用户模型”。
2. 明确哪些结果只用于参考，哪些需要作为后续建模依据。

### GATE 2：执行基础流程

1. 按父级闭环执行完整验证。
2. 用 `references/validation-rules.md` 选择关键变量、基础判据和解释口径。

### GATE 3：处理异常

1. 若样例执行失败，用 `references/common-errors.md` 缩小问题范围。
2. 若样例只是参考起点，不把样例本体直接当作最终交付模型。

### GATE 4：形成结论

1. 对照 `references/acceptance-checklist.md` 和 `references/output-contract.md`，说明验证完成度和参考边界。
2. 明确样例可复用的结构、不可直接继承的部分，以及后续建模还需补充的内容。

## 输出重点

- 说明验证对象、验证目标和实际执行结果。
- 说明关键变量的验证结论与异常情况。
- 说明该样例对后续建模的参考价值和限制。
