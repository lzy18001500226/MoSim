# MoSim报告公式与推导

> 用途：本文件是《MoSim四旋翼无人机位姿控制系统仿真分析报告》的统一公式源。正文写作时从这里摘取公式、变量定义和简短推导，嵌入对应章节。
> 边界：公式完整不等于项目全部完成验证。`mu_synthesis`、`neural_smc`等证据未闭合项必须标注为“理论说明/待补证据”，不能写成已通过仿真或部署验收。

## 0. 证据状态约定

| 状态                 | 含义                                          | 报告写法                         |
| -------------------- | --------------------------------------------- | -------------------------------- |
| 已实现且有MWORKS证据 | 已有图形化模型、仿真结果或截图证据            | 可写“完成MWORKS建模与仿真验证” |
| 已实现但证据待整理   | 源码/模型存在，截图、指标或Result.msr尚未归档 | 可写“已建立实现，证据整理中”   |
| 理论说明             | 报告中用于说明控制族覆盖或后续路线            | 只能写“给出理论框架”           |
| 阻塞/待补            | 当前没有稳定仿真或关键资产缺失                | 只能写“待补实验”               |

核心边界：

- 在线 `ATTITUDE_THRUST` 中，PX4拥有姿态/角速度内环；MWORKS离线动画不能作为PX4姿态内环证据。
- `Neural Residual` 是神经网络扰动补偿，不是完整神经网络飞控。
- `Neural-SMC` 是滑模控制律中的神经网络逼近路线，当前应写为理论/待补实验。
- `mu_synthesis` 当前写为鲁棒控制理论覆盖和后续工作，不写成已完成验收。

## 1. 坐标系、姿态与四旋翼动力学

对应章节：第3章 3.1、3.2；第4章 4.2；第11章 11.2。

### F-01 坐标系和旋转矩阵

LaTeX：

```latex
\mathbf{p}_W = [x,\ y,\ z]^T,\quad
\mathbf{v}_W = \dot{\mathbf{p}}_W,\quad
\boldsymbol{\omega}_B = [p,\ q,\ r]^T
```

```latex
\mathbf{v}_W = \mathbf{R}_{WB}\mathbf{v}_B
```

变量定义：

- `W`：世界坐标系。MWORKS离线建模中采用ENU语义时，`x`向东、`y`向北、`z`向上。
- `B`：机体系。采用FLU语义时，`x`向前、`y`向左、`z`向上。
- `R_{WB}`：从机体系到世界系的旋转矩阵。

推导说明：
四旋翼平动方程和观测输出都需要在世界系表达，旋翼推力和机体系角速度通常在机体系表达，因此必须通过 `R_{WB}` 做坐标变换。

证据状态：已实现且有MWORKS证据；在线接口证据需区分PX4的NED/FRD转换。

### F-02 欧拉角旋转矩阵

LaTeX：

```latex
\mathbf{R}_{WB}
= \mathbf{R}_z(\psi)\mathbf{R}_y(\theta)\mathbf{R}_x(\phi)
```

```latex
\mathbf{R}_{WB} =
\begin{bmatrix}
c_\psi c_\theta & c_\psi s_\theta s_\phi - s_\psi c_\phi & c_\psi s_\theta c_\phi + s_\psi s_\phi \\
s_\psi c_\theta & s_\psi s_\theta s_\phi + c_\psi c_\phi & s_\psi s_\theta c_\phi - c_\psi s_\phi \\
-s_\theta & c_\theta s_\phi & c_\theta c_\phi
\end{bmatrix}
```

其中：

```latex
c_\phi=\cos\phi,\quad s_\phi=\sin\phi
```

变量定义：`phi`为滚转角，`theta`为俯仰角，`psi`为偏航角。

证据状态：已实现且有MWORKS证据。

### F-03 四元数姿态表示

LaTeX：

```latex
\mathbf{q}_{WB} = [q_x,\ q_y,\ q_z,\ q_w]^T,\quad
\|\mathbf{q}_{WB}\|_2 = 1
```

```latex
\mathbf{R}_{WB} = \mathbf{R}(\mathbf{q}_{WB})
```

接口边界：

- 跨进程建议字段：`q_enu_from_flu_xyzw`。
- 离线或内部实现若使用 `wxyz`，必须在Adapter边界转换。
- 若 `\mathbf{q}_k^T\mathbf{q}_{k-1}<0`，可取 `-\mathbf{q}_k` 保持符号连续。

证据状态：接口设计已冻结；在线RT能力待验证。

### F-04 平动动力学

LaTeX：

```latex
m\dot{\mathbf{v}}_W
= m\mathbf{g}_W
+ \mathbf{R}_{WB}\mathbf{f}_B
+ \mathbf{d}_f
```

```latex
\dot{\mathbf{p}}_W = \mathbf{v}_W
```

对于四旋翼总推力：

```latex
\mathbf{f}_B = [0,\ 0,\ T]^T,\quad
T = \sum_{i=1}^{4} f_i
```

变量定义：

- `m`：无人机质量。
- `g_W=[0,0,-g]^T` 或按模型坐标约定写入。
- `T`：总推力。
- `d_f`：外部风扰、建模误差和未建模气动力合力。

证据状态：已实现且有MWORKS证据。

### F-05 转动动力学

LaTeX：

```latex
\mathbf{J}\dot{\boldsymbol{\omega}}_B
= \boldsymbol{\tau}_B
- \boldsymbol{\omega}_B \times \mathbf{J}\boldsymbol{\omega}_B
+ \mathbf{d}_\tau
```

```latex
\dot{\mathbf{R}}_{WB}
= \mathbf{R}_{WB}[\boldsymbol{\omega}_B]_\times
```

变量定义：

- `J`：机体转动惯量矩阵。
- `tau_B=[tau_x,tau_y,tau_z]^T`：机体系控制力矩。
- `d_tau`：力矩扰动和未建模耦合项。
- `[omega]_x`：叉乘反对称矩阵。

证据状态：已实现且有MWORKS证据。

## 2. 旋翼、电机、电调与控制分配

对应章节：第3章 3.2、3.3；第10章 10.2。

### F-06 旋翼推力和反扭矩

LaTeX：

```latex
f_i = k_f \eta_i \Omega_i^2
```

```latex
\tau_{z,i} = \sigma_i k_m \eta_i \Omega_i^2
```

变量定义：

- `Omega_i`：第 `i` 个电机转速。
- `k_f`：推力系数。
- `k_m`：反扭矩系数。
- `eta_i`：第 `i` 个电机效率，正常为1，故障下降时小于1。
- `sigma_i`：旋翼旋向符号。

证据状态：故障注入和电机效率下降用于MWORKS/Gazebo场景说明；在线应用值需要AppliedEvent证据。

### F-07 四旋翼控制分配矩阵

LaTeX：

```latex
\begin{bmatrix}
T \\ \tau_x \\ \tau_y \\ \tau_z
\end{bmatrix}
=
\begin{bmatrix}
1 & 1 & 1 & 1 \\
0 & l & 0 & -l \\
-l & 0 & l & 0 \\
\sigma_1\kappa & \sigma_2\kappa & \sigma_3\kappa & \sigma_4\kappa
\end{bmatrix}
\begin{bmatrix}
f_1 \\ f_2 \\ f_3 \\ f_4
\end{bmatrix}
```

```latex
\mathbf{u}_a = \mathbf{B}_a\mathbf{f}
```

变量定义：

- `l`：电机到质心距离。
- `kappa=k_m/k_f`。
- `u_a=[T,tau_x,tau_y,tau_z]^T`。

证据状态：已实现且有MWORKS证据；故障分配重构需单独说明证据状态。

### F-08 电机一阶动态

LaTeX：

```latex
\tau_m \dot{\Omega}_i = -\Omega_i + \Omega_{i,c}
```

```latex
\Omega_i \in [\Omega_{\min},\ \Omega_{\max}]
```

变量定义：

- `tau_m`：电机响应时间常数。
- `Omega_{i,c}`：控制器或分配器给出的期望转速。

证据状态：用于执行器动态建模说明。

### F-09 电机故障下的分配重构

LaTeX：

```latex
\mathbf{u}_a = \mathbf{B}_a \mathbf{E}\mathbf{f}_c,\quad
\mathbf{E}=\mathrm{diag}(\eta_1,\eta_2,\eta_3,\eta_4)
```

```latex
\mathbf{f}_c^\star
= \arg\min_{\mathbf{f}_c}
\left\|
\mathbf{W}_u(\mathbf{B}_a\mathbf{E}\mathbf{f}_c-\mathbf{u}_{a,d})
\right\|_2^2
+ \rho\|\mathbf{f}_c-\mathbf{f}_{c,0}\|_2^2
```

```latex
\mathrm{s.t.}\quad
f_{\min}\le f_{c,i}\le f_{\max}
```

证据状态：故障容错层可写为已建立框架；单电机故障完整闭环按当前仿真证据写，不夸大多故障重构。

## 3. 基线控制与PID族

对应章节：第5章。

### F-10 位置误差和速度误差

LaTeX：

```latex
\mathbf{e}_p = \mathbf{p}_d-\mathbf{p},\quad
\mathbf{e}_v = \mathbf{v}_d-\mathbf{v}
```

### F-11 级联PID外环

LaTeX：

```latex
\mathbf{a}_d
= \ddot{\mathbf{p}}_d
+ \mathbf{K}_p\mathbf{e}_p
+ \mathbf{K}_i\int_0^t \mathbf{e}_p(\tau)d\tau
+ \mathbf{K}_d\mathbf{e}_v
```

```latex
T_d = m\left\|\mathbf{a}_d-\mathbf{g}_W\right\|_2
```

```latex
\mathbf{b}_{3,d}
= \frac{m(\mathbf{a}_d-\mathbf{g}_W)}{T_d}
```

推导说明：位置外环先计算期望加速度，再转换为期望推力方向和总推力；`ATTITUDE_THRUST`输出边界使用该思想。

证据状态：Official PID、Cascade PID、Anti-windup、Feedforward Profile可写入PID族说明。

### F-12 抗积分饱和

```latex

= \mathbf{e}_p
+ \mathbf{K}_{aw}(\mathbf{u}_{sat}-\mathbf{u})
```

```latex
\mathbf{u}_{sat}
= \mathrm{sat}(\mathbf{u},\mathbf{u}_{\min},\mathbf{u}_{\max})
```

变量定义：`xi`为积分状态，`K_aw`为抗饱和回灌增益。

证据状态：已实现且有MWORKS证据。

### F-13 前馈轨迹补偿

LaTeX：

```latex

= \mathbf{u}_{fb}+\mathbf{u}_{ff}
```

```latex
\mathbf{u}_{ff}
= m\ddot{\mathbf{p}}_d

```

推导说明：前馈项补偿已知参考轨迹加速度，反馈项负责误差收敛和扰动抑制。

证据状态：已实现且有MWORKS证据。

### F-14 增益调度PID

LaTeX：

```latex
\mathbf{K}_p(\rho)
= \sum_{j=1}^{N_s} \alpha_j(\rho)\mathbf{K}_{p,j},\quad
\sum_{j=1}^{N_s}\alpha_j(\rho)=1,\quad
\alpha_j(\rho)\ge0
```

```latex
\mathbf{u}
= \mathbf{K}_p(\rho)\mathbf{e}
+ \mathbf{K}_i(\rho)\int\mathbf{e}dt
+ \mathbf{K}_d(\rho)\dot{\mathbf{e}}
```

变量定义：`rho`可取速度、姿态角、推力裕度或任务阶段。

证据状态：已实现且有MWORKS证据。

### F-15 模糊PID

LaTeX：

```latex
\Delta K_p,\Delta K_i,\Delta K_d
= \mathcal{F}(e,\dot e)
```

```latex
K_p=K_{p0}+\Delta K_p,\quad
K_i=K_{i0}+\Delta K_i,\quad
K_d=K_{d0}+\Delta K_d
```

推导说明：模糊规则根据误差和误差变化率调节PID增益，适合在模型不确定或工作点变化时改善过渡过程。

证据状态：已实现且有MWORKS证据。

### F-16 Neural PID

LaTeX：

```latex
\Delta \mathbf{K}
= \mathbf{W}_2 \sigma(\mathbf{W}_1\mathbf{z}+\mathbf{b}_1)+\mathbf{b}_2
```

```latex
\mathbf{z}=[e,\dot e,\int e dt,\rho]^T
```

```latex
\mathbf{u}_{npid}
= (K_{p0}+\Delta K_p)e
+ (K_{i0}+\Delta K_i)\int e dt
+ (K_{d0}+\Delta K_d)\dot e
```

证据状态：Neural PID可写为PID族智能增益补偿；不要写成完整神经网络飞控。

## 6. MPC与优化控制族

### F-39 MPC统一优化问题

LaTeX：

```latex
\min_{\mathbf{u}_{0:N-1}}
\sum_{i=0}^{N-1}
\left(
\|\mathbf{x}_{k+i}-\mathbf{x}_{ref,k+i}\|_{\mathbf{Q}}^2
+ \|\mathbf{u}_{k+i}\|_{\mathbf{R}}^2
```
