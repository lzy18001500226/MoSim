### 4.2 提交包准备策略

#### **方案 A：完整源码包（推荐）**

**包含内容**：
```
MoSim/
├── Models/                    # MWORKS 模型（必需）
├── Config/                    # 配置文件（必需）
├── Scripts/                   # 运行脚本（必需）
├── Docs/                      # 文档（必需）
├── apps/model_studio/         # APP 源码（可选）
├── Results/                   # 结果示例（精简版）
│   ├── control_platform/      # 控制器结果
│   │   ├── seven_scenario_ab_v2/     # 七场景结果
│   │   ├── px4ctrl_three_uav_figure8_v1/  # 三机编队
│   │   └── px4ctrl_codegen_sil_v1/   # 代码生成 SIL
│   └── ui_platform/           # APP 证据
├── requirements.txt           # Python 依赖
├── README.md                  # 项目说明
└── LICENSE                    # 开源协议
```

**排除内容**：
```
- References/          # 参考资料（不提交）
- build/               # 编译产物
- .git/                # Git 历史
- __pycache__/         # Python 缓存
- .venv/               # 虚拟环境
- *.msr > 10MB         # 大结果文件（保留小样本）
- src/                 # 已迁移到 References 的源码
```

**打包命令**：
```bash
# 创建临时目录
mkdir -p /tmp/MoSim_Submission

# 复制核心文件
rsync -av --exclude='References/' --exclude='build/' --exclude='.git/' \
  --exclude='__pycache__/' --exclude='.venv/' --exclude='*.msr' \
  /c/Users/HP/Desktop/MoSim/ /tmp/MoSim_Submission/

# 复制精选结果（小文件）
cp -r Results/control_platform/seven_scenario_ab_v2/*.json /tmp/MoSim_Submission/Results/control_platform/seven_scenario_ab_v2/

# 压缩
cd /tmp && zip -r MoSim_Submission.zip MoSim_Submission/
```

**预计大小**：约 500 MB - 1 GB

#### **方案 B：最小化包（备选）**

只包含 Models/ + Config/ + Scripts/ + Docs/，Results/ 只保留 JSON 指标，不包含原始 .msr 文件。

**预计大小**：约 100-200 MB

### 4.3 Git 仓库清理

**建议**：提交前不做破坏性清理，提交后再优化

**理由**：
1. 当前 git 历史包含所有实验记录（可追溯性）
2. 清理 git 历史（git filter-branch）风险高，容易丢失证据
3. 评委如果要查看开发过程，完整历史更可信

**提交包策略**：
- 提交包（zip）：不包含 .git/
