## 任务 3：补充第6章 接口说明（P1）

**位置**: `Docs/报告/用户手册_正文骨架.md` 第6章（line 250-393）

**操作**: 补充四输出边界接口和控制器注册流程

### 6.1 四输出边界接口

补充接口定义（来自 `Models/MoSimQuadrotorModel/Control/Interfaces/Partial*.mo`）：

| 边界类型 | Modelica 接口 | 输出信号 | 控制器数量 | 典型控制器 |
|---------|--------------|---------|-----------|-----------|
| ATTITUDE_THRUST | PartialAttitudeThrustController | `desired_attitude[4]` (四元数)<br>`normalized_thrust` (0-1) | 20 | Cascade PID, LQR, MPC, Backstepping |
| BODY_RATE_THRUST | PartialBodyRateThrustController | `body_rate_sp[3]` (rad/s)<br>`normalized_thrust` (0-1) | 2 | DFBC High Order, DFBC Smooth Robust |
| WRENCH | PartialWrenchController | `body_force[3]` (N)<br>`body_torque[3]` (N·m) | 1 | H∞ Hover Wrench (未通过) |
| ROTOR_COMMAND | PartialRotorCommandController | `rotor_speed[4]` (rad/s) | 5 | INDI, L1, AWFF, Linear MPC, Improved PID |

**坐标系约定**：
- Plant 统一使用 ENU/FLU（East-North-Up / Forward-Left-Up）
- Adapter 层负责坐标转换（如 px4ctrl 使用 NED/FRD）
- 仅在 Adapter 边界转换，控制器核心保持原生坐标系

### 6.2 控制器注册流程

补充添加新控制器的步骤：

**步骤 1：实现控制器核心**
- Sysblock：在 `Models/QuadrotorControllerBlocks/` 创建 Sysblock 模型
- CFunction：在 `Models/MoSimQuadrotorModel/Control/Implementations/` 创建 EquationBridge + CFunction

**步骤 2：创建 Adapter**
- 选择输出边界（ATTITUDE_THRUST/BODY_RATE_THRUST/WRENCH/ROTOR_COMMAND）
- 在 `Models/MoSimQuadrotorModel/Control/Adapters/` 创建 Adapter.mo
- 继承对应 Partial*Controller 接口
- 映射控制器输出到边界信号

**步骤 3：注册到 MoSim Studio**
- 编辑 `apps/model_studio/src/app.jl` line 40-56
- 在 `MODEL_POSITION_OPTIONS` 数组添加新条目：
  ```julia
  "家族名称/控制器名称" => "Models/Path/To/Adapter.mo"
  ```

**步骤 4：验证 ClimbPath50s**
- 在 MoSim Studio 选择新控制器
- 运行基线测试，检查是否通过 G3（终端误差 < 5 m）

**步骤 5：添加到七场景配置**
- 编辑 `Config/control_platform/seven_scenario_experiment_profiles_g3_gate.json`
- 添加新 Profile 条目

### 6.3 Profile 参数配置

补充 Profile 结构（来自 `Models/MoSimQuadrotorModel/Parameters/Sunray150VirtualPx4Classic.mo`）：

**物理参数**：
- `takeoff_mass_kg`: 起飞质量（kg）
- `arm_length_m`: 机臂长度（m）
- `Ixx, Iyy, Izz`: 转动惯量（kg·m²）
- `rotor_thrust_coefficient`, `rotor_torque_coefficient`: 电机系数

**控制参数**：
- `mworks_controller_hover_percentage`: 悬停油门（0-1）
- `max_tilt_angle_deg`: 最大倾角（deg）
- `max_climb_rate_mps`: 最大爬升率（m/s）

**Adapter 专用参数**：
- `px4ctrl_gains_*`: px4ctrl 增益
- `official_pid_gains_*`: Official PID 增益

### 1.1 系统定位

补充实际描述：
> MoSim 是基于 MWORKS 的四旋翼无人机位姿控制与仿真平台，服务于 2026 年全国大学生数学建模竞赛 A8 赛题。平台以 MWORKS（Sysplorer/Sysblock/Syslab）为建模与控制器验证主线，支持模型在环仿真（MIL）、代码生成、软件在环（SIL）和 Gazebo/PX4/MAVROS 工程部署验证。

**核心特性**：
1. **分层可组合架构**：四输出边界（ATTITUDE_THRUST/BODY_RATE_THRUST/WRENCH/ROTOR_COMMAND）+ 薄 Adapter 层
2. **28 控制器实现**：覆盖经典鲁棒、自适应、非线性、先进控制四大家族
3. **七场景鲁棒性评价**：Hover/Step/Figure8/Spiral/Wind/Mismatch/MotorFault
4. **灵敏度分析工具链**：电机故障/风扰/参数失配三批次自动化验证
5. **MWORKS 国产化工具链闭环**：建模 → MIL → 代码生成 → SIL → Gazebo 部署
