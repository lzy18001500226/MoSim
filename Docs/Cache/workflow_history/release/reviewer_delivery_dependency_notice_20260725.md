# Historical Reviewer Delivery Dependency Notice

> Scope: external cover note for the pre-refactor `MoSim` folder already sent
> to reviewers. Do not add this note, a copied `QuadrotorModel`, or new wrapper
> models into that immutable delivery folder.

## Verified Boundary

The delivered `MoSim\Models` tree contains `MoSimQuadrotorModel`,
`QuadrotorExperiments`, and `QuadrotorControllerBlocks`, but does not contain
the official `QuadrotorModel/package.mo` library. Its source directly requires
types such as:

```text
QuadrotorModel.PathPlanning.EightPath
QuadrotorModel.Mechanics.QuadChassis
QuadrotorModel.Electricals.Actuator
QuadrotorModel.Sensors.Sensors
```

The delivered folder contains no native `Result.msr` result package and no
simulation animation/video fallback. It is therefore not a self-contained
clean-machine simulation delivery.

## Conditional Reviewer Procedure

This procedure is valid only when the reviewer already has a compatible,
properly licensed official `QuadrotorModel` library. Compatibility means the
four required class families above resolve in the same Sysplorer/MWORKS
environment; a package with the same top-level name is not sufficient.

1. Load or enable the reviewer-owned official `QuadrotorModel/package.mo`.
2. Add the submitted `MoSim\Models` directory to the library search path.
3. Load `QuadrotorExperiments/package.mo` and
   `QuadrotorControllerBlocks/package.mo` if Sysplorer does not resolve the
   sibling packages automatically.
4. Load `MoSimQuadrotorModel/package.mo`.
5. Select an existing complete scenario and run **Check Model** before any
   simulation. A source-level candidate is not a passing simulation claim.
6. Simulate only after Check Model passes, then inspect the result generated by
   that same session. Do not substitute an old result window or an unrelated
   file.

Source-level candidates in the historical package are listed below only to
help the reviewer locate the intended entry points after all dependencies
resolve. They have not been revalidated in a clean reviewer environment:

| Candidate class | Intended task |
|---|---|
| `MoSimQuadrotorModel.Missions.Example1LinearMPCSysblockClosedLoop` | single-UAV step climb |
| `MoSimQuadrotorModel.Missions.Example3AWFFSysblockClosedLoop` | single-UAV figure-8 |
| `MoSimQuadrotorModel.Planning.Sunray150PlanningOpenBlocksLinearMPCSysblockClosedLoop` | single-UAV OpenBlocks obstacle scenario |
| `MoSimQuadrotorModel.Formation.FormationTriangleFigure8LinearMPCSysblockClosedLoop` | three-UAV triangle figure-8 |

## If The Official Package Is Unavailable

The submitted source cannot compile or simulate. The correct response is to
obtain the compatible official package through the reviewer-approved vendor or
course distribution channel, or to arrange a separately authorized,
license-compliant supplementary dependency delivery. Do not silently copy a
local reference library into the already-submitted folder.
