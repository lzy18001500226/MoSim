```markdown
### 第07.5页：坐标系与FrameContract转换——ENU/FLU ↔ NED/FRD

**标题**：坐标系与FrameContract转换：ENU/FLU ↔ NED/FRD + 四元数顺序陷阱

**核心视觉（左图右公式）**：
- 左：手绘架构图 `Docs/报告/图/手绘架构/18_坐标系与FrameContract转换关系.png`
- 右：转换公式（报告公式3-1、3-2）
  ```
  ENU → NED:  [x_ned, y_ned, z_ned]^T = [y_enu, x_enu, -z_enu]^T
  FLU → FRD:  [x_frd, y_frd, z_frd]^T = [x_flu, -y_flu, -z_flu]^T
  ```

底部：四元数顺序陷阱——MWORKS用[w,x,y,z]，ROS/PX4用[x,y,z,w]，Adapter必须显式转换

**台词（约12秒）**：
> MWORKS默认用ENU坐标系和FLU机体系，而PX4用NED和FRD。我们在Adapter层做了完整的坐标变换，包括四元数顺序——MWORKS是w在前，ROS是w在后，必须显式调整，否则姿态全错。
```
