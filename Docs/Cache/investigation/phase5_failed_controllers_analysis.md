## dfbc_smooth_robust_attitude 详细诊断

### 问题根源
控制器架构设计假设大范围加速度限制(±8 m/s²或更大)，但当前平台强制±3.0 m/s²限制导致:

1. **PD反馈增益过大** (kp=2.8, kd=2.0)
   - 即使小误差(3.57m)也会产生巨大加速度需求(~144 m/s²)
   - 立即被限制器钳位到3.0 m/s²

2. **鲁棒项和扰动观测器失效**
   - 鲁棒项输出-1.0 m/s² (向下加速度，与上升需求相反)
   - 扰动观测器输出被限制在±0.8 m/s²范围
   - 两者贡献远小于所需的上升加速度

3. **边界层归一化不匹配**
   - `smooth_boundary_normalization_z.k = 2.857` (1/0.35)
   - 边界层厚度0.35可能针对±8 m/s²设计
   - 当限制改为±3.0后，归一化系数过大导致tanh函数快速饱和

### 已尝试的修复
- [x] 将z轴加速度限制从8.0改为3.0 (未解决)
- [x] 交换X/Y加速度到姿态角映射 (未解决)
- [x] 统一推力归一化公式 (未解决)

### 结论
**无法通过简单参数调整救活**，需要重新设计控制器增益和架构以匹配±3.0 m/s²限制。

**建议**: 暂时跳过，标记为"需要重新设计"，优先处理其他11个失败控制器。
