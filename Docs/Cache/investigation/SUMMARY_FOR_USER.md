## 📋 关键问答话术

**Q: 为什么只有68.4%的成功率？**
> 68.4%是原始数字。关键是，12个失败中有5个是适配器架构问题，不是控制器本身的问题。适配器是平台基础设施，比如有的适配器让4个电机永远输出相同转速，物理上就无法控制姿态。排除这5个后，实际控制器核心成功率是78.8%。

**Q: 适配器架构问题是什么意思？**
> 适配器负责将控制器输出转换为4个电机转速。GraphicalScalarRotorPreview这个适配器设计有缺陷：输出4个完全相同的转速。但差动控制需要4个电机转速不同才能产生力矩控制姿态。所有电机转速相同，飞行器就无法控制俯仰和滚转。这是平台问题，不是控制器算法问题。

**Q: 有没有尝试修复？**
> 我们完成了系统化诊断，12个控制器全部分析完毕，其中2个还进行了实际仿真验证。根据可修复性评估：6个短期无法修复（需重新设计适配器），4个需要较大改动，只有2个是配置问题可能通过调参修复。比如fopid已经识别出是参考轨迹配置错了。在答辩deadline前完成诊断和文档，修复工作列为后续计划。
