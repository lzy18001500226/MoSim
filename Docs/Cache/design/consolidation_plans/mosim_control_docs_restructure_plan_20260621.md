# MoSim控制体系文档重构方案

> 日期：2026-06-21
> 位置：`Docs/Cache/design/`
> 性质：重构方案草案，不是正式执行规范。
> 约束：本方案只设计文档重构方式，不修改正式架构文档，不替代当前主线工作流。

## 1. 结论

当前不应再新建一批正式架构文档。

正确做法是对现有文档做收敛式重构：

```text
9份正式控制体系规范
+ 1份研发工作流
+ 1份旧版研究草稿降级归档
```

其中：

```text
MoSim体系.md
```

应明确标记为旧版研究草案，只作为设计输入，不作为当前执行依据。

## 2. 正式文档集合

正式控制体系规范应固定为以下9份：

| 编号 | 文档 | 定位 |

| 文档 | 处理方式 |

## 3. 当前主要问题

### 3.1 文档数量认知需要固定

后续所有索引和回答必须按以下口径：

```text
正式体系 = 9份规范 + 1份工作流
MoSim体系.md = 旧版研究草稿
```

不得再把 `MoSim体系.md` 混入正式规范数量。

### 3.2 标题层级过平

多份文档存在大量一级标题，导致人工和模型检索都很困难。

目标结构：

```text
# 文档标题
## 一级章节
### 二级章节
#### 细分条目
```

每份正式文档只保留一个 `#` 标题。

### 3.3 当前执行入口不够硬

`MoSim控制体系总览.md` 应新增最前置的短入口：

```text
当前阶段
当前只允许推进的任务
当前禁止抢跑的任务
当前需要读取的文档和章节
当前验收门禁
当前未验收/阻塞项
```

这个入口必须短，不应再写成大段体系说明。

### 3.4 状态词过度乐观

文档中不应直接把未经用户审核或证据门禁通过的内容写成：

```text
完成
稳定
已通过
闭环成功
```

建议统一状态枚举：

```text
DESIGNED        设计完成
IMPLEMENTED     已实现但未完整验收
MEASURED        已有实测证据
ACCEPTED        用户/PMO已验收
BLOCKED         有明确阻塞
FUTURE          未来阶段
DEPRECATED      已废弃/历史草稿
```

### 3.5 当前主线和未来路线仍需强隔离

当前主线应固定表达为：

```text
Sunray ROS1 / Gazebo Classic / PX4 Native baseline / px4ctrl baseline
```

第一阶段不应抢跑：

```text
FAST-LIO定位闭环
EGO完整避障闭环
多机编队
完整前端
完整Controller Manager
批量控制器迁移
完整PX4 Module板载部署
UE真值地图导出
```

这些内容可以保留在规范里，但必须标注为后续阶段。

## 4. 建议重构方式

### 4.1 第一轮：只做文档结构硬化

不改技术路线，只改可读性和执行边界。

任务：

```text
1. 给MoSim体系.md增加旧版草稿声明
2. 给MoSim控制体系总览.md增加当前执行索引
3. 给每份正式规范增加文档状态块
4. 把每份文档规范为单H1结构
5. 把状态矩阵中的“完成”替换为状态枚举
6. 给每份文档补“禁止误用”小节
```

### 4.2 第二轮：做正式索引和互链

在 `MoSim控制体系总览.md` 中维护唯一总索引。

每份分册只保留：

```text
本文负责什么
本文不负责什么
依赖哪些文档
被哪些文档引用
当前阶段是否需要读取
```

### 4.3 第三轮：收缩重复内容

优先清理以下重复：

```text
控制器分类重复
MWORKS/Gazebo/PX4关系重复
FAST-LIO/EGO接入时机重复
Agent禁止行为重复
完成标准重复
```

处理原则：

```text
总览只写原则和索引
接口规范只写接口
实现规范只写算法实现
调参规范只写参数和评价
测试规范只写门禁和证据
工作流只写任务顺序和Agent协作
```

## 5. 各文档具体调整建议

### CTRL-01：MoSim控制体系总览.md

需要成为唯一正式入口。

建议新增：

```text
0. 当前执行索引
0.1 当前阶段
0.2 当前允许任务
0.3 当前禁止任务
0.4 当前应读文档
0.5 当前验收证据
0.6 文档权威顺序
```

同时加入：

```text
MoSim体系.md 为旧版研究草稿，不作为正式执行依据。
```

### CTRL-02：MoSim统一控制接口规范.md

重点保留接口，不要承担任务顺序。

需要明确：

```text
当前阶段只要求理解px4ctrl相关ATTITUDE_THRUST接口
IController完整冻结属于后续阶段
Controller Manager完整实现不得抢跑
```

### CTRL-03：MoSim单机控制器实现规范.md

需要把控制器族分成：

```text
当前基线
比赛优先
后续增强
研究储备
```

避免让Agent一次性批量实现 SE3、DFBC、MPC、NMPC、INDI、L1。

### CTRL-04：MoSim控制增强与容错规范.md

需要明确当前阶段不是主线。

建议标注：

```text
当前只作为架构设计和后续比赛亮点储备
不得在px4ctrl基线未稳定前启动完整容错链路
```

### CTRL-05：MoSim规划与编队控制接口规范.md

需要拆清：

```text
轨迹发生器
在线规划器
EGO
FAST/SUPER
编队控制
```

当前阶段只关心轨迹输入和后续 px4ctrl/EGO 接口预留。

### CTRL-06：MoSim控制器管理与配置规范.md

需要避免过早实现完整Manager。

当前只应冻结：

```text
控制器Profile命名
状态源Profile命名
频率Profile命名
参数集版本
```

### CTRL-07：MoSim控制器代码生成与PX4部署规范.md

方向正确，但要在开头强调：

```text
当前不是立刻做完整PX4 Module
当前先完成PX4 Native与px4ctrl基线
MWORKS代码生成从官方PID黄金纵向切片开始
```

### CTRL-08：MoSim控制系统测试与评价规范.md

需要作为验收依据。

建议新增：

```text
当前最小验收套件
起飞-悬停-降落
8字
螺旋爬升
误差表
Gazebo动画审核
RViz轨迹审核
```

并明确截图不能替代指标。

### CTRL-09：MoSim控制器调参与参数优化规范.md

方向较好。

需要重点确认：

```text
100Hz作为当前冻结频率是否已经验收
状态源Profile到底使用哪一个
px4ctrl调参是否先冻结PX4内环
误差目标区分优秀目标和基本通过目标
```

不要把 2cm 当作所有场景硬门槛。

### 工作流：MoSim研发工作流与Agent任务编排规范.md

需要把状态矩阵改成证据驱动，不直接写“完成”。

建议矩阵列改为：

```text
设计状态
实现状态
实测证据路径
用户审核状态
当前阻塞
下一步
```

## 6. 建议的当前阶段入口文本

可放入 `MoSim控制体系总览.md` 顶部：

```text
当前阶段：单机基线控制闭环。

当前主线：
1. PX4 Native基线复现与参数冻结
2. px4ctrl原版复现
3. px4ctrl Sunray适配
4. 起飞、悬停、降落、8字、螺旋爬升实测

当前禁止抢跑：
FAST-LIO定位闭环、EGO完整避障闭环、多机、完整前端、完整Controller Manager、批量控制器迁移、完整PX4 Module板载部署、UE真值地图导出。

当前读取顺序：
CTRL-01 总览
工作流 P0-P2
CTRL-09 调参与误差边界
CTRL-08 当前测试门禁
CTRL-07 px4ctrl与PX4 Native相关章节
```

## 8. 需要用户确认的问题

1. `CTRL-01~09 + 工作流` 是否作为唯一正式文档体系。

2. `MoSim体系.md` 是否只加草稿声明，不迁移内容。

3. 当前状态枚举是否采用：

```text
DESIGNED / IMPLEMENTED / MEASURED / ACCEPTED / BLOCKED / FUTURE / DEPRECATED
```

4. 当前阶段是否固定为：

```text
PX4 Native baseline -> px4ctrl original reproduction -> px4ctrl Sunray adaptation -> baseline trajectory gates
```

5. 第一轮重构是否只做结构、索引、状态词和禁止抢跑项，不改技术内容。

## 9. 推荐执行顺序

如果用户审核通过，建议按以下顺序修改正式文档：

```text
1. 修改 MoSim体系.md：加旧版草稿声明
2. 修改 MoSim控制体系总览.md：加当前执行索引和正式文档索引
3. 修改 MoSim研发工作流与Agent任务编排规范.md：修状态矩阵
4. 修改 CTRL-02~09：统一文档状态块和禁止误用块
5. 批量降级多余H1标题
6. 做一次文档索引一致性检查
```

第一轮完成后，不应宣称架构完成，只能宣称：

```text
控制体系文档执行边界已收敛，正式工程可按当前阶段索引继续推进。
```
