# P0-P3控制器族与实验平台调研矩阵

> 状态：cache调研稿，不是正式设计冻结文档。
> 日期：2026-06-24
> 范围：P0、P1、P2、P3。P4暂不调研。
> 当前口径：MoSim先完成Sunray/PX4/MAVROS/px4ctrl最小大系统闭环，再扩展控制器族；前端目标是RflySim式UE内集成实验平台。

## 0. 调研结论

当前文档里控制器族已经覆盖PID、LQI、SE3、DFBC、SMC、LMPC/NMPC、INDI、L1、DOB/ESO、安全过滤和故障分配，但还缺一个更清晰的“实现位置矩阵”。后续不能按控制器名字平铺，而应按PX4控制链插入点组织。

神经网络相关控制器需要纳入，但不能一开始作为端到端飞控主线。首版应分成四类：

```text
NN/RBF adaptive compensation
  -> 自适应补偿模块，常和Backstepping、SMC、SE3组合。

NN residual controller
  -> 传统控制器输出后的有界残差补偿。

RL gain scheduler
  -> 学习调参模块，输出PID/SMC/MPC权重或增益。

RL residual / policy controller
  -> 后续高风险方向，必须有安全过滤和fallback。
```

P4不做，因此暂不调研P4高层任务或额外控制器批量实现。当前只冻结P0-P3的知识结构、候选清单和后续落正式文档的位置。

## 1. P0：PX4控制链 + MWORKS可实现控制器分类

### 1.1 PX4控制链分层

PX4多旋翼控制链是级联控制结构：

```text
EKF2估计
  ↓
位置/速度控制
  ↓
姿态设定
  ↓
姿态控制
  ↓
角速度设定
  ↓
角速度控制
  ↓
控制分配
  ↓
执行器/电机
```

MoSim控制器必须先声明自己替换哪一层、复用哪一层。第一阶段仍固定：

```text
ATTITUDE_THRUST
  MoSim负责轨迹外环，输出期望姿态 + 物理总推力
  PX4保留姿态环、角速度环、控制分配和执行器输出
```

### 1.2 输出层级与控制器族

| 输出层级 | MoSim可放对象 | PX4保留 | 当前阶段 |
| --- | --- | --- | --- |
| POSITION_SETPOINT | PX4 Native基线、简单目标点接口 | 全部控制环 | 只作为对照 |
| ACCELERATION_YAW | 外部位置/速度控制、部分PID/LQI/MPC | 姿态以下 | 规划保留 |
| ATTITUDE_THRUST | px4ctrl、PID、LQI、SE3 Basic、SMC外环、Backstepping外环、LMPC/NMPC外环、NN/RBF补偿外环 | 姿态环以下 | 第一阶段实际实现 |
| BODY_RATE_THRUST | DFBC高阶、INDI、SMC姿态环、部分NMPC、NN residual姿态层 | 角速度环以下 | 后续阶段 |
| WRENCH | 完整刚体控制、full NMPC、故障容错控制 | 控制分配以下 | 后续阶段 |
| ROTOR_THRUST / ROTOR_SPEED | 故障分配、直接电机控制、端到端RL策略 | 最少 | 高风险后续 |

### 1.3 MWORKS可实现性分级

| 类别 | MWORKS建模 | 代码生成 | Orin/PX4部署风险 | 说明 |
| --- | --- | --- | --- | --- |
| PID / 增强PID | 高 | 高 | 低 | 最适合做模板和教学展示 |
| LQI / LQR | 高 | 高 | 低 | 线性矩阵运算，便于离线一致性 |
| SE3 Basic | 中高 | 中高 | 低到中 | 姿态几何和四元数处理要严控坐标系 |
| SMC / STSMC | 中高 | 中高 | 中 | 抖振、限幅和采样频率是主要风险 |
| Backstepping | 中 | 中 | 中 | 公式复杂度可控时可做 |
| DFBC Basic | 中高 | 中高 | 中 | Basic版可ATTITUDE_THRUST，高阶版需要jerk/snap |
| LMPC | 中 | 中 | 中 | 小维度固定时域可做，求解器要固定内存 |
| NMPC | 中 | 低到中 | 中高 | 依赖求解器、warm start和失败回退 |
| DOB/ESO/ADRC | 高 | 高 | 低 | 适合作为增强模块优先实现 |
| INDI | 中 | 中 | 中 | 更适合BODY_RATE或高频内环阶段 |
| L1 adaptive | 中 | 中 | 中 | 作为增强模块，不是普通主控制器 |
| Fuzzy PID / Fuzzy gain | 中高 | 中 | 中 | 查表/规则推理可部署，训练/规则设计要冻结 |
| NN/RBF compensation | 中 | 中 | 中高 | 推理可部署，训练不进实时闭环 |
| RL gain scheduler | 中 | 中 | 中高 | 更适合MWORKS/Gazebo仿真训练后冻结策略 |
| RL end-to-end actuator | 低 | 低 | 高 | 暂不进第一批，必须有safety/fallback |

## 2. P1：控制器族论文和实现路线

### 2.1 第一层：主控制器

| 控制器 | 插入位置 | 第一版输出 | 需要jerk/snap | 实现路线 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| px4ctrl | 外环轨迹跟踪 | ATTITUDE_THRUST | 否 | 先复现、抽core、MWORKS重建 | 已冻结基准 |
| PID / 增强PID | 位置/速度/高度外环 | ATTITUDE_THRUST | 否 | 先用MWORKS现有模型生成代码，再接同一Adapter | 第一批 |
| LQI | 线性增广状态反馈 | ATTITUDE_THRUST | 否 | 建线性化模型、积分误差、离线一致性 | 第二批 |
| SE3 Basic | 几何外环 | ATTITUDE_THRUST | 通常否 | 基于SE3参考实现，统一四元数/推力语义 | 第一批模板 |
| SMC / STSMC | 外环或姿态环 | ATTITUDE_THRUST优先 | 否 | 先做外环滑模，边界层/超螺旋降低抖振 | 第二批 |
| Backstepping | 外环+姿态层 | ATTITUDE_THRUST优先 | 否 | 先做低阶版本，再考虑NN/RBF增强 | 第三批 |
| DFBC Basic | 微分平坦外环 | ATTITUDE_THRUST | Basic否 | Basic先输出姿态/推力，高阶再用jerk/snap | 第二批 |
| LMPC | 线性约束优化外环 | ATTITUDE_THRUST或ACCELERATION | 通常否 | 固定时域、固定数组、小维度求解器 | 第二批 |
| NMPC | 非线性优化控制 | ATTITUDE_THRUST起步 | 视模型而定 | 先低维外环，后续才WRENCH/ROTOR | 第三批 |

### 2.2 第二层：增强模块

| 模块 | 作用对象 | 插入位置 | 第一版建议 |
| --- | --- | --- | --- |
| DOB/ESO/ADRC | PID、SE3、SMC、Backstepping | 状态/扰动估计层 | 优先实现，适合MWORKS |
| AWFF | PID/SE3/DFBC外环 | 前馈/补偿层 | 和现有MWORKS模型对齐后定义 |
| INDI | DFBC/NMPC/姿态内环 | BODY_RATE或内环 | 暂不塞进第一阶段ATTITUDE_THRUST |
| L1 adaptive | SE3、DFBC、NMPC | 自适应补偿层 | 作为Profile增强，不作为普通下拉控制器 |
| Fuzzy gain | PID/SMC | 增益调度层 | 可做Fuzzy PID或Fuzzy-SMC，不做黑箱主控 |
| NN/RBF compensation | Backstepping、SMC、SE3 | 非线性/扰动逼近层 | 冻结小网络，推理代码可部署 |
| RL gain scheduler | PID/SMC/MPC | 参数调度层 | 比端到端RL更适合比赛主线 |
| RL residual | 传统控制器后处理 | 有界残差层 | 必须接Safety Filter和fallback |

### 2.3 第三层：安全、故障和控制分配

| 对象 | 所属层 | 是否普通控制器 | 第一阶段处理 |
| --- | --- | --- | --- |
| Safety Filter / CBF | 参考或控制输出安全过滤 | 否 | 先设计接口，不抢跑 |
| FDI | 故障检测/隔离 | 否 | 等故障注入模型稳定 |
| Fault Allocation | 控制分配/执行器层 | 否 | 需要WRENCH/ROTOR层级，不进ATTITUDE_THRUST第一版 |
| Reference Governor | 参考约束层 | 否 | 可先作为安全模块文档 |
| 风扰/推力衰减/电机失效 | Plant/实验环境注入 | 否 | 前端滑块和场景配置，不直接作为所有控制器输入 |

### 2.4 神经网络控制器覆盖口径

神经网络相关方向应覆盖，但分阶段进入：

```text
N1 RBF/NN adaptive Backstepping
  用于未知非线性补偿，公式可解释，适合MWORKS建模和小网络推理。

N2 Neural/DOB hybrid
  用NN拟合剩余扰动，DOB/ESO保留主估计结构。

N3 NN residual controller
  传统控制器输出基础上加有界补偿，不绕过主控制链。

N4 RL gain scheduler
  学习参数/权重/Profile选择，最适合前端“扰动/故障滑块”联动。

N5 RL residual policy
  只允许输出小残差，必须Safety Filter裁剪。

N6 End-to-end motor/RPM RL
  作为远期研究，不进当前MoSim第一阶段和P4前任务。
```

前端表达方式：

```text
主控制器：PID / LQI / SE3 / SMC / DFBC / MPC / NMPC
增强模块：DOB-ESO / L1 / AWFF / NN-RBF / RL residual
调参模块：Fuzzy gain / RL gain scheduler
安全模块：CBF / Safety Filter / Reference Governor
故障模块：Fault Injection / FDI / Fault Allocation
```

## 4. P3：UE内集成前端实验平台兼容性矩阵

### 4.1 前端定位

前端目标不是Web dashboard优先，而是RflySim式UE内实验控制台：

```text
UE内集成操作界面
  场景选择
  任务选择
  控制器/Profile选择
  扰动/故障滑块
  状态源选择
  规划器选择
  多机数量与阵型
  运行/暂停/复位
  指标与曲线
  摄像头视角
```

UE只做实验平台和展示面，不拥有控制器成功判定。控制权仍属于Controller Manager / Adapter / PX4链路。

### 4.2 UE前端对象矩阵

| 面板 | 对象 | 后端来源 | 前端控件 |
| --- | --- | --- | --- |
| 场景 | 空场、柱体、窄通道、复杂障碍、比赛场景 | Gazebo/UE场景Profile | 下拉选择 |
| 任务 | 起飞悬停降落、阶跃、圆、8字、螺旋、EGO、Swarm | Trajectory Server / Planner | 按钮/下拉 |
| 控制器 | px4ctrl、PID、LQI、SE3、SMC、DFBC、LMPC、NMPC | Controller Registry | 下拉 + 能力提示 |
| 增强模块 | DOB/ESO、AWFF、L1、INDI、NN/RBF、RL residual | Controller Profile | toggle |
| 调参模块 | Fuzzy gain、RL gain scheduler、自动整定 | Parameter Manager | toggle + profile |
| 状态源 | PX4/MAVROS、FAST-LIO->PX4、FAST-LIO direct、Gazebo truth评价 | State Source Profile | 下拉 |
| 故障扰动 | 风、阵风、推力衰减、电机失效、延迟、饱和 | Plant/Fault Injection | 滑块/时间轴 |
| 安全 | CBF、Safety Filter、限速、限倾角、安全距离 | Safety Manager | toggle + numeric input |
| 多机 | 1/2/3机、队形、目标点、启动延迟 | Swarm Manager | 分段按钮/表格 |
| 可视化 | 点云、累计地图、栅格、轨迹、三轴、第一视角 | RViz/Gazebo/UE bridge | 多窗口/视图切换 |
| 指标 | RMSE、P95、Max、稳态误差、能耗、饱和率 | Results/Test Harness | 曲线/表格 |

### 4.3 兼容性规则

前端必须做兼容性过滤，不能允许任意乱配。

```text
ATTITUDE_THRUST：
  允许px4ctrl/PID/LQI/SE3 Basic/SMC外环/DFBC Basic/LMPC外环/NMPC外环。
  禁止Fault Allocation、rotor-level RL、WRENCH级控制分配。

BODY_RATE_THRUST：
  允许INDI、DFBC高阶、姿态SMC、部分NMPC和NN residual姿态层。
  需要重新验收Adapter。

WRENCH/ROTOR：
  允许故障分配、控制分配重构、full NMPC、直接电机控制。
  默认隐藏或标记为后续阶段。

EGO/Swarm任务：
  规划器只输出轨迹，不直接发布MAVROS控制命令。
  每机控制器实例、状态源、Topic和日志必须隔离。

FAST-LIO状态源：
  未通过LIO门禁前只能作为显示/对照，不默认进入控制闭环。
```

### 4.4 多机显示窗口口径

按当前用户口径，三机实验至少需要：

```text
RViz栅格地图/规划视图：1个
RViz累计点云/轨迹视图：1个
每架飞机第一视角摄像头：3个
合计：2 + 3 = 5个窗口/视图
```

UE内集成后可做成：

```text
主视口：场景跟随/自由相机
左侧：实验配置面板
右侧：指标和控制器状态
底部：时间轴、事件、故障注入
子视口：点云/栅格/每机相机
```
