# 1. 文档目的

本文档规定MoSim中各类四旋翼控制器针对具体飞行器模型进行参数整定、参数搜索、自动优化、结果验证和参数冻结的完整流程。

本文档主要回答：

```text
控制器应该先调哪些参数
哪些参数不能同时调
不同控制器采用什么调参顺序
Agent如何判断当前参数是否更好
调参使用哪些轨迹
优化目标如何定义
哪些情况必须立即停止当前试验
搜索到什么程度可以停止
如何防止只对8字轨迹过拟合
如何证明参数不是刚好卡在稳定边界
如何保存最终参数及其适用机型
机体参数变化后是否需要重新调参
```

# 5. 核心原则

## 5.1 先固定被控对象，再调整控制器

任何调参会话开始前必须冻结：

```text
飞行器质量
惯量
质心
电机布局
电机与桨叶模型
推力上下限
电机时间常数
气动模型
Gazebo物理参数
状态反馈来源
控制周期
控制输出层级
PX4内环参数
```

调参过程中禁止悄悄修改飞行器模型。

---

## 5.2 一套参数只对应一个明确适用域

最终参数集必须绑定：

```text
scenario_profile_id
plant_profile_id
plant_model_hash
sensor_profile_id
height_source_profile_id
truth_profile_id
state_source_profile_id
controller_version
output_level
control_rate_hz
```

不能只保存：

```text
se3_best.yaml
```

应保存为：

```text
se3_attitude_thrust__sunray_gazebo_v1__100hz__v1.yaml
```

---

## 5.3 调参不是最终横向比较

当前阶段允许每个控制器：

```text
使用适合自身结构的调参顺序
使用不同搜索算法
使用不同参数范围
使用不同优化迭代次数
```

但不允许改变：

```text
飞行器
控制频率
参考轨迹几何
状态源
输出层级定义
执行器能力
```

最终横向公平比较由08文档负责。

---

## 5.4 先安全，再性能

调参目标分为：

```text
硬约束
性能目标
工程偏好
```

硬约束不通过时，无论位置误差多小，候选参数均无效。

---

## 5.5 分层调参，禁止一次搜索全部参数

控制器参数应按结构分组：

```text
内环
外环
积分
前馈
滤波
约束
求解器
增强模块
控制分配
```

先单组调优，再进行小范围联合优化。

---

## 5.6 参数必须有稳定裕度

最终参数不是单点最优，而应在附近区域内保持稳定。

主要参数发生：

```text
±5%
```

变化时，系统仍应满足基本稳定和安全要求。

# 8. 调参基本术语

## 8.1 参数向量

[
\theta=
[\theta_1,\theta_2,\ldots,\theta_n]^T
]

表示当前需要优化的控制器参数。

---

## 8.2 候选参数

一次优化算法提出的参数组合称为：

```text
Candidate Parameter Set
```

---

## 8.3 Trial

使用一组候选参数运行一次指定场景，称为一个Trial。

---

## 8.4 Tuning Session

针对：

```text
一个控制器
+
一个机型
+
一个输出层级
+
一个控制周期
```

进行的完整调参过程称为Tuning Session。

---

## 8.5 Phase

一个调参会话分为多个阶段：

```text
SAFE_INIT
SENSITIVITY
COARSE
FINE
JOINT_REFINE
VALIDATION
ROBUST_MARGIN
FROZEN
```

---

## 8.6 工程最优

本文档中的“最优参数”定义为：

> 在冻结的机型、状态源、控制周期、轨迹集合、搜索空间和搜索预算内，满足全部硬约束，且综合目标函数最小并具有局部稳定裕度的参数集。

不声称获得数学意义上的全局最优。

# 9. 调参、验收和最终对比的区别

## 9.1 调参评价

用于搜索参数。

特点：

```text
测试场景少
运行时间短
可以高频反复执行
关注参数方向和综合目标
允许使用剪枝
```

---

## 9.2 参数验收

用于判断参数是否可以冻结。

特点：

```text
使用未参与优化的验证轨迹
重复运行
检查稳定裕度
检查参数扰动
检查输出平滑性
```

---

## 9.3 最终横向对比

全部控制器冻结后执行。

特点：

```text
统一场景
统一指标
统一随机种子
统一失败规则
不再修改参数
```

# 25. 优化问题定义

参数优化问题定义为：

[
\theta^\ast
===========

\arg\min_{\theta\in\Theta}
J(\theta)
]

满足：

[
g_i(\theta)\le0
]

其中：

```text
J：综合性能目标函数
g_i：安全和工程硬约束
Θ：允许参数空间
```

---

# 26. 硬约束与软目标分离

以下内容属于硬约束：

```text
不坠机
不发散
不出现NaN或Inf
不超过绝对安全倾角
不超过绝对推力限制
不出现长期执行器饱和
不出现持续控制周期超时
求解器不能连续失败
姿态不能进入不可恢复状态
```

硬约束失败时：

```text
Candidate = INVALID
```

不能只在目标函数中增加一个有限惩罚继续竞争最优。

# 29. 指标归一化

不同物理量不得直接相加。

每项指标使用目标值归一化：

[
\bar J_i=
\frac{J_i}{J_{i,target}}
]

对于超过上限的指标，可采用二次惩罚：

[
P_i=
\begin{cases}
0,&J_i\le J_{i,target}\
\left(
\frac{J_i-J_{i,target}}
{J_{i,target}}
\right)^2,
&J_i>J_{i,target}
\end{cases}
]

---

# 30. 位置误差目标

平滑轨迹的默认位置损失：

[
J_p=
0.6RMSE_p
+
0.25P95_p
+
0.15E_{p,max}
]

其中：

```text
RMSE反映整体表现
P95反映大部分峰值误差
最大误差用于防止短时严重偏离
```

---

# 31. 姿态误差目标

推荐使用几何姿态误差角：

[
e_R=
\cos^{-1}
\left(
\frac{\operatorname{tr}(R_d^TR)-1}{2}
\right)
]

姿态损失：

[
J_R=
0.7RMSE_R
+
0.3P95_R
]

---

# 32. 控制平滑性目标

建议包含：

[
TV(u)=
\sum_{k=2}^{N}
|u_k-u_{k-1}|
]

以及：

```text
推力RMS
力矩RMS
电机命令变化率
高频控制能量
```

---

# 33. 饱和目标

计算：

```text
总推力饱和率
单电机饱和率
倾角限幅率
角速度限幅率
控制变化率限幅率
```

短时合理饱和可作为软惩罚。

持续饱和应作为硬约束失败。

---

# 34. 计算性能目标

控制器运行频率为：

[
f_c
]

周期为：

[
T_s=\frac{1}{f_c}
]

建议：

```text
平均执行时间 ≤ 0.30Ts
P99执行时间 ≤ 0.70Ts
最大执行时间 < Ts
deadline miss = 0
```

# 52. 阶段C：敏感度分析

对参数：

[
\theta_i
]

计算局部敏感度：

[
S_i=
\frac{
J(\theta_i+\Delta\theta_i)
--------------------------

J(\theta_i-\Delta\theta_i)
}{
2\Delta\theta_i
}
]

用于识别：

```text
高敏感参数
低敏感参数
参数耦合
无效参数
```

# 60. 参数附近区域评分

可计算：

[
J_{robust}
==========

J(\theta)
+
\lambda
\frac{1}{M}
\sum_{i=1}^{M}
J(\theta+\Delta\theta_i)
]

避免选择非常尖锐的单点最优参数。

# 122. Agent禁止行为

```text

同时调多个未稳定控制环
绕过硬约束
```

# 148. 强制性规则

1. 调参前必须冻结飞行器、执行器、仿真和状态源Profile。

2. 一套参数必须绑定具体机型、控制频率和输出层级。

3. 所有优化必须从已知安全参数开始。

4. 算法错误不得通过调参掩盖。

5. 硬约束与性能目标必须分离。

6. 坠机、发散和NaN候选必须标记为无效。

7. 无效Trial不得从记录中删除。

8. 参数必须按控制环和功能分组调节。

9. 不得一次搜索所有控制器参数。

10. 串级控制器必须从内环向外环调节。

11. 保留PX4内环时，不得同时优化PX4内环和外部控制器。

12. 高阶前馈必须在基础反馈稳定后启用。

13. MPC/NMPC必须先保证模型、约束和求解器稳定。

14. INDI必须先校正时间、滤波和控制有效性。

15. L1必须在名义控制器冻结后单独调节。

16. AWFF必须先完成算法审计。

17. 组合Profile必须逐模块加入，不得整体随机搜索。

18. 调参集不得只包含8字。

19. 验证集不得参与参数搜索目标。

20. 调参过程中不得改变轨迹时间尺度。

21. 平滑轨迹可以使用2 cm和5 cm目标。

22. 阶跃轨迹不得使用5 cm最大误差作为判据。

23. 停止调参必须同时满足性能、收敛、验证和稳定裕度。

24. 未达到2 cm但进入性能平台期的控制器可以按结构极限验收。

25. 最终参数必须执行±5%稳定裕度测试。

26. 最优候选必须重复运行。

27. 所有Trial必须使用统一仿真时间。

28. 控制效果与wall执行时间必须分开评价。

29. MWORKS粗调参数必须在Gazebo中重新验证。

30. Gazebo冻结参数不得直接声明为真机最优参数。

31. 参数或机体Profile变化后必须重新验证。

32. 参数冻结后才能进入08文档规定的最终比较。

# 149. 文档结论

MoSim控制器调参不能采用：

```text
只调8字
只看RMSE
所有参数一次搜索
误差越小越好
仿真不稳定就降低轨迹速度
删除失败结果
从随机参数开始
一个控制器没调完就切下一个
```

正确流程应为：

```text
冻结飞行器和仿真配置
        ↓
建立安全初值
        ↓
按控制层级分阶段调参
        ↓
敏感度和粗搜索
        ↓
细搜索和联合微调
        ↓
验证未见轨迹
        ↓
检查参数附近稳定裕度
        ↓
重复运行
        ↓
冻结机型专属参数
```

最终，每个控制器都应得到：

```text
明确适用机型
明确控制频率
明确输出层级
明确参数来源
明确搜索过程
明确停止条件
明确验证结果
明确稳定裕度
```

从而使Agent不只是“把控制器调得能飞”，而是能够针对当前Sunray Gazebo四旋翼，系统地获得可解释、可复现、具有稳定裕度的工程最优参数。
