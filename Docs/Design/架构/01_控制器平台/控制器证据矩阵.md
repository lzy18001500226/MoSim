# MoSim控制器证据矩阵

> 状态：控制器可实现性与证据规划，2026-06-24。
>
> 本文回答“每类控制器是否覆盖全面、是否能在 Simulink/MWORKS 中建模、是否有
> 开源代码或资料、是否能进入 Gazebo/PX4 闭环”。本文不替代具体控制器卡片；
> 具体公式、参数和实现细节仍落在 `controllers/` 和 `modules/`。

## 1. 设计原则

控制器清单不能只停留在名字层面。任何控制器进入实施前，必须至少完成：

```text
1. 理论来源：论文、教材、官方示例或开源实现；
2. Simulink/MWORKS可实现路线：基础块、MATLAB Function、Sysblock函数块、
   S-Function、生成C/C++或外部C++ core；
3. Gazebo/PX4接入层级：ATTITUDE_THRUST、BODY_RATE_THRUST、WRENCH或ROTOR；
4. 实时性风险：是否能在100Hz或目标频率下运行；
5. 证据门禁：离线仿真、离线一致性、Gazebo闭环、指标和报告。
```

没有完成这些证据前，不得把控制器写成已实现、已测量或已验收。

## 2. 控制器证据等级

| 等级 | 含义 | 可声明内容 | 禁止声明 |
| --- | --- | --- | --- |
| E0 需求列入 | 只有需求和链路位置 | 已列入候选 | 可实现、可闭环 |
| E1 资料冻结 | 有论文、官方示例或开源代码 | 有参考依据 | 本项目已实现 |
| E2 模型可行 | 有 Simulink/MWORKS 建模路线或最小模型 | 可进入模型实现 | Gazebo闭环 |
| E3 Core可行 | 能抽成 C/C++ core 或生成代码 | 可进入离线一致性 | 可真机部署 |
| E4 Gazebo可行 | 通过统一Adapter闭环 | 可进入横向比较 | 已最终验收 |
| E5 验收冻结 | 有run_id、metrics、profile和审核结论 | 可作为基线/对比项 | 超出profile的泛化结论 |

## 3. 实施门禁

每个控制器按以下顺序推进：

```text
C0 参考冻结
  论文/公式/开源代码/Simulink资料确认

C1 模型侧实现
  MATLAB/Simulink 或 MWORKS/Sysblock 离线仿真

C2 Controller Core
  统一 IController / generated C ABI / C++ wrapper

C3 Gazebo闭环
  通过 ATTITUDE_THRUST Adapter 接 PX4/MAVROS/Gazebo

C4 指标和报告
  与 px4ctrl / PID / SE3 在同场景横向比较
```

若某控制器做不到 C1，不进入 Gazebo；做不到 C2，不声明真机化；做不到 C3，
只算模型仿真；做不到 C4，不进入正式排行榜。

## 4. 第一批和第二批功能规划

| 批次 | 控制器/模块 | 当前目标 | 证据要求 |
| --- | --- | --- | --- |
| 第一批模板 | px4ctrl、official PID、SE3 Basic | 证明 ATTITUDE_THRUST、Profile、Adapter 和 MWORKS Golden Slice 可复用 | E4/E5 |
| 第二批代表扩展 | LQI、DFBC、SMC、LMPC/NMPC | 覆盖线性积分、微分平坦、鲁棒滑模和优化控制 | E3/E4 |
| 鲁棒增强 | INDI、DOB/ESO、ADRC、L1、AWFF | 作为 augmentation，不掩盖基准控制问题 | E2/E3 |
| 智能复合 | Fuzzy PID、Fuzzy-SMC、RBF/NN、ANFIS | 作为调参、补偿或残差模块 | E1/E2 |
| 学习/研究 | ILC、RL residual、Learning MPC、Tube MPC、mu-synthesis | 先证明资料和模型路线，不承诺第一阶段闭环 | E1/E2 |

## 5. 控制器覆盖矩阵

| 类别 | 控制器/算法 | 链路位置 | Simulink/MWORKS路线 | Gazebo首选接口 | 第一阶段定位 |
| --- | --- | --- | --- | --- | --- |
| 基准 | 官方PID / Cascade PID | Nominal Controller | 基础块或Sysblock函数块 | ATTITUDE_THRUST | MUST |
| 工程基准 | px4ctrl | Nominal Controller | 先抽取C++ core，再MWORKS重建 | ATTITUDE_THRUST | MUST |
| 改进PID | PID+FF、Anti-windup、Gain Scheduling | Nominal Controller / Augmentation | 基础块、查表、限幅和状态机 | ATTITUDE_THRUST | MUST/SHOULD |
| 现代线性 | LQR、LQI、LQG | Nominal Controller | 线性化模型 + 状态反馈/观测器 | ATTITUDE_THRUST | SHOULD |
| 鲁棒线性 | H-infinity、mu-synthesis | Nominal Controller | 线性化模型 + 鲁棒控制设计 | ATTITUDE_THRUST | COULD/RESEARCH |
| 几何控制 | SO(3)、SE(3) | Nominal Controller | MATLAB Function / Sysblock函数块 | ATTITUDE_THRUST | MUST/SHOULD |
| 非线性控制 | Backstepping、NDI | Nominal Controller | MATLAB Function / Sysblock函数块 | ATTITUDE_THRUST | SHOULD/COULD |
| 滑模控制 | SMC、Integral SMC、Terminal SMC、Super-Twisting SMC | Nominal Controller | MATLAB Function + 边界层/饱和处理 | ATTITUDE_THRUST | SHOULD |
| 微分平坦 | DFBC Basic、DFBC jerk/snap | Nominal Controller | 轨迹高阶导数 + 姿态/推力生成 | ATTITUDE_THRUST，后续BODY_RATE | SHOULD |
| 优化控制 | LMPC、NMPC | Nominal Controller | MPC/NMPC模块或自定义求解器 | ATTITUDE_THRUST | SHOULD |
| 鲁棒MPC | Robust MPC、Adaptive MPC、Tube MPC | Nominal Controller / Safety | MPC扩展模型和约束 | ATTITUDE_THRUST | COULD/RESEARCH |
| 迭代学习 | ILC | Trajectory/Controller augmentation | 重复轨迹误差迭代更新 | ATTITUDE_THRUST | COULD |
| 扰动观测 | DOB、ESO、ADRC | Augmentation | 观测器模块 + 有界补偿 | 不直接发布，接入名义控制器 | SHOULD |
| 增量动态逆 | INDI | Augmentation / Inner-loop candidate | 加速度/角速度增量估计 | 后续BODY_RATE，第一阶段只规格化 | SHOULD |
| 自适应补偿 | L1、Adaptive Backstepping | Augmentation / Nominal | 低通滤波、自适应律、限幅 | ATTITUDE_THRUST | COULD |
| 前馈补偿 | AWFF、drag feedforward | Reference/Controller输入侧 | 风/阻力/加速度前馈 | ATTITUDE_THRUST | SHOULD |
| 智能控制 | Fuzzy PID、Fuzzy-SMC、ANFIS、RBF/NN补偿 | Augmentation / Nominal | Fuzzy/NN函数块或离线训练参数 | ATTITUDE_THRUST | COULD |
| 强化学习 | RL gain scheduler、RL residual policy | Augmentation / Research | Simulink RL或离线训练策略 | 不直接首飞，必须Safety包裹 | RESEARCH |
| 安全过滤 | CBF、Reference Governor、MPC Safety Filter | Safety | 约束检查/QP/参考过滤 | 发布前SafetySupervisor | COULD/SHOULD |
| 编队控制 | Leader-Follower、Virtual Structure、Consensus、Distributed MPC | Formation / Swarm | 编队参考生成和多机状态反馈 | 每机ATTITUDE_THRUST | SHOULD/COULD |

## 6. 参考来源最低要求

每个控制器卡片进入 E1 前，必须至少满足以下之一：

```text
官方示例:
  MathWorks / Simulink / MATLAB 示例，或同元/MWORKS官方资料。

开源代码:
  GitHub、MATLAB File Exchange、论文作者代码或可审计工程实现。

论文/教材:
  公式完整、状态定义和输入输出清晰，可复现到Simulink/MWORKS。
```

仅有博客介绍、截图或二手总结时，只能记为研究线索，不能记为 E1 资料冻结。

## 7. 参考资料种子清单

以下只作为首批资料种子，后续要在每个控制器卡片中写入固定版本、commit、
license和本项目采用范围。

| 对象 | 初始资料方向 |
| --- | --- |
| NMPC | MathWorks quadrotor nonlinear MPC 示例 |
| ILC | MathWorks quadrotor trajectory tracking ILC 示例 |
| SE(3) | `plusk01/se3quad`、FDCL geometric control 等开源实现 |
| Linear MPC | Quadrotor linear MPC Simulink/Pixhawk参考工程 |
| PID/SMC/Backstepping | MATLAB File Exchange 四旋翼控制方法示例 |
| INDI/L1/DOB/ESO/ADRC | 论文公式 + MATLAB/Simulink观测器实现 + 本项目限幅封装 |
| Fuzzy/ANFIS/RBF | MATLAB/Simulink智能控制模块或自定义函数块 |
| RL | Simulink RL 作为研究候选，不作为第一阶段飞行闭环主线 |

资料进入正式引用前，必须补齐：

```text
source_url
source_type
license
commit_or_version
used_for
not_used_for
local_patch
```
