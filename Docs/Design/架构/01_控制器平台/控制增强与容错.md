# 0. 当前批准的 Profile 边界

本文保留增强、诊断、容错和控制分配的通用理论与实现规范；当前比赛的 Profile
目录、组合合法性和运行状态以
`MWORKS控制器关系与组合架构.md` 为唯一权威。当前目录仍是 47 个 MWORKS Profile，
另有 1 条 `px4ctrl` 工程/部署基线；47 个 Profile 的源/Adapter/Runner 路由均已
登记，且当前目录 48 条都有对应对账记录。这里的“已实现”只表示源面和运行入口存在，
不表示性能门通过。

`PidAwffLinearEso` 的固定语义为：PID/AWFF 名义链后接一个线性 ESO 扰动估计和
有界补偿。它不叠加 L1 或学习残差，也不应被写成完整 ADRC。该 Profile 的项目源、
Adapter、`PidAwffLinearEsoFormalRunner` 和 50 s 运行记录均已存在；当前记录的终端
位置误差为 3412.36 m，因此它是“实现存在但性能门失败”，不是“未实现”或“未运行”。
目录中的 `planned/not_runnable` 只保留为冻结元数据兼容字段；后续选择资格仍须与
`PidAwff`、`PidAwffL1Residual` 在名义、风扰和参数失配下完成消融。

当前七场景中的风扰和电机效率下降仅是物理/场景注入；不启用 Battery Low、Geofence
Breach、GPS Dropout、Mission Failure、Offboard Loss、Fault Allocation 或主动容错
作为正式比赛场景。上述模块保留为理论/研究资产，只有依赖审计完成后才能从活动模型中
归档。`CBF` 同样仅保留为研究候选，等待真实约束场景和触发证据。

本节的文档批准不授权模型实现、MWORKS 仿真、代码生成或 Gazebo 运行。实际执行必须
先完成模型库原子迁移，再遵循当前主线看板和相应证据工作流。

历史看板记录了 G9 控制器族的 MWORKS/codegen 和 ROS/Sunray 回灌闭环证据；当时
计划仅重新打开以下最小 Gazebo 验证。该计划不授权当前 G1-G7 直接执行：

```text
L1/AWFF
Safety Filter
Fault Allocation
```

DOB/ESO、INDI、参数调度、NN/Fuzzy等现有探针和设计继续保留为backlog证据；
未获重新打开前不得写成正式ExperimentProfile，也不得宣称MWORKS/codegen或
Gazebo增强闭环完成。

G10第一轮覆盖以下增强类别。每个类别必须先说明作用位置、输入输出、兼容
控制器、禁用条件、失败模式和消融实验，不允许作为“另一个控制器按钮”直接
接入。

| G10项 | 模块类别 | 第一轮最低实现 | 主要验证 | 禁止声明 |
| --- | --- | --- | --- | --- |
| G10-A | DOB / ESO / ADRC | 至少一个平动扰动估计与有界补偿实现 | 风扰、质量误差、推力误差下的跟踪误差和补偿量消融 | 不得直接发布MAVROS命令；不得替代状态估计 |
| G10-B | L1 / AWFF | 至少一个风扰或气动阻力前馈/自适应补偿实现 | 同一轨迹下开关补偿对RMSE、峰值误差和控制抖动的影响 | 不得绕过SafetySupervisor；不得无低通/限幅 |
| G10-C | INDI标准增强 | 将G9-E从“控制器候选”整理成标准增强层Profile | 与PID/SE3/DFBC/NMPC组合的兼容性和消融 | 第一阶段不得宣称替代PX4姿态/角速度内环 |
| G10-D | Safety Filter | 推力、倾角、角速度、加速度、地理边界和障碍距离的发布前过滤 | 约束触发日志、拒绝/修正命令、回退策略 | 不得作为性能调参工具；不得静默修改命令 |
| G10-E | Fault Allocation | 推力衰减、电机失效和控制分配降级候选 | 故障注入下的可控性、降级模式和失败日志 | ATTITUDE_THRUST阶段不得宣称电机级容错完成 |
| G10-F | Parameter Scheduling | 质量、电池、推力系数或工况变化的参数调度 | 参数切换平滑性、稳定性和profile可追溯 | 不得在飞行中无门禁切换控制器或状态源 |
| G10-G | NN / Fuzzy Compensation | 有界残差或参数调节规格；第一轮可只做离线/候选 | 只验证补偿边界、接口和安全过滤兼容性 | 不得让NN/RL端到端替代安全关键闭环 |

历史 G10 完成后进入历史 G11。历史 G11 要求所有进入`implemented`或`accepted`的增强组合与
名义控制器一起完成MWORKS模型、生成C/C++、离线一致性、ROS/Sunray回灌和
Gazebo回归。若某个增强层不能代码生成，必须明确停留在`candidate`或
`research`，不得混入正式ExperimentProfile。

## 0.1 增强模块信号语义与安全权责

增强模块不是“另一个控制器按钮”，而是插在名义控制器、约束、安全和执行器
分配之间的可组合模块。当前信号语义冻结如下：

| 模块族 | 作用位置 | 典型输入 | 典型输出 | 不允许承担的职责 |
| --- | --- | --- | --- | --- |
| AWFF / drag feedforward | 名义控制器前馈项 | 参考速度、加速度、模型参数、风扰估计 | 前馈加速度/力补偿 | 不替代状态估计和安全限幅 |
| DOB / ESO / ADRC | 扰动观测与反馈补偿 | 状态误差、控制输入、模型输出 | 扰动估计或补偿项 | 不直接发布MAVROS命令 |
| L1 / adaptive | 鲁棒自适应补偿 | 跟踪误差、状态估计、低通滤波参数 | 有界补偿项 | 不绕过SafetySupervisor |
| INDI | 低层增量控制增强 | 角速度/角加速度、执行器响应、期望增量 | 增量角加速度/力矩/推力修正 | 第一阶段不替代PX4姿态/角速度内环 |
| CBF / safety filter | 发布前约束过滤 | 候选控制命令、障碍/边界/速度/姿态约束 | 通过、修正或拒绝命令 | 不作为性能调参工具 |
| Fault allocation | 控制分配和执行器层 | 故障程度、电机能力、候选总推力/力矩 | 分配后的电机级命令或降级策略 | 第一阶段不进入ATTITUDE_THRUST正式闭环 |

`SafetySupervisor`拥有命令发布前的最终否决权；PX4 failsafe拥有飞控侧最终
保护权。增强模块只能提出补偿或约束修正，不能绕过状态有效性、推力/姿态
限幅、解锁/模式门禁和PX4 failsafe。

# 4. 核心概念区分

## 4.1 名义控制器

名义控制器根据参考和状态计算理想模型下的控制命令。

例如：

```text
PID
SE3
DFBC
SMC
LMPC
NMPC
```

## 4.2 增强模块

增强模块在名义控制器基础上补偿：

```text
未建模动力学
外部扰动
参数不确定性
执行器动态
控制延迟
```

例如：

```text
DOB
ESO
INDI
L1
AWFF
```

## 4.3 故障诊断模块

故障诊断模块回答：

```text
是否发生故障
故障发生在哪里
故障类型是什么
故障程度是多少
估计结果有多可信
```

## 4.4 控制分配器

控制分配器将期望合力和力矩转换为各执行器命令。

## 4.5 容错控制器

容错控制器利用故障信息重新计算控制目标或改变控制结构。

## 4.6 安全过滤器

安全过滤器保证碰撞、飞行区域和状态约束。

安全过滤器不等同于故障容错模块。

# 6. 基本设计原则

## 6.1 增强模块不得冒充基础控制器

例如：

```text
SE3 + L1
```

应拆分为：

```text
SE3名义控制器
+
L1增强模块
```

不得建立一个无法分离的：

```text
se3_l1_controller
```

算法副本。

---

## 6.2 故障诊断与故障补偿分离

诊断模块输出：

```text
故障位置
故障类型
故障程度
置信度
```

补偿模块根据这些信息采取控制动作。

诊断模块不得直接修改电机命令。

---

## 6.3 控制分配与轨迹控制分离

轨迹控制器输出：

```text
总推力
三轴力矩
```

控制分配器输出：

```text
各执行器命令
```

只有明确以单电机推力为优化变量的控制器，才可以绕过独立控制分配层。

---

## 6.4 功能必须有唯一所有者

以下功能只能有一个主要所有者：

```text
重力补偿
气动补偿
积分抗饱和
扰动补偿
推力归一化
控制分配
执行器效率补偿
```

---

## 6.5 增强模块必须可关闭

所有增强模块必须支持：

```text
DISABLED
STANDBY
ACTIVE
DEGRADED
FAILED
```

以便进行消融实验和故障回退。

---

## 6.6 安全约束始终具有最终优先级

增强控制不能绕过：

```text
最终推力限制
力矩限制
单电机推力限制
变化率限制
状态安全限制
```

# 21. 模块排序约束

以下顺序通常不允许交换：

```text
控制分配
必须位于
```

# 42. INDI定位

INDI是基于测量增量和局部控制有效性的增量动态逆方法。

它不要求精确建模全部气动力，而是围绕上一工作点计算控制增量。

---

# 43. INDI通用形式

设受控输出导数为：

[
\dot y
======

f(x)+G(x)u
]

在当前工作点附近：

[
\dot y
\approx
\dot y_f
+
G_f
\left(
u-u_f
\right)
]

令期望虚拟控制量为：

[
\nu
]

则：

[
\Delta u
========

G_f^\dagger
\left(
\nu-\dot y_f
\right)
]

[
u=u_f+\Delta u
]

其中：

```text
u_f：滤波后的上一控制输入
dot y_f：滤波后的当前响应
G_f：当前控制有效性矩阵
```

---

# 44. INDI关键要求

INDI必须保证：

```text
测量响应与执行器状态时间对齐
响应和控制输入使用匹配滤波器
控制有效性矩阵正确
执行器延迟得到处理
控制增量受到限幅
```

---

# 74. 故障模型

执行器故障统一表示为：

[
f_{actual}
==========

\Lambda f_{cmd}
+
b_f
+
d_f
]

其中：

```text
Λ：执行器效率矩阵
b_f：故障偏置
d_f：未建模故障项
```

---

# 75. 效率矩阵

对于四旋翼：

[
\Lambda =
diag(
\lambda_1,
\lambda_2,
\lambda_3,
\lambda_4
)
]

其中：

```text
λ_i = 1：正常
0 < λ_i < 1：部分效率下降
λ_i = 0：完全失效
```

---

# 76. 故障类型

## 76.1 效率下降

[
f_i=\lambda_i f_{i,c}
]

## 76.2 偏置

[
f_i=f_{i,c}+b_i
]

## 76.3 卡死

[
f_i(t)=f_i(t_f)
]

或固定在指定值。

## 76.4 响应变慢

执行器时间常数增大。

## 76.5 间歇故障

正常和故障状态随时间切换。

## 76.6 完全失效

[
f_i=0
]

缺点：

# 105. 控制分配数学模型

设期望控制广义力为：

[
w_d=
\begin{bmatrix}
T_d\
\tau_{x,d}\
\tau_{y,d}\
\tau_{z,d}
\end{bmatrix}
]

执行器推力向量为：

[
f=
\begin{bmatrix}
f_1&f_2&\cdots&f_n
\end{bmatrix}^T
]

控制有效性矩阵：

[
w=Gf
]

---

# 106. 标准四旋翼分配

对于固定桨距四旋翼，矩阵由：

```text
电机位置
推力方向
反扭矩方向
推力系数
```

确定。

禁止控制分配器硬编码电机编号对应的空间位置。

---

# 107. 直接逆分配

当：

[
G
]

为方阵且满秩时：

[
f=G^{-1}w_d
]

适合作为理论和名义基线。

它不直接处理：

```text
推力上下限
推力变化率
故障
冗余执行器
```

---

# 108. 伪逆分配

[
f=G^\dagger w_d
]

适合：

```text
冗余执行器
超定或欠定系统
基础故障重构
```

仍需后续限幅处理。

---

# 109. 加权最小二乘分配

求解：

[
\min_f
|
W_w(Gf-w_d)
|^2
+
|
W_f(f-f_{ref})
|^2
]

其中：

```text
W_w：控制通道优先级
W_f：执行器使用代价
```

---

# 110. QP控制分配

标准形式：

[
\min_f
\frac{1}{2}
f^THf+c^Tf
]

约束：

[
f_{min}\le f\le f_{max}
]

[
\Delta f_{min}
\le
f-f_{prev}
\le
\Delta f_{max}
]

并可以加入：

```text
跟踪误差松弛
电机效率
功率限制
故障电机固定约束
```

---

# 111. 分配优先级

默认推荐：

```text
Roll/Pitch稳定
>
总推力
>
Yaw
```

具体顺序可按任务调整，但必须记录。

# 112. 分层分配

可以依次实现：

```text
第一层：Roll/Pitch
第二层：总推力
第三层：Yaw
第四层：能耗与平滑性
```

低优先级不能破坏高优先级已经达到的结果。

# 113. 故障感知分配

故障后：

[
G_f=G\Lambda
]

同时约束：

[
0\le f_i\le f_{i,max}^{available}
]

对于完全失效电机：

[
f_i=0
]

```text
暂不完全移除
```

# 129. 故障恢复

并非所有故障都允许自动恢复到NORMAL。

例如：

```text

```

可以恢复。

但：

```text
电机完全失效
结构损伤
```

通常应保持锁定状态，直到地面检查或明确复位。

```text
切换被动容错模式
降低速度和轨迹强度
```

不得把未知状态默认为全部正常。

# 186. 强制性规则

1. 名义控制器、增强模块、故障诊断器和控制分配器必须分离。

2. 每项补偿功能必须具有唯一所有者。

3. 所有增强模块必须可单独关闭并支持消融实验。

4. 增强模块必须声明输入和输出控制层级。

5. 参考加速度不包含重力，重力补偿不得重复。

6. 显式气动模型和扰动估计必须明确分工。

7. INDI必须保证响应测量和执行器信号时间、滤波一致。

8. 无真实RPM时必须明确使用估计或模型反馈。

9. L1自适应补偿必须经过低通滤波和参数投影。

10. L1、DOB、ESO等组合必须说明频带和补偿对象。

11. AWFF未完成算法审计前不得随意定义其含义。

12. 故障注入必须位于正确物理层级。

13. 故障检测、隔离和程度估计必须分层输出。

14. 主动容错不得仅依据一次阈值触发永久重构。

15. 故障估计必须包含置信度和有效期。

16. 控制分配必须使用执行器几何和效率矩阵。

17. 故障后必须重新计算可用控制能力。

18. 分配器必须输出期望与实际Wrench差异。

19. 分配残差必须反馈给Anti-Windup和控制能力管理。

20. 单电机推力NMPC不得再次经过普通控制分配。

21. 控制分配失败必须具有降级求解器和最终安全策略。

22. 增强模块失效时应优先保留名义控制器。

23. 故障诊断失效时不得默认所有执行器正常。

24. 故障后必须向规划器反馈降低后的动力学能力。

25. 安全约束优先级高于轨迹跟踪和Yaw控制。

26. 现有完整系统模型必须拆分为原子模块和Profile。

27. 所有生成代码必须无动态内存并支持多实例。

28. 所有模块必须经过统一Test Harness。

29. 未通过故障闭环验证的模块不得标记为容错完成。

30. 未通过板载实时性验证的模块不得标记为PX4板载支持。

# 187. 文档结论

MoSim控制增强与容错体系不能采用：

```text
每一个完整组合建立一个独立工程
INDI、L1和AWFF写死在基础控制器中
故障诊断和电机分配混在一个黑盒中
故障后只修改PID增益
控制分配只做简单限幅
```

正确结构应为：

```text
名义控制器
      ↓
可组合的增强模块
      ↓
扰动与执行器状态估计
      ↓
故障检测和隔离
      ↓
控制能力评估
      ↓
主动或被动容错控制
      ↓
故障感知控制分配
      ↓
降级任务与安全控制
```

最终使：

```text
PID
SE3
DFBC
LMPC
NMPC
```

能够按需与：

```text
DOB
ESO
INDI
L1
AWFF
故障诊断
故障程度估计
QP控制分配
降级控制
```

组合，而不复制算法代码、不混淆控制层级，也不绕过统一接口、安全管理和测试体系。

由此，MoSim能够形成从：

```text
扰动产生
→
状态响应
→
扰动估计
→
故障检测
→
故障隔离
→
程度估计
→
控制重构
→
执行器重分配
→
安全降级
```

的完整四旋翼鲁棒控制与故障容错闭环。
