# L1

Status: BACKLOG / augmentation module.

Layer: adaptive disturbance/model-uncertainty compensation.

Inputs: tracking error, reference, model estimate, filtered adaptation state,
bandwidth parameters, dt, reset.

Outputs: bounded compensation term or corrected reference/control command.

PX4 dependency: depends on host controller; first release should be a bounded
outer-loop augmentation.

MWORKS/codegen route: fixed adaptation law -> filter and bounds -> generated
C/C++ -> A/B tests under parameter mismatch.

Gazebo/Sunray validation: wind, load and plant-parameter perturbation cases.

Forbidden claims: L1 evidence must state its host controller and cannot be
reported as a standalone controller result.

Current reopen gate: use a single host controller selected by the board, keep
the same Sunray/Gazebo/PX4/MAVROS runtime baseline, and compare L1 off/on in
one minimal disturbance or parameter-mismatch case before any broader matrix.
The run packet must record host controller, adaptation law, filter bandwidth,
compensation bounds, reset condition, safety filter interaction, and the
no-L1 baseline directory. Passing this gate means "candidate L1 contribution
observed"; it does not mean standalone controller acceptance or MWORKS/codegen
promotion.
