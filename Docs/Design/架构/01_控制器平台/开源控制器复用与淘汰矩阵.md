# 开源控制器复用与淘汰矩阵

> 状态：G4来源冻结，2026-07-16。
>
> 本文记录可复用上游、固定commit、许可证和在MoSim中的用途。GitHub star只用于
> 发现候选，不是算法或工程质量证明。正式派生时必须保留许可证、来源commit和
> 数学映射；没有明确许可证的仓库不得复制源码或模型。

机器清单：`Config/control_platform/upstream_sources.json`。

## 1. 复用方式

```text
上游实现
  -> 许可证和commit审计
  -> 隔离数学核心
  -> golden vectors
  -> MoSim类型化接口
  -> MWORKS图形化等价模型
  -> generated C一致性
  -> Factory运行验收
```

不直接搬运ROS节点、launch、UI、plant或状态估计。MoSim只复用可解释的数学核心、
测试向量、参数设计方法和成熟的生命周期/插件结构。

## 3. 禁止直接复制的候选

| 上游 | 原因 | 允许用途 |
| --- | --- | --- |
| `uzh-rpg/rpg_quadrotor_control` | GitHub API无可确认SPDX许可证 | 公开论文、接口思想和行为对照 |
| `SihaoSun/INDI_Quadrotor_FTC` | 仓库无明确许可证 | 论文公式与实验设计对照 |
| `bhavanarao3/...backstepping...` | 仓库无明确许可证 | 公开页面和论文线索 |
| `oussama-sadki/...Backstepping...` | 仓库无明确许可证 | 公开页面和论文线索 |
| GPL INDI/FTC候选 | GPL-2.0/3.0会改变派生分发边界 | 只作算法和实验参考，除非后续单独批准GPL隔离路线 |

“无许可证”不代表算法不可实现；它只表示必须依据论文和项目自有推导重新实现，
不能复制仓库内容。

## 4. 实施波次

```text
Wave A
  LQR/LQI family
  SO(3) attitude inner loop
  Backstepping baseline

Wave B
  H-infinity
  SMC boundary-layer baseline
  SMC strategy variants
  Tube/robust MPC

Wave C
  INDI / DOB-ESO / L1 / ADRC
  safety filter / CBF / reference governor

Wave D
  formation reference generation
  fault detection and allocation

Wave E
  bounded neural residual and parameter scheduling
```

LQR与LQI共用一个核心，通过是否启用积分状态和不同ParameterSet形成两个Profile。
SO(3)属于姿态/角速度内环，不得伪装成`ATTITUDE_THRUST`名义外环。Backstepping
先做确定性固定尺寸基线，不一次引入自适应、终端滑模和神经估计全部变体。
Wave B当前只落地非自适应边界层SMC基线；它使用固定尺寸的滑模面、线性项和
饱和边界层，不能代表终端滑模、超螺旋或自适应SMC，也不能替代MWORKS/MIL、
生成C或Gazebo验收。对应离线门禁为
`Results/control_platform/g5_wave_b_smc_20260716/G5_WAVE_B_SMC_GATE.json`。

H∞候选按上游固定commit在MATLAB中复现悬停点综合，再冻结为固定尺寸C增益核心。
上游原生输出是总推力与三轴力矩，因此登记为`WRENCH`且`selectable=false`；在
WRENCH safety、控制分配器和后端适配器存在前，不映射或伪装为
`ATTITUDE_THRUST`。离线门禁为
`Results/control_platform/g5_wave_b_hinf_20260716/G5_WAVE_B_HINF_GATE.json`。

Tube MPC候选依赖CasADi/IPOPT、MPT3和YALMIP，本机均未安装；其在线优化、MRPI
集合计算和仿真脚本也未隔离成固定尺寸step核心。按止损规则2和3退出当前Wave，
不安装大型求解栈或编写替代求解器来制造通过。结构化审计位于
`Results/control_platform/g5_wave_b_tube_mpc_audit_20260716/G5_WAVE_B_TUBE_MPC_AUDIT.json`。

Wave C优先复用项目现有成熟资产：PID-INDI固定核心与generated-C对照通过，
DOB-ESO固定核心静态门禁通过；L1-inspired残差补偿保留已有MWORKS A/B证据，但
尚未抽取为类型化增强模块。现有DOB/ESO不包含完整ADRC的全部结构，因此不新增
“完整ADRC已实现”声明。汇总证据为
`Results/control_platform/g5_wave_c_20260716/G5_WAVE_C_SUMMARY.json`。

## 5. 止损规则

候选满足以下任一条件时退出当前波次：

1. 无法确认许可证且论文不足以独立重建；
2. 必须引入不受控商业求解器或大型运行栈；
3. 无法隔离固定尺寸、无动态分配的确定性step核心；
4. 三次相同门禁失败且没有新的可证伪诊断；
5. 只能通过改变状态源、plant或评价口径才能显得优于基线；
6. 与现有家族数学能力重复，不能形成独立Profile、消融或报告价值。

退出只终止实施，不删除来源、失败证据和原因。
