# Operator Guides

This directory owns step-by-step human operator guides that begin with a clean
project state and end with explicit observation, stop, and evidence steps.

Guides do not own runtime contracts, technical evidence rules, or project
architecture. Those stay in the matching `Docs/Workflows/`, `Docs/Design/`, and
`Results/` owners.
