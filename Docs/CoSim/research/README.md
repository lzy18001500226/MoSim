# CoSim Research

Status: rebuild draft, 2026-06-14.

Research is split into two layers:

| Layer | Purpose |
|---|---|
| `*.md` in this directory | Decision-oriented summaries written with a common template. |
| `raw/` | Original long-form research notes preserved for trace-back. |

Architecture documents should cite the reviewed decision docs in this directory
first. Raw files are used only when a conclusion needs trace-back, correction,
or deeper review.
