## Skill 简要介绍（模型开发调试类）

### 一、简要概述

| 字段 | 内容 |
|------|------|
| **Skill 名称** | `ty-sysblock-diagram-modeling` |
| **Skill 中文名称** | Sysblock 框图建模 |
| **Skill 描述** | 用于在 Sysplorer 中基于 `SysplorerEmbeddedCoder` 执行 Sysblock 控制框图模型的新建、修复、参数整定、仿真验证与结果复核。 |
| **版本信息** | `V1.0.0` |
| **Skill 类型** | 模型开发调试（Model Development & Debugging） |

---

### 二、触发条件

- 当 `ty-sysplorer-modeling-rules` 已将任务分流到 Sysblock 路径时触发。
- 适用于新建 Sysblock 控制系统框图、修复已有 Sysblock 模型、参数整定和仿真验证。
- 适用于信号源、数学运算、连续/离散系统、逻辑运算、观测器和嵌入式控制框图任务。
- 不适用于 Modelica 物理建模、FMU、HDL / Verilog 生成或纯 API 查询。

---

### 三、核心功能

- 支持通过 `call_code(mode="run_script")` 和官方 Sysplorer API 创建、编辑、连线和参数化 Sysblock 模型。
- 支持 `NewModel(name, "Sysblock")`、`AddComponent`、`ConnectPort`、`SetModelParamValue` 等建模动作。
- 支持最小可运行控制闭环构建，以及稳态值、上升时间、超调、调节时间等指标验证。
- 支持排查端口、参数、组件路径、仿真设置和结果读取问题。

---

### 四、适用场景

- 搭建 Sysblock PI / PID 控制器、传递函数系统、嵌入式控制框图或基础控制回路。
- 修复 Sysblock 模型的组件路径、端口连线、参数设置或仿真配置异常。
- 验证控制系统响应曲线和用户指定的性能指标。
- 输出模型名/路径、仿真参数、关键变量、验证表和风险说明。
