# 交付验收清单

本文档定义 Sysblock 建模任务的交付验收标准。

## 1. 模型交付检查

### 1.1 模型文件

| 检查项 | 要求 | 状态 |
|--------|------|------|
| 模型文件存在 | .mo 文件已保存到指定目录 | □ |
| 文件名规范 | 使用有意义的名称，无空格 | □ |
| 模型类型正确 | restriction="Sysblock" | □ |
| 模型可打开 | OpenModel 成功 | □ |

### 1.2 组件完整性

| 检查项 | 要求 | 状态 |
|--------|------|------|
| 信号源 | 至少包含一个输入源 (Step/Constant/Ramp) | □ |
| 控制器 | 包含 PI/PID 控制器组件 | □ |
| 被控对象 | 包含 TransferFcn/StateSpace 等 | □ |
| 观测器 | 包含 Scope/Display | □ |

### 1.3 连接完整性

| 检查项 | 要求 | 状态 |
|--------|------|------|
| 无孤立组件 | 所有组件都有连接 | □ |
| 反馈回路 | 闭环控制系统有反馈连接 | □ |
| 端口匹配 | 连接的端口类型兼容 | □ |

### 1.4 参数设置

| 检查项 | 要求 | 状态 |
|--------|------|------|
| 控制器参数 | Kp, Ki, Kd 已设置 | □ |
| 被控对象参数 | 传递函数系数已设置 | □ |
| 仿真参数 | StopTime, Interval 已设置 | □ |

## 3. 仿真验证

### 3.1 仿真成功

| 检查项 | 要求 | 状态 |
|--------|------|------|
| SimulateModel 成功 | 返回 True | □ |

|--------|------|------|

| 数据点数量 | > 10 个数据点 | □ |
| 曲线可绘制 | CreatePlot 成功 | □ |

## 4. 性能验证 (控制系统)

### 4.1 稳态性能

| 检查项 | 要求 | 实际值 | 状态 |
|--------|------|--------|------|
| 稳态值 | 接近给定值 |  | □ |
| 稳态误差 | < 1% |  | □ |
| 无静差 | 积分环节正常工作 |  | □ |

### 4.2 动态性能

| 检查项 | 要求 | 实际值 | 状态 |
|--------|------|--------|------|
| 上升时间 | 满足要求 |  | □ |
| 超调量 | < 10% (如有要求) |  | □ |
| 调节时间 | 满足要求 |  | □ |
| 响应曲线 | 无振荡/发散 |  | □ |

### 4.3 计算公式

```
稳态误差 = |设定值 - 稳态值| / 设定值 × 100%
上升时间 = t(90%) - t(10%)
超调量 = (峰值 - 稳态值) / 稳态值 × 100%
调节时间 = 首次进入并保持在误差带内的时间
```

## 6. 质量门槛

以下条件**必须全部满足**才能声称任务完成：

1. [ ] 模型文件已保存
2. [ ] CheckModel 成功
3. [ ] SimulateModel 成功
4. [ ] 至少获取了一个变量的仿真结果
5. [ ] 输出了性能指标验证结果
