## Skill 简要介绍

| 字段 | 内容 |
|------|------|
| **Skill 名称** | `ty-design-opt-mpe-modeling` |
| **中文名称** | DesignOpt 与 MPE 参数设计估计 |
| **描述** | 参数设计、参数估计（MPE）、优化类任务的工作顺序、脚本要点与排错；与 `session_manager`、`call_code`、语料检索配合。 |
| **版本** | `v1.0.0` |

### 触发条件

- 用户提到参数估计、标定、MPE、DesignOptMpe、参数优化、实验设计与优化脚本等。  
- 需要在 `run_script` 中 `import` DesignOptMpe 并调用其 API（**不要**用 `get_api_document` 代替模块文档）。  

### 快速开始

1. 确保 Sysplorer 会话就绪：`session_manager(action="health" | "ensure")`。  
2. 用 **`resources_retrieval`** 检索语料 **`design_opt_mpe_api`**（`action="search"`，`sources` 含该语料 id），结合 `references/` 下副本阅读流程与接口。  
3. 通过 **`call_code`**（`mode="run_script"`）执行脚本；根据返回的 stdout/stderr 迭代。  

### 注意事项

- DesignOptMpe **不在**主 ModelingPy `Help()` 路径内；以语料与 `ListFunctions()` / `help()` 为准。  
- 遵守全局禁令：**禁止** `ClearAll`、`ChangeDirectory`；卸载用 `model_manager` 的 `unload`。
