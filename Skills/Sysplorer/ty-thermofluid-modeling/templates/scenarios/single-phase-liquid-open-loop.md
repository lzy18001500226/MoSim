# 液体单相开环主回路模板

## 适用场景

- 水、油、乙二醇等液体单相主回路。
- 需要先做最小可运行骨架，再逐步闭环。

## 默认拓扑

`入口边界 -> 泵或驱动件 -> 主管段 -> 阀或测试段 -> 受热段/冷却段/负载 -> 出口边界`

## 必配要素

- 入口边界
- 出口边界
- 主驱动件
- 至少一段主管段
- 至少一组关键传感器

## 默认验证量

- 入口压力
- 出口压力
- 质量流量
- 主段前后温度

## 建模提示

- 需要分布效应时，优先使用离散管道。
- 闭环改造前，先在开环状态完成 `check` 和一次有效仿真。
