# 输出约定

本文件用于统一热流体建模任务的最终交付结构。

## 最低输出字段

1. 任务类型
2. 系统或模型对象
3. 实际采用的库
4. 实际采用的介质与关键假设
5. 关键组件映射与连接说明
6. 关键参数与默认值来源
7. 已执行动作及其真实结果
8. 已验证变量与结果解释
9. 未闭环问题、风险与下一步建议
10. 若交付为模型库：顶层包名与已绑定依赖库

## 推荐输出模板

```markdown
## 本次任务

- 任务类型：
- 对象：
- 目标：

## 建模与修复决策

- 使用库：
- 使用介质：
- 关键假设：
- 关键组件与连接：

## 实际执行情况

- 已执行：
- 执行结果：
- 结果文件或变量状态：

## 模型库依赖

- 顶层包名：
- 已绑定依赖库：
- 依赖版本：
- 是否已补 `package.mo / package.order`：

## 关键结果验证

- 已验证变量：
- 判据：
- 结果解释：

## 当前结论

- 已完成：
- 未闭环问题：
- 下一步建议：
```

## 表述要求

- 用“已执行”与“已验证”区分动作和结果，不混用。
- 未实际执行的动作不要写成已完成。
- 若使用经验默认值或临时假设，必须显式标注。
- 若交付物是模型库而不是单个文件，必须明确说明依赖库是否已绑定，而不是只写“本机可运行”。
