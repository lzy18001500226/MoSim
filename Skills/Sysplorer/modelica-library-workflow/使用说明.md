## Skill 简要介绍（模型开发调试类）

### 一、简要概述

| 字段 | 内容 |
|------|------|
| **Skill 名称** | `modelica-library-workflow` |
| **Skill 中文名称** | Modelica 模型库与模型工作流 |
| **Skill 描述** | 用于在已应用 `ty-sysplorer-modeling-rules` 后，对 Modelica 模型库或模型执行新建、修复、扩充、规范化、审查、本地化与交付整理。 |
| **版本信息** | `V1.0.0` |
| **Skill 类型** | 模型开发调试（Model Development & Debugging） |

---

### 二、触发条件

- 当用户明确要求创建、修复、扩展、规范化、审查、本地化或交付 Modelica 模型库 / 模型时触发。
- 适用于包结构规范化、`Examples` / `Tests` 补齐、图形修复、中文化、本地化和交付准备。
- 适用于用户提供 `TYComponentsTemplate`、同类模板、已有骨架或顶层 package 目录的任务。
- 本 Skill 默认在已经应用 `ty-sysplorer-modeling-rules` 之后作为工作流补充层使用。

---

### 三、核心功能

- 支持顶层包结构设计、业务包划分、公共层归位和 `package.order` 维护。
- 支持从模板建库、扩展已有库、评审已有库、规范化结构、中文本地化和图解注解修复。
- 支持 `Interfaces`、`Utilities`、`Sources`、`Sensors` 等共享层整理。
- 支持 `Examples` 与 `Tests` 的分离组织和交付前自检。

---

### 四、适用场景

- 基于模板或已有骨架搭建 Modelica 模型库。
- 修复或规范化已有 Modelica 库的包结构、示例、测试或图面。
- 对模型库做中文化、本地化、审查或交付整理。
- 将零散模型整理成可复用、可加载、可验证的库结构。
