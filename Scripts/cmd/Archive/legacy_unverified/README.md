# Archived Windows Entrypoints

These wrappers were moved out of `Scripts/cmd/` during the C99 baseline
cleanup. They are retained unchanged for historical trace-back only.

They are not supported startup paths and must not be used to claim that FUEL,
Diff-Planner, three-UAV formation, Factory calibration, generic Gazebo startup,
or MWORKS G8 has passed in the current source-local runtime. Their original
scripts, result bundles, and active workflows must be audited before any route
is promoted back to `Scripts/cmd/`.

For the current supported Windows entrypoints, see `../../README.md`.
