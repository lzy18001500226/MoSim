# MoSim 评委运行说明

本说明对应本目录下的交付副本：

```text
C:\Users\HP\Desktop\MoSim\MoSim\
```

模型根目录必须保持为：

```text
MoSim\Models\
  QuadrotorModel\package.mo
  MoSimQuadrotorModel\package.mo
  QuadrotorExperiments\package.mo
  QuadrotorControllerBlocks\package.mo
```

`QuadrotorModel` 不能只复制其中的 STL 文件。它包含四旋翼机体、执行器、传感器、
控制器基础类和三维动画资源；缺少它时，模型检查会因找不到
`QuadrotorModel.*` 类而失败。当前交付副本中的该目录包含 `package.mo` 和全部
`Resources`，与本机参考副本的 19 个文件一致。

## 1. 一次性加载方式

1. 在 Sysplorer / MWORKS 的用户模型路径中添加：
   `C:\Users\HP\Desktop\MoSim\MoSim\Models\`。
   这里必须是四个 package 根目录的共同父目录，不能只指向某一个子目录。
2. 在一个新的 Sysplorer 会话中，先加载：
   `C:\Users\HP\Desktop\MoSim\MoSim\Models\QuadrotorModel\package.mo`。
3. 再加载：
   `C:\Users\HP\Desktop\MoSim\MoSim\Models\MoSimQuadrotorModel\package.mo`。
4. 库树出现 `MoSimQuadrotorModel` 后，只从它下面选择本说明列出的完整模型。
   不需要逐个打开各个 `.mo` 文件。

若第二步后提示找不到 `QuadrotorExperiments` 或 `QuadrotorControllerBlocks`，先确认
用户模型路径仍是上面的 `Models` 父目录；仍不能自动解析时，只加载错误信息点名的
同级 `package.mo` 一次，然后重新加载 `MoSimQuadrotorModel\package.mo`。不要把
`QuadChassis`、控制器块或某个子文件当作独立实验运行。

## 2. 本机已验证、可交给评委的完整模型

下列三项都直接位于截图中已经展开的：
`MoSimQuadrotorModel -> Baseline`。它们是本次在当前交付副本中已经确认可以
Check Model、仿真并查看三维飞行动画的入口，也是本次交给评委的全部运行清单。

| 库树位置 | 完整类名 | 演示内容 | 默认时长 |
|---|---|---|---:|
| `Baseline -> OfficialExample1` | `MoSimQuadrotorModel.Baseline.OfficialExample1` | 单机阶跃爬升 | 50 s |
| `Baseline -> OfficialExample2` | `MoSimQuadrotorModel.Baseline.OfficialExample2` | 单机螺旋爬升 | 50 s |
| `Baseline -> OfficialExample3` | `MoSimQuadrotorModel.Baseline.OfficialExample3` | 单机 8 字轨迹 | 120 s |

`Missions`、`Controllers`、`Robustness`、`Planning`、`Formation` 下的项目模型
在这份历史交付副本中仍有旧式控制器加载依赖，未纳入本次已验证运行清单。不要把
它们写成评委可以直接运行的演示，也不要因为库树图标显示为绿色而作此承诺。

## 3. 每个模型的运行步骤

1. 在库树中打开上表中的一个完整模型。
2. 先点击 **Check Model**。
3. 只有 Check Model 通过后，点击 **Simulate**。
4. 仿真完成后，从本次仿真生成的结果窗口打开三维动画并播放。
5. 只有当前结果窗口中的无人机实际运动，才可记为本机验证通过。

模型结构图、单独的 `QuadChassis`、控制器内部模块、静态 STL、旧的 `Result.msr` 或
已经打开的旧动画都不能替代本次 Check Model 和 Simulate。

## 4. 不要作为独立飞行演示运行的项目

以下树项是组件、结构图、诊断模型或兼容入口，不是给评委直接点击仿真的完整任务：

- `Baseline -> OfficialQuadChassis`
- `Dynamics`、`Parameters`、`Missions`、`Controllers`、`Robustness`
- `Planning`、`Formation`、`System`、`ExperimentRunner`、`Support`
- `SceneTrace`、`LegacyCompatibility`
- `QuadrotorExperiments` 下的兼容别名、控制器块和单独的 `OpenBlocksLinearMPCVehicle`

它们可以被完整模型引用，但不是首选演示入口。

## 5. 本机交付前确认

在交给评委前，用**本目录**而非重构后的 `C:\Users\HP\Desktop\MoSim\Models\` 完成
下列确认：

```text
[x] OfficialExample1：Check Model 通过，完成一次仿真，三维动画可播放
[x] OfficialExample2：Check Model 通过，完成一次仿真，三维动画可播放
[x] OfficialExample3：Check Model 通过，完成一次仿真，三维动画可播放
```

若出现错误，先记录第一个报错并停止切换模型。常见的根因与处理顺序如下：

1. `QuadrotorModel` 找不到：检查目录是否恰好为
   `MoSim\Models\QuadrotorModel\package.mo`，并确认用户模型路径指向 `Models`。
2. `QuadrotorExperiments` 或 `QuadrotorControllerBlocks` 找不到：不要复制单个 `.mo`；
   重新确认这两个同级目录仍在 `MoSim\Models\` 下。
3. `Modelica` 版本不兼容：本模型声明使用 `Modelica 4.0.0.TY.1`，需要在兼容的
   Sysplorer / MWORKS 安装环境中加载。
4. 项目任务模型提示找不到 AWFF、INDI、L1 或 LinearMPC 控制器类型：该历史副本
   不是本次交付的已验证演示范围；不要用它替代上面的三个 Baseline 模型。

本说明只说明本地交付副本的加载顺序和应审查的完整模型入口；一次实际运行是否通过，
以该机器上该模型的 Check Model、Simulate 和当前三维动画结果为准。
