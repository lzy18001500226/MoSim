函数说明¶

  • handle charaCreate ( string name, string filename, float scale, string fieldPath )

描述：创建人物。用人物模型文件.fxske文件（读取文件一般在项目文件主目录，即和.peproj一个目录中），创建一个模型，设置人物模型大小scale，路径是指读取到.fxske文件后，将模型存入项目（模型管理）中的路径，是下面其它人物函数的使用基础(另外可以根据需求开启模型碰撞)。

name [in] 创建人物的名字，字符串

filename [in] .fxske文件名

scale [in] 大小

fieldPath [in] 存放至项目中的路径

return

示例1：    h2 = charaCreate("h2", "worker0328_2.fxske", 0.01, "/scene/modules/main/model/QT.vis/人物组/人物/Character");                        ''''加载一个人物模型
示例2：    charaCreate("h2", "worker0328_2.fxske", 0.01, "/scene/model");                  ''''创建一个人物模型

  • void charaDelete ( handle h )

描述：删除人物。

h [in] handle，人物

示例：
handle h2;
h2 = charaCreate("h2", "worker0328_2.fxske", 0.01, "/scene/model");                     ''''注意这里string和handle区别
charaDelete(h2);

  • void charaMoveTo ( handle h, float time, float x, float y, float z )

描述：人物向x，y，z方向移动多少距离（时间设置运行起来影响不明显，可能是电脑原因）。

h [in] handle，人物

time [in] 浮点，时间

x [in] 浮点，x坐标

y [in] 浮点，y坐标

z [in] 浮点，z坐标

示例1：charaMoveTo(handle_h2,  100, 10, 0, 0);
示例2：charaMoveTo(h2, 100,-19.28636, -0.16198, -1.23177);

  • void charaMoveTo ( handle h, float x, float y, float z )

描述：人物向x，y，z方向移动多少距离。

h [in] handle，人物

x [in] 浮点，x坐标

y [in] 浮点，y坐标

z [in] 浮点，z坐标

示例：charaMoveTo(handle_h2, 10, 0, 0);

  • void charaMoveTo ( string name, float time, float x, float y, float z )

描述：人物向x，y，z方向移动多少距离。

name [in] 字符串，人物

time [in] 浮点，时间

x [in] 浮点，x坐标

y [in] 浮点，y坐标

z [in] 浮点，z坐标

示例：
charaCreate("h2", "worker0328_2.fxske", 0.01, "/scene/model/Character");
charaMoveTo("h2", 100, 10, 0, 0);

  • handle charaGetHandle ( string name )

描述：通过名称获取人物handle。

name [in] 字符串，人物

return handle，人物

示例：
charaCreate("h3", "worker0328_2.fxske", 0.01, "/scene/model/Character3");
handle_h3 = charaGetHandle("h3");

描述：获取当前handle。（代码不报错，但与预期不符）

  • handle charaGetCurrent ( )

示例：
handle_h2 = charaCreate(string_h2, "worker0328_2.fxske", 0.01, "/scene/model/Character");
handle_h3 = charaGetCurrent();
if(handle_h2 == handle_h3)

        messageBox("获取当前handle");       ''' 没有生效
}

return

string_h2 = charaGetName(h2);  ''string_h2 为 h2

描述：设置人物ID。

示例1：charaSetID(h2, 202405171533);               '' 注意，超长， 测试时ID变成  2147483647
示例2：charaSetID(h2, 20240517);                   ''  ID = 20240517

return 长整型，ID

charaSetID(h2, 20240517);
Long_h2 = charaGetID(h2);

描述：获取人物Key。

return 长整型，节点key值

示例：
handle h2 = charaCreate("h2", "worker0328_2.fxske", 0.01, "/scene/model");

  • void charaStartAction ( handle h, int index, bool loop )

描述：开始人物行为。

h [in] handle，人物

index [in] 整型，动作序号，一般已经在.fxske中已经设置好

loop [in] 布尔，循环

示例：charaStartAction( h2, 2, true, true);        '''调用人物模型下的跑步动作,人物对象名、动作序号、动作是否循环

  • void charaStartAction ( handle h, int index, bool loop, bool autoLock )

描述：开始人物行为。

h [in] handle，人物

index [in] 整型，动作序号，一般已经在.fxske中已经设置好

loop [in] 布尔，循环

autoLock [in] 布尔，最后一帧是否用动作的最后一帧

示例：charaStartAction( h2, 2, true, true);        '''调用人物模型下的跑步动作,人物对象名、动作序号、动作是否循环、最后一帧是否用动作的最后一帧

  • void charaStopAction ( handle h, int index )

描述：停止人物行为。

h [in] handle，人物

index [in] 整型，动作序号，一般已经在.fxske中已经设置好

示例：charaStopAction(h2,0);       '' 停止动作序号为0的动作

  • void charaSetPosition ( handle h, float x, float y, float z )

描述：设置人物位置。

h [in] handle，人物

x [in] 世界坐标x

y [in] 世界坐标y

z [in] 世界坐标z

示例：
handle h2 = charaCreate("h2", "worker0328_2.fxske", 0.01, "/scene/model");
charaSetPosition(h2, -30, 0, 0);
charaMoveTo(h2, 30, 0, 0);  '' 不是在h2设置后的位置移动，而是创建时位置，即初始位置，往x方向移动了30单位，所以最后结果相当于在起点往x移动30个单位距离

  • void charaUpdate ( handle h, float delta_time )

描述：人物更新/刷新

h [in] handle，人物

delta_time [in] 浮点，时间

示例：charaUpdate(handle_h3, 500);

  • void charaUpdate ( handle h, float delta_time, bool sync )

描述：人物更新/刷新。

h [in] handle，人物

delta_time [in] 浮点，时间

sync [in]

示例：
Animation{''''''刷新人物
name{刷新人物}
Property{continuous}                    '''循环动画
Controller{
        life{0,200}
        Action{
                Program{
                        charaUpdate(0, 1, true);
                        }
                }
        }
}
