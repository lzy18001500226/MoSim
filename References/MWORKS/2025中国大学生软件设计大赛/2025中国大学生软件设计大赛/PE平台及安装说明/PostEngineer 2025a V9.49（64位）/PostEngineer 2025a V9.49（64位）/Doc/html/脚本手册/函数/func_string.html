函数说明¶

  • string itoa ( int val )

描述：将一个整型变量转换成字符串型变量，此函数可以直接等于一个字符串型变量

val [in] 待转换的整型变量

return 转换得到的字符串

示例：string a = itoa(100); '''// a ="100";

  • string itoa16 ( int val )

描述：将十进制转换成16进制数字的字符串。

val [in] 待转换的十进制数变量

return 转换得到的字符串

示例：string a = itoa16(10); '''// a = A;

  • int atoi ( string vstr )

描述：将一个字符串型变量转换成整型，此函数可以直接等一个整型变量,

vstr [in] 待转换的字符串型变量

return 转换得到的整数

注:此字符串型的内容需是一个或一串数字；

示例：int i = atoi("100"); '''// i = 100;

  • string ftoa ( float f, int intNum, int decimalNum )

描述：将一个浮点型变量转换成字符串型变量，此函数可以直接等于一个字符串型变量

f [in] 待转换的浮点数

intNum [in] 整数位数，表示获取小数点前面几位。如果数字大于小数点前面的位数会在前面加上“0”；小于则显示全部位数

decimalNum [in] 小数位数，表示获取小数点后面几位。如果数字大于小数点后面的位数会在后面加上“0”；小于则显示指定位数，指定位数后一位四舍五入

return 转换得到的字符串

示例：
string s = ftoa(100.11, 4, 3);  '''// s = "0100.110";
string s = ftoa(656.565,1,2);  '''// s = "656.57";

  • float atof ( string s )

描述：将字符型变量转换成浮点型变量，此变量可以直接等于一个浮点型变量

s [in] 待转换的字符串

return 转换得到的浮点数（默认保留三位小数）

示例：float f = atof("100.10"); '''// f = 100.100;

  • string trim ( string s )

描述：消除字符串中的空白字符。

s [in] 待处理的字符串

return 消除空白后的字符串

示例：string s = trim(" hello world "); '''// s = "helloworld";

  • int getStringLength ( string s )

描述：获取字符串长度。

s [in] 待处理的字符串

return 得到字符串的长度

示例：
int i= getStringLength("你好"); '''// i = 4;
int i= getStringLength("12"); '''// i = 2;

  • string getStringContent ( string s, int start, int end )

描述：获取一段字符串中的指定位数的内容;

s [in] 待获取的字符串

start [in] 整型变量，表示获取这一段字符串中的起始位；

end [in] 整形变量，表示获取这一段字符串中的结束位；

return 得到获取的字符串内容

注：此变量中如果结束位为“-1”的话表示到从起始位到结束；如果起始位和结束位是一个数字的话表示只获取此位数。

示例：
string str;
str = getStringContent("0123456789",1,4);
str = 1234;
str = getStringContent("你好",0,1);
str = "你";

  • void splitString ( string s, string division, string array & subStrArr, int & count )

描述：切割一个字符串,并将它生成为一个数组;

s [in] 待分割的字符串

division [in] 分隔字符串,隔断符号,例如空格、逗号、分号等分隔符

subStrArr [out] 分割得到的子字符串数组

count [out] 分割得到的子字符串个数,表示被切割后分成了多少段；

示例：
    string s = "hello&&world";
string div = "&&";
string sa[5];
int count = -1;
splitString(s, div, sa, count); '''// sa[0] = "hell0", sa[1] = "world", count = 2;

  • byte ascii ( string char )

描述：获取字符的ascii码

char [in] 字符

return 返回字符ASCII码

示例：
int a = ascii("a");
messageBox(itoa(a));

  • bool stringInclude ( string str1, string str2 )

描述：判断字符串”str1”中是否包含字符串”str2”；包含就返回true值;否则返回false值。

str1 [in] 第一个字符串

str2 [in] 第二个字符串

return 包含返回true，否则返回false

示例：
string str1 = "123";
bool b = stringInclude(str1, "1");

  • bool stringEqual ( string str1, string str2 )

描述：判断两个字符串是否相同

str1 [in] 第一个字符串

str2 [in] 第二个字符串

return 相同返回true，否则返回false

示例：
string str = "str";
bool b = stringEqual(str, "str");

  • void stringToValues ( string str, float array& values, int & count )

描述：将字符串分割成float变量的数组

str [in] 待分割字符串

values [out] 分割得到的float型数组

count [out] 分割得到的子字符串个数

示例：
string str = "1,2,3,4,5";
float values[5];
int count;
stringToValues(str,values,count) '''// values[5] = {1.000,2.000,3.000,4.000,5.000};

  • void valuesToString ( float array& values, int count, string & str )

描述：将float变量数组合并成字符串

values [out] 待合并float型数组

count [in] 数组数量

str [out] 合并的字符串

示例：
float values[5] = {1.000,2.000,3.000,4.000,5.000};
int count = 5;
string str;
valuesToString(values, count, str); '''// str = "1.000,2.000,3.000,4.000,5.000";

  • void bytesToString ( byte array& bytes, int len, string & str )

描述：将byte型转换成字符串型;

bytes [out] 需要被转换成字符串型的数据的数组;

len [in] 为被转换数组中数据长度;

str [out] 转换完成后的字符串变量;

示例：
string str;
byte byteArray[5] = {72, 101, 108, 108, 111};
bytesToString(byteArray, 5, str);
messageBox(str); '''// str = "hello";

  • void bytesToString ( byte array& bytes, int len, string & str, bool isUnicode )

描述：将byte型转换成字符串型;

bytes [out] 需要被转换成字符串型的数据的数组;

len [in] 为被转换数组中数据长度;

str [out] 转换完成后的字符串变量;

isUnicode [in] 是否是unicode编码

示例：
string str;
byte byteArray[5] = {72, 101, 108, 108, 111};
bytesToString(byteArray, 5, str, 0);
messageBox(str);  '''// str = "hello";

  • void stringToBytes ( string str, byte array& bytes, int & len )

描述：将字符串转换成byte型

str [in] 被转换的字符串变量;

bytes [out] 将字符串转换完后的数据存放在此数组中;

len [out] 为存放后的数组中数据长度;

示例：
string str = "hello";
byte byteArray[5];
int len;
stringToBytes(str, byteArray, len);

  • void stringToBytes ( string str, byte array& bytes, int & len, bool isUnicode )

描述：将字符串转换成byte型

str [in] 被转换的字符串变量;

bytes [out] 将字符串转换完后的数据存放在此数组中;

len [out] 为存放后的数组中数据长度;

isUnicode [in] 是否是unicode编码

示例：
string str = "hello";
byte byteArray[5];
int len;
stringToBytes(str, byteArray, len, 0);

  • int findString ( string str, string subStr )

描述：从一个大字符串里面找一个小字符串，返回小字符串的第一个字符在大字符串中的位置

str [in] 大字符串

subStr [in] 小字符串

return 返回小字符串的第一个字符在大字符串中的位置

示例：
string content = "string";
int id = findString(content, "str");  '''// id = 0;
