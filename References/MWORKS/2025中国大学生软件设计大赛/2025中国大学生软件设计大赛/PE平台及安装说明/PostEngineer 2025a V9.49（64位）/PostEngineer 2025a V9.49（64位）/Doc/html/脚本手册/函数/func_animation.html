函数说明¶

  • void astart ( string animName )

描述：启动动画

animName [in] 动画名称

示例：astart("Ani风扇转动");

  • void astart ( string animName, bool bReverse )

描述：启动动画,可以设置是否反向

animName [in] 动画名称

bReverse [in] 是否反向

示例：astart("Ani风扇转动", 1);

  • void astart ( string animName, bool bReverse, bool bCopy )

描述：启动动画,可以设置是否反向,是否复制出独立动画

animName [in] 动画名称

bReverse [in] 是否反向

bCopy [in] 是否复制动画

示例：astart("Ani风扇转动", 1, 1);

  • void astartDelay ( string animName, float delaytime )

描述：动画延迟执行

animName [in] 动画名称

delaytime [in] 动画延迟时间

示例：astartDelay("动画_1",2000);'''动画延迟2s执行

  • void areset ( string animName )

描述：重置动画

animName [in] 动画名称

示例：areset("Ani风扇转动");

  • void astop ( string animName )

描述：停止动画

animName [in] 动画名称

示例：astop("Ani风扇转动");

  • void apause ( string animName )

描述：暂停动画

animName [in] 动画名称

示例：apause("Ani风扇转动");

  • void acontinue ( string animName )

描述：继续播放动画

animName [in] 动画名称

示例：acontinue("Ani风扇转动");

  • void rotateFieldAnim ( string pathname, float x, float y, float z, float axisx, float axisy, float axisz, float angle, float time )

描述：在规定时间内(time)完成设置的节点(pathname)围绕指定轴(x,y,z,axisx,axisy,axisz)进行旋转指定角(angle)。

pathname [in] 节点路径，为字符串型，需要用双引号括起来

x [in] 旋转轴的局部坐标

y [in] 旋转轴的局部坐标

z [in] 旋转轴的局部坐标

axisx [in] 旋转轴

axisy [in] 旋转轴

axisz [in] 旋转轴

angle [in] 角度

time [in] 旋转的时间

示例：rotateFieldAnim("/scene/modules/main/model/电风扇/扇叶", -2.07502, -0.26032, -3.10892, 0, 1, 0, 30, 1000);

  • void moveFieldAnim ( string pathname, float x, float y, float z, float time )

描述：在time时间内完成某个节点相对当前位置移动到设置的位置。

pathname [in] 需要移动节点路径，为字符串型，需要用双引号括起来

x [in] x方向移动的位移量

y [in] y方向移动的位移量

z [in] z方向移动的位移量

time [in] 移动时间

示例：moveFieldAnim("/scene/modules/main/model/小车", 0, 20, 0, 1000);

  • void transparencyFieldAnim ( string pathname, float s, float e, float time )

描述：在time时间内完成物体透明度由s渐变透明至e

pathname [in] 需要透明变化的节点路径，为字符串型，需要用双引号括起来

s [in] 初始透明度参数

e [in] 最终透明度参数

time [in] 透明变化时间

示例：transparencyFieldAnim("/scene/modules/main/model/小车", 1,0.5, 1000)

  • void movePipePointAnimByField ( string pathname, int pointIndex, float dx, float dy, float dz, float time )

描述：动态移动管道上的控制点

pathname [in] 管道节点路径

pintIndex [in] 控制点序号

dx [in] 移动距离分量

dy [in] 移动距离分量

dz [in] 移动距离分量

time [in] 动画运行时间

示例：

  • void printTextAnim ( string pathname, float time )

描述：在time时间内打印文字

pathname [in] 文字节点/文字图表对象名

time [in] 打印时间

示例1：printTextAnim("/scene/texts/步骤提示",4000);'''打印文本(旧)
示例2：printTextAnim("图表_整体介绍",4000)'''打印图表文字(新)

  • void printTextAnim ( dword key, float time )

描述：通过获取文字节点key值，在time时间内打印文字

key [in] 文字节点key值，通过getkey获取出来

time [in] 打印时间

示例1：printTextAnim(getkey("/scene/texts/步骤提示"),4000);

  • void setAnimSpeed ( string animName, float factor )

  • void setGeometry2DAnimatingTime ( float time )

描述：设置动态图表时间，实现图表的动态效果

time [in] 动态效果时间

示例：
