函数说明¶

  • bool netCreateServer ( string port, string user, string password )

描述：创建网络通信

hostAddress [out] 服务器IP地址

port [in] 服务器端口号

user [in] 用户名

password [in] 密码

return

示例：
string hostAddress = "192.168.50.121";
int port = 5810;
string user = "mis01";
string password = "123456";
netCreateServer(hostAddress,port,user,password);

  • bool netConnect ( string hostAddress, int port, string user, string password )

描述：链接网络通信

hostAddress [in] 服务器IP地址

port [in] 服务器端口号

user [in] 用户名

password [in] 密码

return

示例：
string hostAddress = "192.168.50.121";
int port = 5810;
string user = "mis01";
string password = "123456";
netConnect(hostAddress,port,user,password);

  • void netClose ( )

描述：关闭网络通信

示例：     netClose();

  • void netGetHostAddress ( string & hostAddress )

描述：获取网络通信主机地址

hostAddress [out] 输出服务器IP地址

return

示例：
string hostAddress;
netGetHostAddress(hostAddress);
输出hostAddress为服务器IP地址

  • bool netSendData ( string address, int port, byte array& data, int len )

描述：发送网络通信数据

address [in] IP地址
