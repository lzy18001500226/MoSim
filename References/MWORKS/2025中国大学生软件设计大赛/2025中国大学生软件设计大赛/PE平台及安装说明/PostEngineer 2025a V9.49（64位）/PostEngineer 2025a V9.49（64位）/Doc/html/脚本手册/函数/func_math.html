函数说明¶

  • float exp ( float val )

描述：自然指数函数，即以实数e（e≈2.71828）为底的指数函数。其表达式为exp(x)=e^x。

val [in] 指数

return

示例：
float f1;
f1 = exp (0);
输出f1 = 1.000000;

  • float log ( float val )

描述：对数函数，是以幂（真数）为自变量，指数为因变量，底数为10的函数。

val [in] 真数

return

示例：
float f1;
f1 = log (10);
输出f1 = 1.000000;

  • float pow ( float val, float index )

描述：计算指数次幂,返回幂指数的结果,即val的index次幂。

val [in] 底数

index [in] 指数

return

示例：
float f1;
f1 = pow (2,3);
输出f1 = 8.000000;

  • float sqrt ( float val )

描述：开方函数,接受一个数值参数，并返回该数值的平方根。

val [in] 被开方数

return

示例：
float f1;
f1 = sqrt(9);
输出f1 = 3.000000;

  • float atan ( float val )

描述：反正切函数,用于计算一个数的反正切值,即该数的正切值所对应的角度。

val [in] 正切值(-∞, +∞)

return

示例：
float f1;
f1 = atan(1);
输出f1 = 45.000000;

  • float sin ( float val )

描述：正弦函数,对于任意一个实数x都有唯一确定的值sinx与它对应,,按照这个对应法则所建立的函数,表示为f（x）=sinx。

val [in] 角度

return

示例：
float f1;
f1 = sin(30);
输出f1 = 0.500000;

  • float cos ( float val )

描述：余弦函数,对于任意一个角x,都有的余弦cosx与之对应,所以 f（x）=cosx 是一个函数,一般称为余弦函数。

val [in] 角度

return

示例：
float f1;
f1 = cos(60);
输出f1 = 0.500000;

  • float tan ( float val )

描述：正切函数,为正弦函数sinx除以余弦函数cosx。

val [in] 角度

return

示例：
float f1;
f1 = tan(45);
输出f1 = 1.000000;

  • float acos ( float val )

描述：反余弦函数,为余弦函数f（x）=cosx在[0,π]上的反函数。

val [in] 余弦值([-1, 1])

return

示例：
float f1;
f1 = acos(0);
输出f1 = 90.000000;

  • float asin ( float val )

描述：反正弦函数,为正弦函数f（x）=sinx在[-π/2,π/2]上的反函数。

val [in] 正弦值([-1, 1])

return

示例：
float f1;
f1 = asin(0);
输出f1 = 0.000000;

  • int rand ( )

描述：随机函数

示例：
int i1;
i1 = rand();
输出i1为随机整数;

  • int rand ( int fmin, int fmax )

描述：范围内随机函数

fmin [in] 最小整数

fmax [in] 最大整数

return

示例：
int i1;
i1 = rand(0,100);
输出i1为0-100内随机整数;

  • void rand ( int array& arr, int fmin, int fmax, int num )

描述：随机数组

arr [out] 输出数组

fmin [in] 最小整数

fmax [in] 最大整数

num [in] 数组个数

示例：
int i1[30];
rand(i1,0,100,30);
输出30个为0-100内随机整数的数组i1[30];

  • bool arc ( float array& center, float array& start, float array& end, float delta_angle, bool bCcw, float array& points, float array& count )

描述：计算圆弧，返回圆弧线上的点

center [out] 圆弧中心点

start [out] 圆弧起始点

end [out] 圆弧终止点

delta_angle [in] 角度精度

bCcw [in] 是否逆时针

points [out] 返回圆弧线上的点数组

count [out] 点个数

return

  • bool encrypt ( string & key, string & strIn, string & strOut )

描述：加密

key [out] 加密字符串

strIn [out] 输入字符串

strOut [out] 输出字符串

return

示例：
string key = "www";
string strIn = "111";
string strOut;
encrypt(key, strIn, strOut);
输出strOut = "i?*8譺";

  • bool decrypt ( string & key, string & strIn, string & strOut )

描述：解密

key [out] 解密字符串

strIn [out] 输入字符串

strOut [out] 输出字符串

return

示例：
string key = "www";
string strIn1 = "111";
string strOut1;
string strIn2;
string strOut2;
encrypt(key, strIn1, strOut1);
strIn2 = strOut1;   '''strOut1 = "i?*8譺";
decrypt(key, strIn2, strOut2);
输出strOut2 = "111";

  • bool encrypt ( string array& btsIn, int countIn, byte array& btsOut, int & countOut )

描述：加密

key [out] 加密字符串

btsIn [out] 输入字节数组

countIn [in] 输入字节数组个数

btsOut [out] 输出字节数组

countOut [out] 输出字节数组个数

return

示例：
string key = "www";
byte by_In[5];
by_In[0] = 1;
by_In[1] = 1;
by_In[2] = 1;
by_In[3] = 1;
by_In[4] = 1;
int countOut;
byte by_Out[countOut];
encrypt(key, by_In, 5, by_Out, countOut);
输出by_Out[8] = {12,227,70,21,229,242,184,29};

  • bool decrypt ( string array& btsIn, int countIn, byte array& btsOut, int & countOut )

描述：解密

key [out] 解密字符串

btsIn [out] 输入字节数组

countIn [in] 输入字节数组个数

btsOut [out] 输出字节数组

countOut [out] 输出字节数组个数

return

示例：
string key = "www";
byte by_In[5];
by_In[0] = 1;
by_In[1] = 1;
by_In[2] = 1;
by_In[3] = 1;
by_In[4] = 1;
int countOut1;
byte by_Out1[countOut1];
int countOut2;
byte by_Out2[countOut2];
encrypt(key, by_In, 5, by_Out1, countOut1);
decrypt(key, by_Out1, countOut1, by_Out2, countOut2);
输出by_Out2[8] = {1,1,1,1,1,0,0,0};
