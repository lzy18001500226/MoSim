# Simulation References

External simulation, physics, RL, and comparison platforms. These references
help with architecture research and controller benchmarking, but the current
MoSim runtime lane remains Sunray ROS1/Gazebo Classic unless explicitly changed.

| Directory | Purpose |
| --- | --- |
| `physics/` | General physics engines and modern simulator backends. |
| `rl/` | RL-oriented control and drone simulation environments. |
| `mpc/` | MPC and optimal-control simulator references. |
| `assets/` | Simulator model and robot asset libraries. |
| `aviation/` | Flight dynamics and aerial robotics simulators. |
| `webots/` | Webots ROS2 integration references. |
