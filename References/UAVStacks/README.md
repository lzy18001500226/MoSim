# UAV Stack References

Full-stack UAV engineering references used to study ROS/PX4/Gazebo integration,
planning, perception, and multi-UAV engineering patterns.

| Directory | Purpose |
| --- | --- |
| `ros_px4_gazebo/` | ROS/PX4/Gazebo UAV stacks, including XTDrone and Prometheus. |

These projects are not current MoSim runtime baselines. Adoption into MoSim
requires an explicit architecture decision and evidence gate.
