# Unreal External Renderer

This folder contains small, project-owned Unreal integration code. It is not a
full Unreal project and should not contain `Binaries/`, `Intermediate/`,
`Saved/`, packaged builds, or engine files.

## Purpose

MWORKS/Sysplorer remains the simulation source of truth. Unreal is only an
external visualization layer for:

- UAV and propeller materials;
- terrain, wall, and obstacle materials;
- radar sector visualization;
- local plan and trajectory trails;
- follow/overview cameras;
- video recording.

Unreal must not feed data back into the controller, planner, collision checker,
or metrics.

## Project Entry

Open this project when using Unreal as the external renderer:

```text
unreal/MworksUnrealRenderer/MworksUnrealRenderer.uproject
```

It enables the project-owned UDP bridge and the local Unreal MCP editor plugin
without copying either plugin into the engine install directory.

## Current Plugins

`QuadrotorMworksBridge` provides a lightweight UDP receiver component:

```text
unreal/QuadrotorMworksBridge/
```

It listens on `0.0.0.0:5005` by default and parses packets generated by:

```bash
python3 scripts/stream_unreal_udp.py <raw.csv> --host 127.0.0.1 --port 5005
```

Expected packet schema:

```text
quadrotor.unreal_state.v1
```

## Integration

1. Create or open a UE 5.7 C++ project.
2. Copy `unreal/QuadrotorMworksBridge` into the project's `Plugins/` folder.
3. Enable the plugin and rebuild the project.
4. Add `QuadrotorMworksUdpReceiverComponent` to an Actor.
5. Bind `OnFrameReceived` in Blueprint or C++.
6. Convert MWORKS meters to Unreal centimeters in the receiving Actor.

Coordinate conversion belongs in Unreal. Do not change raw CSV units.

`UnrealMCP` is loaded from:

```text
Skills/unreal-engine-mcp/FlopperamUnrealMCP/Plugins/UnrealMCP
```

Use it only to automate Unreal Editor scene setup. If `get_actors_in_level`
returns `Connection refused`, the WSL MCP wrapper is working but Unreal Editor
has not loaded/listened through the plugin yet.
