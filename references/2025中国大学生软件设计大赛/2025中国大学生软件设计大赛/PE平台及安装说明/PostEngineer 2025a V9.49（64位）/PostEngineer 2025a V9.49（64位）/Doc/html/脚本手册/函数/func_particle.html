函数说明¶

  • void startParticle ( string name )

描述：启动粒子

name [in] 对象名

示例：startParticle("粒子_1");

  • void stopParticle ( string name )

描述：停止发射粒子

name [in] 对象名

示例：stopParticle("粒子_1");

  • void killParticle ( string name )

描述：粒子立即消失

name [in] 对象名

示例：killParticle("粒子_1");

  • void showParticle ( string name, bool b )

描述：显示隐藏粒子，隐藏粒子后，粒子仍然运行，只是不显示。若需要实现隐藏粒子后，粒子也不运行，则可隐藏其父节点。

name [in] 对象名

b [in] 是否显示 0隐藏，1显示

示例：showParticle("粒子_1", 1);

  • void setParticleCount ( string name, int count )

描述：设置粒子发射数量 (问题反馈：函数无效)

name [in] 对象名

count [in] 发射数量

示例：setParticleCount("粒子_1", 10);

  • void setParticleInterval ( string name, int interval )

描述：设置粒子发射间隔 (问题反馈：函数无效)

name [in] 对象名

interval [in] 发射间隔

示例：setParticleInterval("粒子_1", 1);

  • void setParticleSize ( string name, float size )

描述：设置粒子基准大小

name [in] 对象名

size [in] 基准大小

示例：setParticleSize("粒子_1", 5);

  • void setPipelingAxis ( string name, float array& axisArr, int pcount )

描述：设置粒子管道的中心点

name [in] 粒子对象名

axisArr [out] 点数组

pcount [in] 点个数

示例：

  • void setPipelingForce ( string name, float axisF, float radiusF, float rotateF )

name [in] 粒子对象名

radiusF [in] 径向力系数

rotateF [in] 自转力系数
