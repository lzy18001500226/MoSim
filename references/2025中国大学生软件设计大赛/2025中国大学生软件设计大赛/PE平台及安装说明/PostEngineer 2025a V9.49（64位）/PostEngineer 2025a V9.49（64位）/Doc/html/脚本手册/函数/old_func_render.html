  • void setLineColor ( string pathname, float r, float g, float b, float a )

描述：设置物体的高亮颜色

pathname [in] 模型节点

r [in] 颜色R

g [in] 颜色G

b [in] 颜色B

a [in] 透明度

示例：setLineColor("/scene/modules/main/model/DD2",0,0,1,0.5);

  • void setOptionValuefv ( string option_name, float array& value, int count )

描述：设置高亮颜色

option_name [in] option_name为 “hicolor”

array& value [out] 颜色r,g,b数组

count [in] 数组长度

示例：
float clr[3] = { 0,1,0};
setOptionValuefv("hicolor", clr, 3);
