函数说明¶

  • void camZoomToField ( dword key )

描述：将视角移动到某个物体上。

key [in] 节点key值，通过getkey获取出来。

示例：camZoomToField(getkey("/scene/modules/main/model/模型.vis/.../..."));

  • void camZoomToFieldAnim ( dword key, float time )

描述：把相机设置到节点生成动画。

key [in] 节点key值，通过getkey获取出来。

time [in] 时间

示例：

  • void camZoomToFieldAnimByPath ( string pathname, float time )

描述：把相机设置到节点生成动画，节点不用getkey，直接填写路径。

pathname [in] 节点路径

time [in] 时间

示例：camZoomToFieldAnimByPath("/scene/modules/main/model/模型.vis/.../...", 1000);

  • void camSetDisableAllowed (BOOL b )

描述：允许/禁止用户相机变换。（没有实现示例）

b [in]

  • void camGetCamera ( string vportName, dword array& values )

描述：获取当前视口内容的相机参数值，将获取出来的值赋给 key值 数组float array& values。

vportName [in] 视口名称

key [out] 节点key值

values [out] 一个9位数的浮点型数组，内容为相机参数值

示例：
dword key_a;
float values[9];
camGetCamera("main", key_a,  values);  '' 或 camGetCamera("视口名称", key_a, values);
string str = itoa(values[0]);           '' 显示数组中第一个值，可以改其它
messageBox(str);

  • void camGetCamera ( string vportName, float array& values )

描述：获取当前视口内容的相机参数值，将获取出来的值赋给 数组float array& values。

vportName [in] 视口名称

values [out] 一个9位数的浮点型数组，内容为相机参数值

示例:
float CameraValues[9];
camGetCamera("main",  CameraValues);

  • void camSetCamera ( string vportName, dword key, float array values )

描述：设置相机视角；类似 set camera。

vportName [in] 相机名称

key [in] 节点key值

array values [in] 一个9位数的浮点型数组，内容为相机参数值

示例1:
dword key_a;
float values[9];
camGetCamera("main", key_a,  values);
camSetCamera("视口_1", key_a, values);

示例2:
camSetCamera("XL无人机视角", getkey("/scene/modules/main/model/wrdj001.vis/通讯车/无人机"),1.566077, -0.034142, 0.043991, 1.523037, -0.204041, 0.047614, 1, 0, 0);

  • void camSetCamera ( string vportName, dword key, float ex, float ey, float ez, float tx, float ty, float tz, float ux, float uy, float uz )

描述：设置相机视角。

vportName [in] 相机名称

key [in] 节点key值

ex [in] 相机参数值

ey [in] 相机参数值

ez [in] 相机参数值

tx [in] 相机参数值

ty [in] 相机参数值

tz [in] 相机参数值

ux [in] 相机参数值

uy [in] 相机参数值

uz [in] 相机参数值

示例: camSetCamera("main", -1, 8.744553, 80.568665, -1.936754, 8.801472, 20.440569, -0.650128, 0, 0, -1);

  • void camSetCameraHost ( string hostName )

描述：在网络协同中，设置主变换相机的IP地址，其他电脑的相机变换跟随这个相机进行变换。

hostName [in] 主变换相机的IP地址

示例: camSetCameraHost(hostName);

  • void camZoom ( float factor )

描述：设置相机缩放 （不清楚使用方法）

factor [in] 缩放系数

示例:

  • void camLift ( float distance )

描述：相机升降。

distance [in] 浮点，距离

示例: camLift(100)

  • void camSetBasisField ( string vportName, dword key, bool bConvertCamera )

描述：设置基础节点。

vportName [in] 字符串，接口名

key [in] 长整型，相机key值getKey(“/scene”)

bConvertCamera [in] 布尔，改变相机，bConvertCamera默认为1

示例1:    camSetBasisField("main", getkey("/scene"), 1);          '''恢复到主视口
示例2:    camSetBasisField("main", getkey("/scene"), true);               '''解除主视口相机绑定相对节点

  • void camSetVertical ( float x, float y, float z )

描述：设置相机垂直的旋转轴，例如当参数x=1时，运行程序，鼠标左键移动时会在当前视角下，以x轴旋转。

x [in] 浮点.x

y [in] 浮点.y

z [in] 浮点.z

示例:     camSetVertical(1,1,1);

  • void camLock ( float distance, float minAngle, float maxAngle )

描述：限制相机旋转的距离和幅度，角度限制是竖直方向的限制，对水平方向无限制。

distance [in] 浮点，距离

minAngle [in] 浮点，最小角度

maxAngle [in] 浮点，最大角度

示例:     camLock(100,10,60);

  • void camLock ( float minDis, float maxDis, float minAngle, float maxAngle )

描述：限制相机旋转的距离和幅度，角度限制是竖直方向的限制，对水平方向无限制。

minDis [in] 浮点，最小距离

maxDis [in] 浮点，最大距离

minAngle [in] 浮点，最小角度

maxAngle [in] 浮点，最大角度

示例:     camLock(6, 16000,10,60);

  • void camUnlock ( )

描述：解除相机锁，用于相机锁之后。

示例:
camLock(6, 16000,10,60);
camUnlock();

speed [in] 浮点，速度

示例:     camSetWalkSpeed(6000);
