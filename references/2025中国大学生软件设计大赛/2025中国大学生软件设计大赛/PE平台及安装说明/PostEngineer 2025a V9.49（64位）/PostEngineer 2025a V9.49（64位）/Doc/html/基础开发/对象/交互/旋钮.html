旋钮¶

旋钮对象可以用于模拟旋钮、表盘指针等，也可用于控制二维模型和三维模型，但是需在旋钮属性中指定二维或三维对象。

获取当前三维场景中的坐标轴

以图片对象中心点为旋转轴，通过图片对象属性的位置坐标去获取

一般默认初始角度为0°，当有具体内容要求可根据需求调整初始角度

8

停靠角度

停靠角度是一组角度刻度值，当用户旋转后释放旋钮时自动停留在最近的刻度上，可以为空。

9

指针能旋转的最大角度

10

速度

指针旋转的速度

  • 旋钮编辑

备注

旋钮对象包含模型节点路径、旋转轴、初始角度、最大角度和停靠角度等属性，以及一个“dial”的属性变量， 代表当前旋钮所处的角度。用户在旋转旋钮时，系统会自动给“dial”赋值。 如果用户给直接“dial”赋值，则可驱动旋钮自主旋转。脚本程序中访问“dial”变量的方式是：旋钮名.dial。

1）创建对象

创建旋钮对象的方法是，首先在项目管理树的右键菜单中选择“添加交互对象>旋钮”。

2）复制路径

然后在右侧属性窗口中设置旋钮的属性。从模型树中复制模型节点路径填充到节点路径的属性栏中。这个节点路径即为旋钮指针的模型路径。指针的形态可以不一，例如下图的表盘指针和方向盘均可作为旋钮对象的指针：

3）设置旋转轴

设置旋钮的旋转轴，旋转轴包含 6 各分量，前三个为基点坐标，后三个为方向坐标。如果是三维模型，则可以直接在三维场景中通过鼠标获取几何信息。如果是二维模型，则要在屏幕上选取屏幕坐标，或者直接使用图片的中心坐标，方向则一般设置为(0,0,1)或(0,0,-1)，即屏幕的 Z 轴方向。

几何信息和屏幕坐标在导航栏的工具里面，几何信息需要CTRL+鼠标左键点击目标位置，一般几何信息是指世界坐标，即下图红色框中的三个数据，屏幕坐标直接用鼠标左键点击后会自动复制屏幕坐标。

备注

创建函数调用旋钮对象，函数创建方法类似其它对象，也是鼠标右键项目管理的“main”节点，具体参考上文。

Animation{''Ani_旋钮取值
    name{ani 旋钮取值}
        Controller{
            Action{
                    program{
                            int p = 0           '''局部工具变量
                                p = 旋钮_风向.dia1  '''旋钮变量赋值拿给工具变量
                                p = p%360           '''工具变量取余

                                if (p <0 ){
                                    p = 360 + p
                                }
                                旋钮_风向.dial = p
                                ' messageBox(""+p)  '''消息弹出
                                if(p == 0){
                                    '' 0°，北
                                    astart("Ani_风力清除");
                                    astart("Ani_设置北风");
                                }
                                else if(p == 45){
                                    '' 45°，西北
                                    astart("Ani_风力清除");
                                    astart("Ani_设置西北风");
                                }
                                else if(p == 90){
                                    '' 90°, 西
                                        astart("Ani_风力清除");
                                        astart("Ani_设置西风");
                                }
                                else if(p == 135){
                                    '' 135°，西南
                                        astart("Ani_风力清除");
                                        astart("Ani_设置西南风");
                                }
                                else if(p == 180){
                                    '' 180°，南
                                        astart("Ani_风力清除");
                                        astart("Ani_设置南风");
                                }
                                else if(p == 225){
                                    '' 225°，东南
                                        astart("Ani_风力清除");
                                        astart("Ani_设置东南风");
                                }
                                else if(p == 270){
                                    '' 270°，东
                                        astart("Ani_风力清除");
                                        astart("Ani_设置东风");
                                }
                                else if(p == 315){
                                    '' 315°，东北
                                        astart("Ani_风力清除");
                                        astart("Ani_设置东北风");
                                }
                        }
                }
        }
}
