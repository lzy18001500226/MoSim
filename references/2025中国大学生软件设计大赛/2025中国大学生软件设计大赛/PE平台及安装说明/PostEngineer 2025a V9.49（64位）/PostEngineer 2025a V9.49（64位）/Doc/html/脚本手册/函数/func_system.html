函数说明¶

  • void appSendMessage ( string appName, string msg )

描述：向指定进程发送消息

appName [in] 进程名称

msg [in] 传递的信息

示例：appSendMessage("Window_浏览器", "Show_浏览器");

  • void OnAppMessage ( string appName, string msg )

描述：接收数据的回调

appName [in] 进程名称

msg [in] 传递的信息

示例：
void OnAppMessage(string appName, string msg)
{
        if( appName== "雪亮摄像头"){
                监控视频:s_监_主窗口视频源地址 = "rtsp://admin:xx@xx.xx.x." + msg;
        }

        else if( appName== "秸秆摄像头"){
                监控视频:s_监_主窗口视频源地址 = msg;
        }
}

  • void appSetTitle ( string title )

描述：设置程序标题名

title [in] 标题名称

示例：appSetTitle("数字乡村");

  • void appBringToTop ( string appName )

描述：置顶某个进程

appName [in] 进程名称

示例：appBringToTop("微信");

  • void appTakeToBottom ( string appName )

描述：置底某个进程

appName [in] 进程名称

示例：
appSetTitle("数字乡村");
appTakeToBottom("数字乡村");

  • void appExit ( string appName )

描述：退出某个进程

appName [in] 进程名称

示例：     appExit("微信");

  • dword appGetModuleHandle ( )

描述：获取某个组件模块句柄

示例：messageBox(  ""+appGetModuleHandle());

  • void appSetFullScreen ( bool bFullScreen )

描述：设置满屏/窗口化

bFullScreen [in] 1 or 0 (满屏 或 窗口化)

示例：
appSetFullScreen(1); ''设置满屏
appSetFullScreen(0); ''设置窗口化

  • void appPrintLog ( string file, string name, int val )

描述：指定路径存放log

file [in] log路径

name [in] 打印string字段

val [in] 打印int字段

示例：
string gLogFile = "1.log";
appPrintLog(gLogFile,"111",111);
输出1.log内容为"[11:20:10.65]: 111, 111"。

  • void shellExecute ( string strExePath )

描述：打开应用程序

strExePath [in] 应用程序路径

示例：     shellExecute("main\Debug\测试.exe");

  • void pauseSystem ( )

描述：暂停整个系统的运行。

示例：pauseSystem();       ''暂停后无法相应键盘和控制点，仅通过F8打断暂停

  • void pauseActiveAnimations ( string moduleName )

描述：暂停模块的活动动画

moduleName [in] “main”或其他模块

示例：     pauseActiveAnimations("main");

  • void continueActiveAnimations ( string moduleName )

描述：继续模块的活动动画

moduleName [in] “main”或其他模块

示例：     continueActiveAnimations("main");

  • void printString ( float x, float y, string str )

描述：打印字符串

x [in] 坐标轴x

y [in] 坐标轴y

str [in] 输入文字

示例：printString(0,0,"123");

  • void messageBox ( string msg )

描述：弹出窗口

msg [in] 输入文字

示例：
int n=405/360;
messageBox(  ""+n);

  • void pause ( string msg )

描述：断点暂停，显示断点对话框

msg [in] 断点消息，显示在对话框的标题栏上

  • void pause ( int iVal )

描述：断点暂停，显示断点对话框

iVal [in] 断点变量，其值显示在对话框的标题栏上

  • void pause ( int iVal )

  • dword pluginCall ( string dllName, string funName, dword param )

描述：插件调用

param [in] 参数

  • dword pluginCall ( string dllName, string funName, dword param1, dword param2, dword param3 )

描述：插件调用

dllName [in] 函数库名

funName [in] 函数名

param1 [in] 参数1

param2 [in] 参数2

param3 [in] 参数3

return

示例：     pluginCall("PETo3dEarth", "SetOffsetAngle", "tiles_A", "-0.25", "-0.000035");

  • dword pluginCall ( string dllName, string funName, dword param1, dword param2, dword param3, dword param4, dword param5, dword param6 )

描述：插件调用

dllName [in] 函数库名

funName [in] 函数名

param1 [in] 参数1

param2 [in] 参数2

param3 [in] 参数3

param4 [in] 参数4

param5 [in] 参数5

param6 [in] 参数6

return

示例：
float x; float y; float z; float lat; float lon; float dem;
int res = pluginCall(mPluginName, "LatLonDEMToXYZS", lat.self(), lon.self(), dem.self(), x.self(), y.self(), z.self());
