函数说明¶

  • void setButtonPosition ( string Name, float x, float y, float z )

描述：设置按钮位置，动态设置按钮的位置，此位置为屏幕坐标位置。

Name [in] 字符串，按钮名字

x [in] 浮点，x坐标

y [in] 浮点，y坐标

z [in] 浮点，z坐标（决定层级）

示例：setButtonPosition("按钮_1", -0.295, -0.379, 10);

  • void getButtonPosition ( string Name, :ref:`float<class_float>`& x,:ref:`float<class_float>`& y, :ref:`float<class_float>`& z )

描述：获取按钮位置。

Name [in] 字符串，按钮名字

x [out] 浮点，x坐标

y [out] 浮点，y坐标

z [out] 浮点，z坐标

示例：
setButtonPosition("按钮_1", -0.295, -0.379, 10);
getButtonPosition("按钮_1", F_x, F_y, F_z);                       '' PE中自定义浮点变量

  • void setImagePosition ( string Name, float x, float y, float z )

描述：设置图片位置。

Name [in] 字符串，图片名字

x [in] 浮点，x坐标

y [in] 浮点，y坐标

z [in] 浮点，z坐标（决定层级）

示例：setImagePosition("图片_1", 0.549, -0.246, 20);

  • void getImagePosition ( string Name, :ref:`float<class_float>`& x,:ref:`float<class_float>`& y, :ref:`float<class_float>`& z )

示例：

  • void insertAnnotation ( string pathname, string content, float tarx, float tary, float tarz, float x, float y, float z, float sx, float sy, float sz, float r, float g, float b, string font )

描述：添加注释。

pathname [in] 字符串，注释路径

content [in] 字符串，注释的内容

tarx [in] 浮点，注释内容的坐标x

tary [in] 浮点，注释内容的坐标y

tarz [in] 浮点，注释内容的坐标z

x [in] 浮点，被标注的位置坐标x

y [in] 浮点，被标注的位置坐标y

z [in] 浮点，被标注的位置坐标z

sx [in] 浮点，文字的大小

sy [in] 浮点，文字的大小

sz [in] 浮点，文字的大小

r [in] 浮点，字体颜色，0~1之间的值

g [in] 浮点，字体颜色，0~1之间的值

b [in] 浮点，字体颜色，0~1之间的值

font [in] 字符串，字体

示例：insertAnnotation("/scene/Annotation/test/测试1", "动态注释测试", 0.3, 0.1, 0.9, -4728.75, -192.686, 0.209, 2, 2, 2, 1, 0, 0, "微软雅黑");

  • dword insertImage ( string name, float x, float y, float z, float w, float h, string transparency, bool bWorldPos, float offX, float offY )

描述：动态定义图片。

name [in] 字符串，生成的图片路径

x [in] 浮点，屏幕坐标x

y [in] 浮点，屏幕坐标y

z [in] 浮点，屏幕坐标z

w [in] 浮点，宽

h [in] 浮点，高

bmpFile [out] 字符串，图片物理路径

tempFile [out] 字符串，蒙版物理路径

transparency [in] 浮点，透明度

bWorldPos [in] 布尔，（世界位置）false在屏幕平面，true在3D世界，同时影响x、y和offX、offy是否生效

offX [in] 浮点，bWorldPos为true时生效的x坐标

offy [in] 浮点，bWorldPos为true时生效的y坐标

return dword 生成的图片key值

示例：
keyImage = insertImage("/sence/insertImage/test1", -0.8, -0.9, 10, 1, 1, "E:\PEprojectTest\PE项目_说明文档_节点操作类函数\main\image\insertImageTest.png", "", 0.7, true, 1, 1.4);
insertImage("/sence/insertImage/test2", -0.8, -0.9, 10, 1, 1, "E:\PEprojectTest\PE项目_说明文档_节点操作类函数\main\image\图片.bmp", "E:\PEprojectTest\PE项目_说明文档_节点操作类函数\main\image\蒙版.bmp", 0.7, false, 1, 1.4);
