  • bool isChildOf ( dword key, dword owner_key )

描述：判断当前“long key”的模型是否属于“long owner_key”值得子节点。注意：此命令适用于key值使用，需要通过getkey 命令或者参数值。

key [in] dword，key值

owner_key [in] dword，owner_key值

return 布尔，true或false

示例：
dword key = getkey("/scene/modules/main/model/船桨pbr.vis/group1_FBXASC0560FBXASC03269FBXASC03257FBXASC032100");
dword owner_key = getkey("/scene/modules/main/model/船桨pbr.vis");
bool result = isChildOf(key, owner_key);
if(result)
{
        messageBox("是子节点");
}

  • void selectByKey ( dword key, bool bSel )

描述：设置选择和取消物体。

key [in] dword，物体的节点key值；如果是 -1 值则代表所有物体；

bSel [in] 布尔，1-选择；0-取消选择；

示例：selectByKey(owner_key, 1);

  • dword getOwnerKey ( dword key )

描述：获取该节点的父节点key值。

key [in] dword，物体的节点key值

return dword，父节点key值

示例：
dword key = getkey("/scene/modules/main/model/船桨pbr.vis/group1_FBXASC0560FBXASC03269FBXASC03257FBXASC032100");
dword owner_key = getkey("/scene/modules/main/model/船桨pbr.vis");
dword ownerKey = getOwnerKey(key);
if(owner_key == ownerKey)
{
        messageBox("同一个父节点");
}
