# 具身智能无人船仿真平台
## 简介
2025年3月14日（圆周率日），我们正式提出具身信息物理系统和具身域创新概念，推出基于MWORKS的具身空间仿真平台（Embodied Space Simulation Platform）框架，并初步探索形成具身智能无人船案例。

## 使用说明
1.  部署前说明
该版本的具身智能无人船平台需要安装 MWORKS.Sysplorer 2025a。具身智能无人船平台 V1.0完整文件如下图：
 ![image.png](/mohub/resource/question/image_1741934346231.png)
1-具身智能无人船平台模型库，为Sysplorer平台构建的无人船系统模型库； 
2-rosbridge安装包，为rosbridge服务python安装包； 
3-Unity视景软件，为无人船视景软件exe； 
4-ros通信工程，为基于python的ros通信框架文件； 
5-部署与操作说明，为具身智能无人船平台部署与操作说明文档。
