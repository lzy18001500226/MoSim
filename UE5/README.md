# Unreal External Renderer

This folder contains the project-owned Unreal bridge used to visualize MWORKS
simulation results. It is not the source of simulation truth.

## Keep

```text
unreal/MworksUnrealRenderer/
unreal/QuadrotorMworksBridge/
```

`MworksUnrealRenderer` is the UE project shell. `QuadrotorMworksBridge` provides
the project UDP/playback bridge for MWORKS state, trajectory, radar, and camera
review.

## Do Not Recreate

The previous generated map experiments are retired:

- RflySim `OldFactory` direct mount/open attempts;
- project-owned primitive factory blockouts;
- YunZong/Sunray primitive scene reconstructions;
- migration-staging metadata packages;
- grid/STL/semantic-box maps as final visual scenes.

They were useful for renderer plumbing, but they are not acceptable final visual
assets.

## Current Direction

Use real editable Unreal/Fab/Epic/open-source scene assets as the visual base,
then connect the existing MWORKS playback bridge.

Target scene families:

- factory / warehouse / industrial patrol;
- forest / park / campus navigation;
- indoor corridor / cave / gate traversal;
- open outdoor wind and robustness scenes.

MWORKS/Sysplorer remains responsible for dynamics, control, planning,
collision-truth, and metrics. Unreal is only for rendering, camera review,
visual overlays, and demo video.

## Generated Files

Do not commit:

```text
unreal/**/Binaries/
unreal/**/Intermediate/
unreal/**/Saved/
unreal/**/DerivedDataCache/
```

These folders are generated by Unreal and may be safely deleted when cleaning
the workspace.
