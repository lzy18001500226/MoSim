# 07 场景库、扰动库与测试矩阵

## 1. 场景分类

| 分类 | 场景 |
|---|---|
| 基础 | 悬停、阶跃、圆轨迹 |
| 复杂轨迹 | 8字、螺旋、S型搜索 |
| 鲁棒性 | 风扰、质量变化、惯量变化 |
| 故障 | 电机效率下降、电机延迟、传感器噪声 |
| 规划 | 单障碍、多障碍、狭窄通道 |
| 编队 | 三角编队、队形切换、编队绕障 |
| 业务 | 城市巡检、物流配送、应急搜索 |

---

## 2. 基础场景

悬停：

```text
p_ref=[0,0,2]
```

阶跃：

```text
A=[0,0,1] → B=[2,2,2]
```

圆轨迹：

```text
x=Rcos(wt), y=Rsin(wt), z=z0
```

---

## 3. 复杂轨迹

8 字：

```text
x=A sin(wt)
y=B sin(2wt)
z=z0
```

螺旋：

```text
x=Rcos(wt)
y=Rsin(wt)
z=z0+vzt
```

S 型搜索：

```text
x=vt
y=A sin(wt)
```

---

## 4. 业务场景

城市巡检：

```text
螺旋爬升 + 障碍物 + 横风
```

物流配送：

```text
起飞 → 绕障 → 投递 → 质量变化 → 返航
```

应急搜索：

```text
S型搜索 + 阵风 + 定点悬停
```

编队巡检：

```text
三机横队/三角队形区域巡检
```

---

## 5. 扰动库

恒定风：

```yaml
wind: {type: constant, value: [1.0,0,0]}
```

阵风：

```yaml
wind: {type: gust, amplitude: [1,0.3,0], frequency: 0.5}
```

质量变化：

```yaml
mass_scale: 1.2
```

投递：

```yaml
mass_schedule:
  - {time: 0, scale: 1.2}
  - {time: 15, scale: 1.0}
```

电机故障：

```yaml
motor_efficiency:
  start_time: 10
  eta: [1.0,0.7,1.0,1.0]
```

传感器噪声：

```yaml
sensor_noise:
  position_std: 0.02
  attitude_std: 0.005
```

## 8. 场景配置示例

```yaml
scene_id: formation_obstacle_fault
duration: 40
dt: 0.01

task:
  type: formation_obstacle
  start: [0,0,1]
  goal: [10,6,2]

map:
  obstacles:
    - type: box
      min: [3,2,0]
      max: [5,4,3]

planner:
  algorithm: rrt_star
  smoother: min_snap

controller:
  type: nmpc_indi_l1_safe

formation:
  type: triangle
  uav_count: 3
  spacing: 1.5

disturbance:
  wind:
    type: constant
    value: [1,0,0]
  motor_efficiency:
    start_time: 20
    eta: [1,0.7,1,1]
```
