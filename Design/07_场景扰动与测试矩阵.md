# 07 场景库、扰动库与测试矩阵

## 1. 场景分类

| 分类 | 场景 |
|---|---|
| 基础 | 悬停、阶跃、圆轨迹 |
| 复杂轨迹 | 8字、螺旋、S型搜索 |
| 鲁棒性 | 风扰、质量变化、惯量变化 |
| 故障 | 电机效率下降、电机延迟、传感器噪声 |
| 规划 | 单障碍、多障碍、狭窄通道 |
| 编队 | 三角编队、队形切换、编队绕障 |
| 业务 | 城市巡检、物流配送、应急搜索 |
| 自适应任务 | 风场穿越、投递返航、故障降级、狭窄通道队形切换 |

---

## 2. 基础场景

悬停：

```text
p_ref=[0,0,2]
```

阶跃：

```text
A=[0,0,1] → B=[2,2,2]
```

圆轨迹：

```text
x=Rcos(wt), y=Rsin(wt), z=z0
```

---

## 3. 复杂轨迹

8 字：

```text
x=A sin(wt)
y=B sin(2wt)
z=z0
```

螺旋：

```text
x=Rcos(wt)
y=Rsin(wt)
z=z0+vzt
```

S 型搜索：

```text
x=vt
y=A sin(wt)
```

---

## 4. 业务场景

城市巡检：

```text
螺旋爬升 + 障碍物 + 横风
```

物流配送：

```text
起飞 → 绕障 → 投递 → 质量变化 → 返航
```

应急搜索：

```text
S型搜索 + 阵风 + 定点悬停
```

编队巡检：

```text
三机横队/三角队形区域巡检
```

故障返航：

```text
巡检中电机效率下降 → 模式切换 → 降速返航或安全降落
```

风场穿越：

```text
进入风扰区域 → WIND_REJECTION → 离开风场后恢复 NORMAL
```

---

## 5. 扰动库

恒定风：

```yaml
wind: {type: constant, value: [1.0,0,0]}
```

阵风：

```yaml
wind: {type: gust, amplitude: [1,0.3,0], frequency: 0.5}
```

质量变化：

```yaml
mass_scale: 1.2
```

投递：

```yaml
mass_schedule:
  - {time: 0, scale: 1.2}
  - {time: 15, scale: 1.0}
```

电机故障：

```yaml
motor_efficiency:
  start_time: 10
  eta: [1.0,0.7,1.0,1.0]
```

传感器噪声：

```yaml
sensor_noise:
  position_std: 0.02
  attitude_std: 0.005
```

## 7.1 创新展示测试矩阵

| 场景 | 展示创新 | 必须输出 |
|---|---|---|
| baseline_vs_mpc_indi | 控制器主线对比 | RMSE、max_error、trajectory_3d、rmse_bar |
| wind_corridor | 扰动识别与模式切换 | controller_mode、disturbance_hat、recovery_time |
| delivery_mass_change | 质量变化自适应 | event_log、steady_error、mass_mode_duration |
| motor_fault_return | 故障诊断与降级返航 | fault_type、eta、return_or_land_status |
| obstacle_formation_replay | 可跟踪规划、编队切换、三维回放 | trackability_score、min_inter_uav_distance、replay.json |
| system_battery_low | PX4-like 低电量返航 | voltage_margin、battery_low_active、flight_mode、event_code |
| system_offboard_loss | 外部控制链路丢失返航 | offboard_loss_active、flight_mode、active_setpoint_source、event_code |
| system_mission_failure | 任务不可行降级返航 | mission_failure_active、flight_mode、safety_status、event_code |
| system_geofence_breach | 地理围栏越界返航 | geofence_breach_active、flight_mode、safety_status、event_code |

## 8. 场景配置示例

```yaml
scene_id: formation_obstacle_fault
duration: 40
dt: 0.01

task:
  type: formation_obstacle
  start: [0,0,1]
  goal: [10,6,2]

map:
  obstacles:
    - type: box
      min: [3,2,0]
      max: [5,4,3]

planner:
  algorithm: rrt_star
  smoother: min_snap

controller:
  type: nmpc_indi_l1_safe

task_manager:
  enabled: true
  target: delivery_or_return
  mode_switch: true

formation:
  type: triangle
  uav_count: 3
  spacing: 1.5

disturbance:
  wind:
    type: constant
    value: [1,0,0]
  motor_efficiency:
    start_time: 20
    eta: [1,0.7,1,1]

evaluation:
  health_score: true
  replay_export: true
```
