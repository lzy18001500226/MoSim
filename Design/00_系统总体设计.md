# 00 系统总体设计

## 1. 项目定位

项目名称建议：

**面向复杂任务场景的四旋翼无人机自适应鲁棒位姿控制与智能仿真验证系统**

核心口径：

> 以 MWORKS 四旋翼模型为基础，围绕“官方 PID baseline → 改进 PID → PID-INDI/MPC-INDI → 扰动补偿”的逐级消融路线，完成复杂轨迹跟踪、风扰/质量摄动鲁棒性验证和量化评估；在主线稳定的基础上扩展安全过滤、故障注入、路径规划、编队与 Syslab/MCP 自动化评估。

## 4. 关键创新点

### 4.1 控制算法创新

1. **逐级消融控制路线**：PID → 改进 PID → PID-INDI/线性 MPC-INDI → NMPC-INDI → +L1-inspired 补偿 → +Safety/Fault。
2. **可回退的鲁棒位姿控制架构**：以改进 PID/PID-INDI 保证初赛稳定闭环，以 MPC/NMPC 和扰动补偿冲击高分。
3. **执行器效率退化容错**：通过效率矩阵建模和控制分配重构评估故障恢复能力。

### 4.2 规划与任务创新

1. 规划算法多路线可替换：A*、RRT*、Kinodynamic A*、人工势场、B-spline 优化、Minimum Snap。
2. 轻量 EGO-inspired 局部规划：不完整构建 ESDF，而用局部障碍物几何距离构造碰撞代价。
3. 动态可行轨迹输出：速度、加速度、jerk、倾角约束检查后再交给控制器跟踪。

### 4.3 多机协同创新

1. Leader-Follower 编队；
2. 多队形配置；
3. 平滑队形切换；
4. 机间安全距离约束；
5. Leader 规划绕障 + Follower 偏移跟随。

### 4.4 工程验证创新

1. 多场景扰动测试矩阵；
2. 风扰、质量摄动、电机效率下降、传感器噪声；
3. Syslab 批量实验与自动指标；
4. MCP 辅助模型检查、仿真调用、结果读取。

## 8. 参考算法路线

| 方向 | 借鉴点 | 本项目定位 |
|---|---|---|
| Minimum Snap | 四旋翼平滑轨迹、速度/加速度连续 | P2 轨迹平滑或离线参考生成 |
| EGO-Planner / Fast-Planner | ESDF-free、B-spline、局部优化思想 | 只借鉴轻量思想，不完整移植 ROS 栈 |
| INDI | 角加速度反馈、降低模型依赖 | P1 姿态内环增强 |
| MPC/NMPC | 约束跟踪、预测优化 | P1/P2 外环增强，保留线性 MPC 回退 |
| L1 adaptive control | 快速扰动补偿思想 | 采用 L1-inspired 残差估计与低通补偿 |
| CBF / Safety Filter | 安全关键约束保护 | P1/P2 安全过滤，初赛可用裁剪式限幅 |
| MCP | 模型查询、仿真调用、结果读取 | P2 自动化验证辅助，不作为控制算法创新 |
