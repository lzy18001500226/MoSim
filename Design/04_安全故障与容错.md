# 04 安全约束、故障注入与容错控制详细设计

## 1. 设计目标

安全和故障模块用于保证控制器输出可执行、飞行过程不越界、多机不碰撞，并验证系统在执行器故障下的鲁棒性。

---

## 2. Safety Filter 类型

### 2.1 控制指令过滤

```text
raw command → clamp/project → safe command
```

约束：

```text
|roll| <= roll_max
|pitch| <= pitch_max
T_min <= T <= T_max
u_min <= u_i <= u_max
```

### 2.2 轨迹安全检查

```text
trajectory → velocity/acc/jerk/collision check → safe trajectory
```

### 2.3 编队安全检查

```text
multi-UAV references → inter-distance check → adjusted references
```

---

## 3. 基础安全约束

| 类别 | 约束 |
|---|---|
| 姿态 | roll/pitch/yaw rate 限制 |
| 推力 | 总推力、电机推力限制 |
| 速度 | 最大速度 |
| 加速度 | 最大加速度 |
| 高度 | 最低高度 |
| 障碍物 | 最小障碍距离 |
| 编队 | 最小机间距离 |
| 控制平滑 | 最大控制变化率 |

---

## 4. 裁剪式安全过滤

```pseudo
roll_ref = clamp(roll_ref, -roll_max, roll_max)
pitch_ref = clamp(pitch_ref, -pitch_max, pitch_max)
thrust = clamp(thrust, T_min, T_max)

if z < z_min:
    z_ref = z_min + margin
```

优点：简单稳定。  
缺点：可能破坏最优性。

---

## 5. QP 投影式安全过滤

```text
u_safe = argmin ||u - u_raw||²
s.t. constraints
```

可用于：

1. 推力限幅；
2. 倾角限幅；
3. 避障速度约束；
4. 机间距离约束。

---

## 6. CBF-inspired 设计

障碍物安全函数：

```text
h(p) = ||p - p_obs||² - d_safe²
```

安全条件：

```text
h(p) >= 0
```

CBF 约束：

```text
h_dot + α h >= 0
```

构造 QP：

```text
min ||u-u_raw||²
s.t. h_dot + αh >= 0
```

初赛不一定实现完整 CBF，可写为“CBF-inspired 安全过滤”。

## 7. 执行器故障模型

### 7.1 电机效率下降

```text
f_i_actual = η_i f_i_cmd
```

典型：

```text
η = [1.0, 0.7, 1.0, 1.0]
```

### 7.2 电机响应延迟

```text
f_dot = (f_cmd - f_actual) / τ_m
```

故障时：

```text
τ_m_fault = 2τ_m
```

### 7.3 电机饱和

```text
f_i = clamp(f_i_cmd, f_min, f_max)
```

## 8. 故障检测

### 8.1 残差

```text
r = ω_dot_meas - ω_dot_pred
```

或：

```text
r_a = a_meas - a_model
```

### 8.2 阈值

```pseudo
if norm(r) > threshold for N samples:
    fault_detected = true
```

---

## 9. 控制分配重构

正常：

```text
y = Bf
f = B^{-1}y
```

故障：

```text
B_fault = B diag(η)
f = pinv(B_fault)y
```

带约束：

```text
min ||B_fault f - y||² + λ||f||²
s.t. f_min <= f <= f_max
```

## 10. 容错模式

```text
NORMAL
DISTURBANCE_REJECTION
SAFETY_PROTECTION
FAULT_TOLERANT
EMERGENCY_LAND
```

切换逻辑：

```pseudo
if motor_eta < 0.6:
    mode = EMERGENCY_LAND
elif motor_fault:
    mode = FAULT_TOLERANT
elif obstacle_distance < d_safe:
    mode = SAFETY_PROTECTION
elif wind > wind_threshold:
    mode = DISTURBANCE_REJECTION
else:
    mode = NORMAL
```
