# 04 安全约束、故障注入与容错控制详细设计

## 1. 设计目标

安全和故障模块用于保证控制器输出可执行、飞行过程不越界、多机不碰撞，并验证系统在执行器故障下的鲁棒性。

---

## 1.1 功能拆分

安全与故障功能拆成 4 个独立模块，避免实现时互相绑定：

| 模块 | 作用 | 输入 | 输出 | 优先级 |
|---|---|---|---|---|
| safety_filter | 对姿态、推力、速度、高度、障碍距离和机间距离进行约束保护 | raw command / state / limits | safe command | P1 |
| fault_injector | 按场景配置注入电机效率下降、响应延迟或饱和 | motor_cmd / fault_config | motor_actual / eta | P1 |
| fault_detector | 根据残差判断是否发生故障 | state / motor / residual | fault_flag / fault_type | P2 |
| fault_reallocator | 根据 eta 或故障估计重构控制分配 | desired wrench / eta | motor_cmd_reallocated | P2 |

初版可直接由场景配置给定 `eta`，先完成故障注入和对比实验；故障检测作为增强功能，不阻塞 Safety 和 Fault Reallocation。

推荐链路：

```text
controller
  → safety_filter
  → fault_reallocator
  → fault_injector
  → motor/plant
```

## 2. Safety Filter 类型

### 2.1 控制指令过滤

```text
raw command → clamp/project → safe command
```

约束：

```text
|roll| <= roll_max
|pitch| <= pitch_max
T_min <= T <= T_max
u_min <= u_i <= u_max
```

### 2.2 轨迹安全检查

```text
trajectory → velocity/acc/jerk/collision check → safe trajectory
```

### 2.3 编队安全检查

```text
multi-UAV references → inter-distance check → adjusted references
```

## 3. 基础安全约束

| 类别 | 约束 |
|---|---|
| 姿态 | roll/pitch/yaw rate 限制 |
| 推力 | 总推力、电机推力限制 |
| 速度 | 最大速度 |
| 加速度 | 最大加速度 |
| 高度 | 最低高度 |
| 障碍物 | 最小障碍距离 |
| 编队 | 最小机间距离 |
| 控制平滑 | 最大控制变化率 |

---

## 4. 裁剪式安全过滤

```pseudo
roll_ref = clamp(roll_ref, -roll_max, roll_max)
pitch_ref = clamp(pitch_ref, -pitch_max, pitch_max)
thrust = clamp(thrust, T_min, T_max)

if z < z_min:
    z_ref = z_min + margin
```

优点：简单稳定。  
缺点：可能破坏最优性。

---

## 5. QP 投影式安全过滤

```text
u_safe = argmin ||u - u_raw||²
s.t. constraints
```

可用于：

1. 推力限幅；
2. 倾角限幅；
3. 避障速度约束；
4. 机间距离约束。

---

## 6. CBF-inspired 设计

障碍物安全函数：

```text
h(p) = ||p - p_obs||² - d_safe²
```

安全条件：

```text
h(p) >= 0
```

CBF 约束：

```text
h_dot + α h >= 0
```

构造 QP：

```text
min ||u-u_raw||²
s.t. h_dot + αh >= 0
```

初赛不一定实现完整 CBF，可写为“CBF-inspired 安全过滤”。

## 7. 执行器故障模型

### 7.1 电机效率下降

```text
f_i_actual = η_i f_i_cmd
```

典型：

```text
η = [1.0, 0.7, 1.0, 1.0]
```

### 7.2 电机响应延迟

```text
f_dot = (f_cmd - f_actual) / τ_m
```

故障时：

```text
τ_m_fault = 2τ_m
```

### 7.3 电机饱和

```text
f_i = clamp(f_i_cmd, f_min, f_max)
```

## 8. 故障检测

### 8.1 残差

```text
r = ω_dot_meas - ω_dot_pred
```

或：

```text
r_a = a_meas - a_model
```

### 8.2 阈值

```pseudo
if norm(r) > threshold for N samples:
    fault_detected = true
```

## 9. 控制分配重构

正常：

```text
y = Bf
f = B^{-1}y
```

故障：

```text
B_fault = B diag(η)
f = pinv(B_fault)y
```

带约束：

```text
min ||B_fault f - y||² + λ||f||²
s.t. f_min <= f <= f_max
```

## 10. 容错模式

```text
NORMAL
DISTURBANCE_REJECTION
SAFETY_PROTECTION
FAULT_TOLERANT
EMERGENCY_LAND
```

切换逻辑：

```pseudo
if motor_eta < 0.6:
    mode = EMERGENCY_LAND
elif motor_fault:
    mode = FAULT_TOLERANT
elif obstacle_distance < d_safe:
    mode = SAFETY_PROTECTION
elif wind > wind_threshold:
    mode = DISTURBANCE_REJECTION
else:
    mode = NORMAL
```

### 10.1 故障等级与降级策略

| 等级 | eta | 策略 | 验收口径 |
|---|---:|---|---|
| 轻度 | 0.9 | 继续任务，记录性能退化 | RMSE 和饱和比例可接受 |
| 中度 | 0.7 | 启用 fault_reallocator，对比有/无重构 | 最大误差或饱和比例下降 |
| 重度 | 0.5 | 不承诺继续完成任务，进入降级或 emergency_land | 保持可控下降或安全终止 |

重度故障不要作为“性能提升”主结论，只作为安全降级展示。

降级策略：

```pseudo
if eta_min >= 0.85:
    mode = NORMAL_OR_LIGHT_FAULT
elif eta_min >= 0.65:
    mode = FAULT_TOLERANT
elif eta_min >= 0.5:
    mode = DEGRADED_RETURN_OR_LAND
else:
    mode = EMERGENCY_LAND
```

### 10.2 safety_filter 实现规格

输入：

```text
thrust_ref
attitude_ref
state_bus
safety_limits
```

输出：

```text
thrust_safe
attitude_ref_safe
debug.constraint_violation
debug.safety_mode
```

P1 裁剪式实现：

```pseudo
roll_ref = clamp(roll_ref, -roll_max, roll_max)
pitch_ref = clamp(pitch_ref, -pitch_max, pitch_max)
thrust_ref = clamp(thrust_ref, thrust_min, thrust_max)

if state.z < z_min:
    thrust_ref = max(thrust_ref, hover_thrust + climb_margin)
    safety_mode = LOW_ALTITUDE_PROTECTION
```

P2 再加入障碍物/机间距离 QP 或 CBF-inspired 约束。

### 10.3 fault_injector 实现规格

输入：

```text
motor_cmd[4]
fault_config
time
```

输出：

```text
motor_cmd_actual[4]
eta[4]
fault_event
```

伪代码：

```pseudo
eta = [1, 1, 1, 1]
if time >= fault.start_time:
    eta = fault.eta

for i in 1..4:
    motor_cmd_actual[i] = eta[i] * motor_cmd[i]
```

事件日志：

```json
{
  "time": 12.0,
  "event": "motor_efficiency_drop",
  "motor": 2,
  "eta": 0.7
}
```

### 10.4 fault_reallocator 实现规格

输入：

```text
desired_wrench = [T, tau_x, tau_y, tau_z]
eta[4]
motor_limits
allocation_matrix
```

输出：

```text
motor_cmd_reallocated[4]
debug.allocation_error
debug.saturation_ratio
```

实现：

```pseudo
B_fault = B * diag(eta)
f_cmd = pinv(B_fault) * desired_wrench
f_cmd = clamp(f_cmd, f_min, f_max)
allocation_error = norm(B_fault * f_cmd - desired_wrench)
```

验收：

```text
motor_fault_eta70:
  +Fault Reallocation 的 max_error 或 saturation_ratio 低于 no Reallocation
```

## 11. 实验设计

| 实验 | 对比 |
|---|---|
| 倾角限制 | Safety vs no Safety |
| 障碍物距离 | Safety vs no Safety |

| 横风 + 故障 | L1 vs no L1 |
| 编队机间距离 | Safety vs no Safety |

