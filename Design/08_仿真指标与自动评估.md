## 4. 控制指标

位置 RMSE：

```text
RMSE = sqrt(mean(||p-p_ref||²))
```

最大误差：

```text
Emax=max||p-p_ref||
```

稳态误差：

```text
Ess=mean(error in last T seconds)
```

超调量：

```text
OS=(max-response-target)/target
```

调节时间：

```text
error enters tolerance band and stays
```

推荐统一口径：

| 指标 | 统计口径 |
|---|---|
| RMSE | 全时段位置三维误差的均方根 |
| max_error | 全时段最大三维位置误差 |
| steady_error | 最后 5 s 的平均位置误差；若总时长小于 10 s，取最后 20% 时段 |
| overshoot | 仅用于阶跃场景，按目标方向单轴响应统计 |
| settling_time | 误差进入 0.1 m 或目标幅值 5% 容差带，并持续 2 s |
| recovery_time | 扰动开始后，误差重新进入 0.2 m 容差带并持续 2 s 的时间 |

## 11. metrics.csv

```csv
experiment_id,controller,scene,status,rmse,max_error,steady_error,settling_time,overshoot,recovery_time,energy,smoothness,saturation,min_altitude,min_obs_dist,min_inter_uav_dist,formation_rmse,notes
```

其中 status 取值：

```text
success
failure
partial
```

failure 判据与 `01_需求范围与验收.md` 保持一致：

```text
z < 0.1 m
|roll| 或 |pitch| > 60 deg 持续超过 0.5 s
位置误差 > 5 m 持续超过 2 s
任一电机指令饱和比例 > 80%
仿真提前终止或无结果文件
```

## 17. Syslab/MCP 自动化评估

### 17.1 定位

Syslab 是 P0/P1 指标计算主工具，MCP 是 P2 自动化辅助，不改变控制算法本身。

```text
MWORKS 仿真
  → 结果导出 raw.csv
  → Syslab 指标计算和绘图
  → 可选 MCP 模型查询/仿真调用/结果读取
```

### 17.2 自动化流程

```text
batch_config.yaml
    ↓
读取 scene/controller 列表
    ↓
检查模型和参数
    ↓
运行仿真或提示手动运行
    ↓
读取 raw.csv
    ↓
计算 metrics.csv
    ↓
生成 figures 和 summary.md
```

### 17.3 MCP 能力映射

| 工具类别 | 用途 |
|---|---|
| Sysplorer session/model/check/simulate | 会话、模型打开、模型检查、仿真调用 |
| Sysplorer result/plot | 结果读取、绘图动画 |
| Syslab run/evaluate | 执行指标脚本、绘图脚本 |
| Syslab docs/search | 平台 API 和函数文档查询 |

### 17.4 MCP 裁剪路线

```text
全流程自动化
→ 结果读取自动化
→ 模型查询自动化
→ MCP 工具列表截图
→ 手动仿真 + Syslab 脚本
```
