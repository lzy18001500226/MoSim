# 03 控制系统详细设计：PID、NMPC、INDI、L1

## 1. 控制架构总览

```text
reference trajectory
    ↓
PID / MPC / NMPC outer loop
    ↓
desired acceleration / thrust / attitude
    ↓
disturbance compensation
    ↓
Safety Filter
    ↓
INDI attitude inner loop
    ↓
control allocation
    ↓
motor command
```

## 3. PID baseline 与改进 PID

### 3.1 baseline 分析重点

- Kp、Ki、Kd；
- 积分限幅；
- 电机输出限幅；
- 阶跃超调；
- 8 字跟踪滞后；
- 风扰下稳态误差。

### 3.2 改进项

```text
u = Kp e + Ki ∫e dt + Kd de/dt + Kff a_ref
```

加入：

1. 积分抗饱和；
2. 导数低通滤波；
3. 加速度前馈；
4. 速度阻尼；
5. 输出限幅；
6. 参数配置化。

### 3.3 改进 PID 实现规格

## 4. NMPC 外环

NMPC 是高分主线，但不作为初赛唯一可行路线。若实时求解、平台接口或参数整定风险较高，可先实现线性 MPC 或 PID-INDI，确保 P0/P1 闭环稳定，再逐步替换为 NMPC。

### 4.1 简化状态

```text
X = [x, y, z, vx, vy, vz]^T
U = [ax, ay, az]^T
```

### 4.2 离散模型

```text
p(k+1) = p(k) + v(k) dt
v(k+1) = v(k) + a(k) dt
```

### 4.3 目标函数

```text
J = Σ [
    ||p - p_ref||²_Qp
  + ||v - v_ref||²_Qv
  + ||a||²_R
  + ||a_k - a_{k-1}||²_Rd
]
```

### 4.4 约束

```text
||v|| <= v_max
||a|| <= a_max
T_min <= T <= T_max
|roll_ref| <= roll_max
|pitch_ref| <= pitch_max
```

### 4.5 推荐参数

```yaml
dt_nmpc: 0.05
N: 20
Qp: [10, 10, 15]
Qv: [2, 2, 3]
R: [0.2, 0.2, 0.3]
Rd: [0.5, 0.5, 0.8]
```

### 4.6 输出转换

```text
a_cmd → T_ref, roll_ref, pitch_ref
```

近似：

```text
T_ref = m ||g e_z + a_cmd||
tilt ≈ atan(||a_xy|| / (g + a_z))
```

更完整的加速度到姿态转换：

```pseudo
function accel_to_attitude(a_cmd, yaw_ref, mass):
    g_vec = [0, 0, g]
    f_des = mass * (g_vec + a_cmd)
    z_b_des = normalize(f_des)

    x_c = [cos(yaw_ref), sin(yaw_ref), 0]
    y_b_des = normalize(cross(z_b_des, x_c))
    x_b_des = cross(y_b_des, z_b_des)

    R_des = [x_b_des, y_b_des, z_b_des]
    attitude_ref = rotation_to_euler(R_des)
    thrust_ref = dot(f_des, z_b_des)
    return thrust_ref, attitude_ref
```

若姿态转换与平台坐标系不一致，以 `02_模型接口与运行流程.md` 中坐标变换为准。

### 4.7 MPC/NMPC 实现规格

模块名：

```text

controller_nmpc_indi
```

最低可实现版本：

```text
线性 MPC 使用 6 状态双积分模型，输出期望加速度 a_cmd。
NMPC 使用同一接口，若求解失败，自动回退上一时刻可行解或改进 PID 输出。
```

核心函数：

```text

build_cost_function()
apply_constraints()
solve_mpc()
fallback_if_solver_failed()
accel_to_attitude()
```

求解失败回退：

```pseudo
if solver_status != success:
    if last_solution_valid:
        a_cmd = last_solution.a0
    else:
        a_cmd = pid_improved_outer_loop(state, ref)
    debug.solver_fallback = true
```

```text

```

## 5. INDI 姿态内环

### 5.1 思路

INDI 不直接依赖完整模型，而使用传感器估计的角加速度和控制增量。

```text
u_k = u_{k-1} + Δu
```

### 5.2 控制律

```text
Δu = G^{-1} (ν - ω_dot_meas)
```

其中：

```text
ν = K_att e_att + K_rate e_rate
```

若直接以力矩为控制：

```text
τ_cmd = τ_prev + J(ν - ω_dot_meas)
```

### 5.3 角加速度估计

```text
ω_dot = (ω_k - ω_{k-1}) / dt
ω_dot_f = α ω_dot_f_prev + (1-α)ω_dot
```

建议：

```text
α = 0.8 ~ 0.95
```

### 5.4 限幅

```text
||Δu|| <= Δu_max
||u|| <= u_max
```

### 5.5 INDI 实现规格

模块名：

```text
attitude_indi_inner_loop
```

输入：

```text
attitude_ref
angular_rate_ref
state_bus.attitude
state_bus.angular_rate
state_bus.angular_acceleration
previous_torque_cmd
```

输出：

```text
torque_cmd
debug.angular_acc_f
debug.delta_torque
```

核心函数：

```text
compute_attitude_error()
estimate_angular_acceleration()
filter_angular_acceleration()
compute_virtual_control()
compute_incremental_torque()
limit_torque_rate()
```

实现伪代码：

```pseudo
e_att = attitude_ref - attitude
e_rate = angular_rate_ref - angular_rate
nu = K_att * e_att + K_rate * e_rate

omega_dot_raw = (angular_rate - angular_rate_prev) / dt
omega_dot_f = alpha * omega_dot_f_prev + (1-alpha) * omega_dot_raw

delta_tau = J * (nu - omega_dot_f)
delta_tau = clamp(delta_tau, -delta_tau_max, delta_tau_max)
tau_cmd = clamp(tau_prev + delta_tau, -tau_max, tau_max)
```

参数示例：

```yaml
indi:
  dt: 0.005
  k_att: [8.0, 8.0, 4.0]
  k_rate: [0.25, 0.25, 0.15]
  angular_acc_alpha: 0.9
  delta_torque_max: [0.03, 0.03, 0.02]
  torque_max: [0.2, 0.2, 0.1]
```

## 6. L1-inspired 扰动补偿

本模块采用“L1-inspired”表述，定位为基于加速度残差估计的低通扰动补偿，不宣称实现严格完整的 L1 自适应控制。报告中应强调其工程作用：估计风扰、质量变化和推力效率偏差带来的等效加速度误差，并对外环加速度指令进行补偿。

### 6.1 扰动估计

```text
a_meas = (v_k - v_{k-1}) / dt
a_model = g + (T/m) R e_z
d_hat = a_meas - a_model
```

### 6.2 递推估计

```text
d_hat(k+1) = (1 - λdt)d_hat(k) + γ e_v dt
```

### 6.3 低通滤波

```text
d_comp = LPF(d_hat)
```

### 6.4 补偿方式

```text
a_cmd_corrected = a_cmd - d_comp
```

或：

```text
T_corrected = T_ref + m d_comp_z
```

### 6.5 限幅

```text
||d_comp|| <= d_max
```

### 6.6 扰动补偿实现规格

P1 推荐只实现加速度残差估计：

```pseudo
a_meas = filtered_derivative(velocity)
a_model = [0, 0, -g] + thrust_ref / mass * R * e_z
d_hat_raw = a_meas - a_model
d_hat = alpha_d * d_hat_prev + (1-alpha_d) * d_hat_raw
d_comp = clamp(d_hat, -d_max, d_max)
a_cmd_corrected = a_cmd - d_comp
```

P2 再加入速度误差递推项：

```pseudo
d_hat = (1 - lambda * dt) * d_hat + gamma * (velocity_ref - velocity) * dt
```

参数示例：

```yaml
disturbance_compensation:
  enabled: true
  method: acceleration_residual
  alpha: 0.85
  d_max: [2.0, 2.0, 2.0]
  gamma: [0.1, 0.1, 0.1]
  lambda: 1.0
```

验收：

```text
figure8_wind: RMSE 或 recovery_time 优于 no compensation
spiral_mass_change: steady_error 优于 no compensation
```

## 7. 控制器伪代码

```pseudo
function step(state, ref):
    a_raw = solve_nmpc(state, ref)
    d_hat = estimate_disturbance(state)
    d_comp = low_pass(d_hat)
    a_cmd = a_raw - d_comp

    thrust_ref, attitude_ref = accel_to_attitude(a_cmd, ref.yaw)
    thrust_ref, attitude_ref = safety_filter(thrust_ref, attitude_ref, state)

    torque_cmd = indi(attitude_ref, state.attitude, state.angular_rate)
    motor_cmd = allocate(thrust_ref, torque_cmd, motor_efficiency)

    return motor_cmd
```

通用控制器接口：

```pseudo
function controller_step(state_bus, reference_bus, params, memory):
    state = state_preprocessor(state_bus, memory)
    ref = reference_bus

    a_cmd = outer_loop(state, ref, params.outer)
    a_cmd = disturbance_compensator(a_cmd, state, ref, params.disturbance)
    thrust_ref, attitude_ref = accel_to_attitude(a_cmd, ref.yaw, params.mass)
    thrust_ref, attitude_ref = safety_filter(thrust_ref, attitude_ref, state, params.safety)
    torque_cmd = attitude_inner_loop(attitude_ref, state, params.inner)
    motor_cmd = control_allocation(thrust_ref, torque_cmd, params.allocation)

    return motor_cmd, debug, memory
```

## 11. 控制器验收指标

| 控制器 | 必要场景 | 通过标准 |
|---|---|---|
| PID baseline | 悬停、阶跃、8 字、螺旋 | 可稳定运行并导出完整数据 |
| Improved PID | 阶跃、8 字、风扰 | 相比 baseline 至少 1 项核心指标改善 |
| PID-INDI | 姿态阶跃、8 字 | 姿态峰值误差或位置 RMSE 低于 baseline |
| MPC/NMPC-INDI | 8 字、螺旋 | 复杂轨迹 RMSE 低于 improved PID |
| L1-inspired 补偿 | 风扰、质量变化 | 稳态误差、RMSE 或恢复时间至少 1 项下降 |
| Safety/Fault | 限幅、eta=0.7 故障 | 约束违规次数、最大误差或饱和比例下降 |

核心报告口径：

```text
PID baseline → Improved PID → PID-INDI/MPC-INDI → +disturbance compensation
```

每增加一个模块，都必须有消融实验说明其收益；若某高级模块效果不稳定，则在报告中作为探索方案，主结论回退到已稳定通过验收的控制器。
