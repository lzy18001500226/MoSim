# 03 控制系统详细设计：PID、NMPC、INDI、L1

## 1. 控制架构总览

```text
reference trajectory
    ↓
task_mode_manager
    ↓
PID / MPC / NMPC outer loop
    ↓
desired acceleration / thrust / attitude
    ↓
disturbance compensation
    ↓
Safety Filter
    ↓
INDI attitude inner loop
    ↓
control allocation
    ↓
motor command
```

|---|---|---|

## 3. PID baseline、改进 PID 与 AWFF PID

### 3.1 baseline 分析重点

- Kp、Ki、Kd；
- 积分限幅；
- 电机输出限幅；
- 阶跃超调；
- 8 字跟踪滞后；
- 风扰下稳态误差。

### 3.2 改进项

```text
u = Kp e + Ki ∫e dt + Kd de/dt + Kff a_ref
```

加入：

1. 积分抗饱和；
2. 导数低通滤波；
3. 加速度前馈；
4. 速度阻尼；
5. 输出限幅；
6. 参数配置化。

抗积分饱和建议：

```pseudo
if output_unsat != output_sat:
    integral = integral + k_aw * (output_sat - output_unsat) * dt
else:
    integral = integral + error * dt
integral = clamp(integral, -integral_max, integral_max)
```

导数滤波：

```pseudo
d_error_raw = (error - error_prev) / dt
d_error_f = alpha_d * d_error_f_prev + (1 - alpha_d) * d_error_raw
```

## 4. NMPC 外环

NMPC 是高分主线，但不作为初赛唯一可行路线。若实时求解、平台接口或参数整定风险较高，可先实现线性 MPC 或 PID-INDI，确保 P0/P1 闭环稳定，再逐步替换为 NMPC。

### 4.1 简化状态

```text
X = [x, y, z, vx, vy, vz]^T
U = [ax, ay, az]^T
```

### 4.2 离散模型

```text
p(k+1) = p(k) + v(k) dt
v(k+1) = v(k) + a(k) dt
```

### 4.3 目标函数

```text
J = Σ [
    ||p - p_ref||²_Qp
  + ||v - v_ref||²_Qv
  + ||a||²_R
  + ||a_k - a_{k-1}||²_Rd
]
```

### 4.4 约束

```text
||v|| <= v_max
||a|| <= a_max
T_min <= T <= T_max
|roll_ref| <= roll_max
|pitch_ref| <= pitch_max
```

### 4.5 推荐参数

```yaml
dt_nmpc: 0.05
N: 20
Qp: [10, 10, 15]
Qv: [2, 2, 3]
R: [0.2, 0.2, 0.3]
Rd: [0.5, 0.5, 0.8]
```

### 4.6 输出转换

```text
a_cmd → T_ref, roll_ref, pitch_ref
```

近似：

```text
T_ref = m ||g e_z + a_cmd||
tilt ≈ atan(||a_xy|| / (g + a_z))
```

更完整的加速度到姿态转换：

```pseudo
function accel_to_attitude(a_cmd, yaw_ref, mass):
    g_vec = [0, 0, g]
    f_des = mass * (g_vec + a_cmd)
    z_b_des = normalize(f_des)

    x_c = [cos(yaw_ref), sin(yaw_ref), 0]
    y_b_des = normalize(cross(z_b_des, x_c))
    x_b_des = cross(y_b_des, z_b_des)

    R_des = [x_b_des, y_b_des, z_b_des]
    attitude_ref = rotation_to_euler(R_des)
    thrust_ref = dot(f_des, z_b_des)
    return thrust_ref, attitude_ref
```

若姿态转换与平台坐标系不一致，以 `02_模型接口与运行流程.md` 中坐标变换为准。

## 5. INDI 姿态内环

### 5.1 思路

INDI 不直接依赖完整模型，而使用传感器估计的角加速度和控制增量。

```text
u_k = u_{k-1} + Δu
```

### 5.2 控制律

```text
Δu = G^{-1} (ν - ω_dot_meas)
```

其中：

```text
ν = K_att e_att + K_rate e_rate
```

若直接以力矩为控制：

```text
τ_cmd = τ_prev + J(ν - ω_dot_meas)
```

### 5.3 角加速度估计

```text
ω_dot = (ω_k - ω_{k-1}) / dt
ω_dot_f = α ω_dot_f_prev + (1-α)ω_dot
```

建议：

```text
α = 0.8 ~ 0.95
```

### 5.4 限幅

```text
||Δu|| <= Δu_max
||u|| <= u_max
```

### 5.5 INDI 实现规格

模块名：

```text
attitude_indi_inner_loop
```

输入：

```text
attitude_ref
angular_rate_ref
state_bus.attitude
state_bus.angular_rate
state_bus.angular_acceleration
previous_torque_cmd
```

输出：

```text
torque_cmd
debug.angular_acc_f
debug.delta_torque
```

核心函数：

```text
compute_attitude_error()
estimate_angular_acceleration()
filter_angular_acceleration()
compute_virtual_control()
compute_incremental_torque()
limit_torque_rate()
```

实现伪代码：

```pseudo
e_att = attitude_ref - attitude
e_rate = angular_rate_ref - angular_rate
nu = K_att * e_att + K_rate * e_rate

omega_dot_raw = (angular_rate - angular_rate_prev) / dt
omega_dot_f = alpha * omega_dot_f_prev + (1-alpha) * omega_dot_raw

delta_tau = J * (nu - omega_dot_f)
delta_tau = clamp(delta_tau, -delta_tau_max, delta_tau_max)
tau_cmd = clamp(tau_prev + delta_tau, -tau_max, tau_max)
```

参数示例：

```yaml
indi:
  dt: 0.005
  k_att: [8.0, 8.0, 4.0]
  k_rate: [0.25, 0.25, 0.15]
  angular_acc_alpha: 0.9
  delta_torque_max: [0.03, 0.03, 0.02]
  torque_max: [0.2, 0.2, 0.1]
```

## 6. L1-inspired 扰动补偿

本模块采用“L1-inspired”表述，定位为基于加速度残差估计的低通扰动补偿，不宣称实现严格完整的 L1 自适应控制。报告中应强调其工程作用：估计风扰、质量变化和推力效率偏差带来的等效加速度误差，并对外环加速度指令进行补偿。

当前已落地的 P1 版本采用工程化残差补偿，不直接依赖速度和推力模型变量，保持与 AWFF Sysblock 完全相同的 `controller3_2` 输入输出接口：

```text
models/QuadrotorControllerBlocks/AWFF_L1ResidualControllerEquation_Sysblock.mo
controllers/l1_residual_sysblock/default.yaml
models/QuadrotorExperiments/Example1L1SysblockClosedLoop.mo
models/QuadrotorExperiments/Example3L1SysblockClosedLoop.mo
models/QuadrotorExperiments/Example1Mass20L1SysblockClosedLoop.mo
models/QuadrotorExperiments/Example1WindGustL1SysblockClosedLoop.mo
models/QuadrotorExperiments/Example1Rotor1Loss15L1SysblockClosedLoop.mo
```

输入接口：

```text
x_error, y_error, z_error, z_ref_rate, roll_mea, pitch_mea, yaw_mea, yaw_ref
```

输出接口：

```text
y, y1, y2, y3
```

补偿逻辑：

```text
residual_i = filtered_derivative(error_i) + l1_model_decay * error_i
der(d_hat_i) = (l1_gain_i * residual_i - d_hat_i) / l1_filter_T
comp_i = clamp(d_hat_i, -limit_i, limit_i)
```

补偿位置：

```text
pitch_ref_raw  += 0.1 * comp_x
roll_ref_raw   += 0.1 * comp_y
thrust_ref_raw += comp_z
```

当前验证结果：`Example1L1SysblockClosedLoop`、`Example3L1SysblockClosedLoop`、`Example1Mass20L1SysblockClosedLoop`、`Example1WindGustL1SysblockClosedLoop` 和 `Example1Rotor1Loss15L1SysblockClosedLoop` 均已完成真实 Sysplorer MCP 仿真。Example1、8 字形、质量 +20% 和横向阵风均通过质量门；横向阵风中，相比 `awff_sysblock`，`position_rmse_m` 降低 `12.568%`，`disturbance_peak_error_m` 降低 `22.210%`，恢复时间缩短 `12.308%`。旋翼退化中单独 L1 仍为 `needs_iteration`，但 `Example1Rotor1Loss15L1FaultAllocationSysblockClosedLoop` 在已知 `eta=0.85` 条件下通过质量门，RMSE 相比 `awff_sysblock` 降低 `33.793%`；`Example1Rotor1Loss15L1OnlineFaultAllocationSysblockClosedLoop` 不直接读取真实 eta，使用残差驱动 `eta_hat` 估计并通过质量门，RMSE 相比 `awff_sysblock` 降低 `29.363%`，`eta_hat` 末值约 `0.904`。`AWFF_L1MultiFaultIsolationControllerEquation_Sysblock` 输出 `eta_hat1..4` 和 `fault_index`，已在 rotor1-4 四个单旋翼 85% 效率退化场景完成真实 Sysplorer MCP 50 s 仿真，四个场景均通过质量门，`5-50 s` 内对应 `fault_index` 正确率均为 `100%`。已知 eta 分支可作为故障参数上界，在线 eta 分支可作为单旋翼估计雏形，多旋翼隔离分支已经具备四旋翼持续单故障隔离验证证据；瞬态故障或故障切换仍需后续加入复位/模式切换逻辑。

### 6.0.1 L1-inspired + INDI-like 组合控制器

`AWFF_INDIControllerEquation_Sysblock` 当前采用组合式实现：保留 AWFF 稳定主反馈，在外环加入 L1-inspired 残差补偿，在姿态环加入有界 INDI-like 角加速度增量修正。该设计来源于单独 INDI 分支的复测结论：仅替换姿态误差导数为测量姿态角速度会削弱 8 字形轨迹中的参考变化前馈，导致 RMSE 不足以通过质量门。因此当前版本不把 INDI 作为独立替换项，而是作为组合控制链路中的姿态内环增强。

已完成真实 Sysplorer MCP 证据：

```text

Example2 helix-tuned: position_rmse_m = 0.446193, 相比 awff_sysblock_helix_tuned 降低 6.035%, quality_status = pass
```

报告表述边界：可以称为“L1-inspired + INDI-like 组合控制器已接入并通过 Example1/Example2 helix-tuned/Example3 质量门”，不能称为“严格完整 INDI 控制器已经单独证明优于 AWFF”。

### 6.1 扰动估计

```text
a_meas = (v_k - v_{k-1}) / dt
a_model = g + (T/m) R e_z
d_hat = a_meas - a_model
```

### 6.2 递推估计

```text
d_hat(k+1) = (1 - λdt)d_hat(k) + γ e_v dt
```

### 6.3 低通滤波

```text
d_comp = LPF(d_hat)
```

### 6.4 补偿方式

```text
a_cmd_corrected = a_cmd - d_comp
```

或：

```text
T_corrected = T_ref + m d_comp_z
```

### 6.5 限幅

```text
||d_comp|| <= d_max
```

### 6.6 扰动补偿实现规格

P1 推荐只实现加速度残差估计：

```pseudo
a_meas = filtered_derivative(velocity)
a_model = [0, 0, -g] + thrust_ref / mass * R * e_z
d_hat_raw = a_meas - a_model
d_hat = alpha_d * d_hat_prev + (1-alpha_d) * d_hat_raw
d_comp = clamp(d_hat, -d_max, d_max)
a_cmd_corrected = a_cmd - d_comp
```

P2 再加入速度误差递推项：

```pseudo
d_hat = (1 - lambda * dt) * d_hat + gamma * (velocity_ref - velocity) * dt
```

参数示例：

```yaml
disturbance_compensation:
  enabled: true
  method: acceleration_residual
  alpha: 0.85
  d_max: [2.0, 2.0, 2.0]
  gamma: [0.1, 0.1, 0.1]
  lambda: 1.0
```

验收：

```text
figure8_wind: RMSE 或 recovery_time 优于 no compensation
spiral_mass_change: steady_error 优于 no compensation
```

## 6.7 扰动识别与模式切换

本模块不替代控制器，而是根据残差和场景事件给控制链路提供模式信号。

识别输入：

```text
velocity_error
acceleration_residual
attitude_residual
motor_efficiency eta
sensor_noise_level
event_log
```

模式定义：

| 模式 | 触发条件 | 控制策略 |
|---|---|---|
| NORMAL | 残差低于阈值 | 标准控制 |
| WIND_REJECTION | 水平加速度残差持续偏大 | 启用 L1-inspired 水平补偿 |
| MASS_ADAPTATION | z 向残差或投递事件导致等效质量变化 | 调整质量估计和 z 向补偿 |
| FAULT_TOLERANT | eta 下降或角加速度残差异常 | 启用故障重构和保守限幅 |
| SAFETY_PROTECTION | 高度、倾角、障碍距离接近边界 | 强化 safety_filter |
| EMERGENCY_LAND | 重度故障或持续失稳 | 降级下降或安全终止 |

状态转移表：

| 当前模式 | 触发条件 | 目标模式 | 最小保持时间 | 恢复条件 | 事件 |
|---|---|---|---:|---|---|
| NORMAL | `norm(acc_residual_xy) > wind_threshold` 持续 N 个采样 | WIND_REJECTION | 1.0 s | 残差低于恢复阈值 2.0 s | wind_enter |
| NORMAL/WIND_REJECTION | 投递事件或 `abs(acc_residual_z) > mass_threshold` | MASS_ADAPTATION | 2.0 s | z 向稳态误差恢复 | mass_change |
| 任意非 EMERGENCY | `eta_min < 0.85` 或角加速度残差异常 | FAULT_TOLERANT | 2.0 s | eta 恢复或故障场景结束 | motor_fault |
| 任意 | 高度/倾角/障碍距离接近边界 | SAFETY_PROTECTION | 0.5 s | 安全裕度恢复 | safety_guard |
| FAULT_TOLERANT/SAFETY_PROTECTION | `eta_min < 0.5` 或持续失稳 | EMERGENCY_LAND | 至仿真结束 | 不自动恢复 | emergency_land |
| WIND_REJECTION/MASS_ADAPTATION | 残差恢复且无故障/安全事件 | NORMAL | 1.0 s | - | mode_recover |

冲突优先级：

```text
EMERGENCY_LAND > FAULT_TOLERANT > SAFETY_PROTECTION > MASS_ADAPTATION > WIND_REJECTION > NORMAL
```

伪代码：

```pseudo
function update_mode(state, residual, event, eta, previous_mode):
    if eta_min < 0.5 or severe_instability:
        mode = EMERGENCY_LAND
    elif eta_min < 0.85 or norm(attitude_residual) > fault_threshold:
        mode = FAULT_TOLERANT
    elif safety_margin_low:
        mode = SAFETY_PROTECTION
    elif abs(acc_residual_z) > mass_threshold or event == DELIVERY:
        mode = MASS_ADAPTATION
    elif norm(acc_residual_xy) > wind_threshold:
        mode = WIND_REJECTION
    else:
        mode = NORMAL

    if mode_changed and hold_time_satisfied:
        write_event_log(time, previous_mode, mode, reason)
    return mode
```

验收：

```text
figure8_wind: controller_mode 从 NORMAL 切换到 WIND_REJECTION
delivery_mass_change: 投递后进入 MASS_ADAPTATION，并记录事件
motor_fault_eta70: 故障后进入 FAULT_TOLERANT
heavy_fault: 进入 EMERGENCY_LAND 或安全终止
```

## 7. 控制器伪代码

```pseudo
function step(state, ref):
    a_raw = solve_nmpc(state, ref)
    d_hat = estimate_disturbance(state)
    d_comp = low_pass(d_hat)
    a_cmd = a_raw - d_comp

    thrust_ref, attitude_ref = accel_to_attitude(a_cmd, ref.yaw)
    thrust_ref, attitude_ref = safety_filter(thrust_ref, attitude_ref, state)

    torque_cmd = indi(attitude_ref, state.attitude, state.angular_rate)
    motor_cmd = allocate(thrust_ref, torque_cmd, motor_efficiency)

    return motor_cmd
```

通用控制器接口：

```pseudo
function controller_step(state_bus, reference_bus, params, memory):
    state = state_preprocessor(state_bus, memory)
    ref = reference_bus

    return motor_cmd, debug, mode, memory
```
