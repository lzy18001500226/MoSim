# 01 需求、范围与裁剪策略设计

## 1. 需求总览

本项目需求分为 6 类：

1. 控制算法需求；
2. 鲁棒性与故障验证需求；
3. 路径规划与轨迹生成需求；
4. 编队控制需求；
5. 仿真评估需求；
6. 文档与展示需求。

---

## 2. 功能需求表

优先级按初赛可落地性重新收紧：

- **P0 保底闭环**：必须稳定运行、导出结果、完成量化对比和视频素材。
- **P1 高分主线**：围绕位姿控制鲁棒性做深，优先完成对评分最有贡献的增强。
- **P2 展示增强**：规划、编队、MCP 等作为加分能力，不影响 P0/P1 主线交付。

| 编号 | 功能 | 优先级 | 验收方式 |
|---|---|---:|---|
| FR-01 | 官方 PID baseline 运行与结果导出 | P0 | 悬停、阶跃、8 字、螺旋至少 4 个场景可运行，并导出 raw.csv |
| FR-02 | 改进 PID 控制器 | P0 | 至少包含抗积分饱和、导数滤波、前馈、限幅中的 2 项，有 PID 对比曲线 |
| FR-03 | 典型轨迹与扰动场景 | P0 | 8 字、螺旋、恒定风扰、质量变化均可复现 |
| FR-04 | Syslab 指标计算与图表 | P0 | 输出 metrics.csv、summary.md、轨迹图、误差图、RMSE 对比图 |
| FR-05 | 三维可视化与视频素材 | P0 | 至少保存 3D 轨迹/动画截图，可支撑 7 分钟演示视频 |
| FR-06 | INDI 姿态内环或 PID-INDI 控制器 | P1 | 姿态响应或复杂轨迹 RMSE 优于官方 PID |
| FR-07 | NMPC 外环或线性 MPC 外环 | P1 | 若实时 NMPC 不稳定，可回退线性 MPC；复杂轨迹跟踪误差低于改进 PID |
| FR-08 | 扰动估计与低通补偿 | P1 | 风扰或质量变化下稳态误差/RMSE 有量化下降 |
| FR-09 | 安全约束过滤器 | P1 | 姿态、推力、高度或速度约束违规次数下降 |
| FR-10 | 电机效率下降故障注入 | P1 | eta=0.7 故障场景可运行，并记录恢复时间或最大姿态误差 |
| FR-11 | 控制分配重构 | P2 | 故障下最大误差或饱和比例低于无重构版本 |
| FR-12 | 路径规划与轨迹平滑 | P2 | A*/RRT*/手工航点 + Minimum Snap/B-spline 至少一种可生成 CSV 参考轨迹 |
| FR-13 | Leader-Follower 编队 | P2 | 三机固定队形跟踪 8 字，输出 formation_error_rmse 和最小机间距离 |
| FR-14 | 队形切换 | P2 | 三角形到一字形平滑切换，可展示队形误差曲线 |
| FR-15 | MCP 辅助仿真流程 | P2 | 至少完成模型查询、结果读取或指标脚本调用中的 1 项 |

## 3. 非功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| NFR-01 | 模块化 | 控制器、规划器、扰动、编队、评估解耦 |
| NFR-02 | 可复现 | 每次实验保存配置、结果、指标、图表 |
| NFR-03 | 可替换 | 控制器和规划算法可以通过统一接口替换 |
| NFR-04 | 可解释 | 每个模块有输入、输出、参数和指标说明 |
| NFR-05 | 健壮性 | 参数非法、模型检查失败、仿真失败要有提示 |
| NFR-06 | 展示性 | 轨迹图、误差图、指标图、3D 图完整 |
| NFR-07 | 可裁剪 | 某个高级模块失败时不影响主线 |
| NFR-08 | 文档性 | 用户手册、报告、README、接口文档齐全 |

- 编队参考轨迹生成；

- 点云建图；
- 真实视觉避障；
- 深度强化学习端到端控制。

## 5. 版本裁剪

```text
V0：官方 PID baseline + 数据导出
V1：改进 PID + 指标计算
V2：PID-INDI 或轻量 MPC + 鲁棒性对比
V3：NMPC-INDI-L1-inspired 主控制器
V4：Safety + Fault
V5：Planning + Formation
V6：MCP Automation
```

### 5.1 控制器裁剪

```text
NMPC-INDI-L1
  → NMPC-INDI
  → 线性 MPC + INDI
  → PID-INDI
  → 改进 PID
  → 官方 PID
```

### 5.2 规划裁剪

```text
EGO-inspired local optimization
  → RRT*/A* + B-spline
  → A* + Minimum Snap
  → 手工航点 + Minimum Snap
  → 预设轨迹
```

### 5.3 编队裁剪

```text
编队绕障 + 队形切换
  → 固定队形绕障
  → 固定队形 8 字
  → 单机轨迹
```

### 5.4 MCP 裁剪

```text
全流程自动化
  → 结果读取自动化
  → 模型查询自动化
  → Syslab 脚本
  → 手动仿真
```

## 6. 验收优先级

### 6.1 初赛必须验收

| 验收项 | 最低通过标准 |
|---|---|
| baseline | 官方 PID 至少完成悬停、阶跃、8 字、螺旋 4 类仿真 |
| 优化控制器 | 改进 PID 或 PID-INDI 至少 1 个控制器可稳定替换 baseline |
| 典型轨迹 | 8 字和螺旋轨迹均有参考/实际轨迹对比 |
| 鲁棒性测试 | 至少完成恒定风扰和质量变化 2 类测试 |
| 指标表 | metrics.csv 包含 RMSE、最大误差、稳态误差、控制能量、饱和比例 |
| 图表 | 3D 轨迹、位置误差、姿态误差、电机输入、RMSE 柱状图 |
| 报告和视频 | 用户手册、仿真分析报告、7 分钟内演示视频素材完整 |

### 6.2 高分加分验收

| 验收项 | 加分标准 |
|---|---|
| INDI/MPC/NMPC | 有消融实验说明每个模块带来的提升 |
| 扰动补偿 | 风扰或质量变化下 RMSE/恢复时间下降 |
| 安全过滤 | 约束违规次数、最小高度或姿态越界情况改善 |
| 电机故障 | eta=0.7 故障下仍可维持可控，并有对比指标 |
| 路径规划 | 规划轨迹可被控制器跟踪，且有最小障碍距离指标 |
| 编队 | 三机队形误差和最小机间距离可量化 |
| MCP | 自动化流程能减少人工操作并留下调用日志 |

### 6.3 失败判据

出现以下情况时，该次实验标记为 failure，不参与“性能提升”结论，只作为稳定性问题分析：

```text
z < 0.1 m
|roll| 或 |pitch| > 60 deg 持续超过 0.5 s
位置误差 > 5 m 持续超过 2 s
任一电机指令饱和比例 > 80%
仿真提前终止或无结果文件
```

## 8. 实现计划与风险控制

### 8.4 风险与回退

| 风险 | 回退 |
|---|---|
| NMPC 不稳定 | 线性 MPC / PID-INDI |
| INDI 噪声大 | 强滤波 / 降增益 / 回退改进 PID |
| L1-inspired 补偿发散 | 限幅 / 降 gamma / 仅保留离线分析 |
| 路径规划接入难 | 手工航点 + Minimum Snap / 预设轨迹 |
| 编队卡顿 | 固定三机队形 / 后处理展示 |
| MCP 失败 | 手动 Sysplorer 仿真 + Syslab 脚本 |
| 视频效果弱 | Syslab/Python 3D 可视化补充素材 |
