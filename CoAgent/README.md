# Legacy CoAgent Material

`CoAgent/` contains the former multi-thread AgentOS implementation, protocol,
packet, and maintenance material. It is retained for dependency audit and
historical trace-back only.

Current MoSim engineering does not use it as a task queue, approval surface,
runtime authority, or documentation entry point. Start from `AGENTS.md`,
`Docs/README.md`, and `Docs/Workflows/mainline_operations_board.md` instead.

Some files here intentionally preserve historical paths and terminology. Do not
repair, move, delete, or reactivate them opportunistically; perform a separate
dependency audit before any executable cleanup.
